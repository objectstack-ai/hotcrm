**Sales: Qualify Lead opens with the Need Type and the Estimated Amount the lead already has (#2754).** Before, the dialog opened with both required boxes empty even on a lead that already held them, so the rep typed the same values again. Now a value the lead already has is filled in when the dialog opens, from the lead's page and from the row menu of the Leads list: keep it or change it, then confirm. A lead without a value still opens with that box empty, and both are still required. No setup is needed.
