# 商机

**商机**是一笔活跃的交易——一个有已知客户、金额、成交日期和阶段的潜在营收事件。这是销售代表每天都要处理的记录。

## 7 个销售阶段

每个商机都会经历这些阶段。系统会跟踪你所处的位置并自动更新赢单概率。

| 阶段 | 默认赢单概率 | 处于此阶段时 |
| --- | --- | --- |
| ⚪ **开发期** | 10% | 首次接触，审核预算和需求 |
| 🟠 **资格审核** | 25% | 你已识别出决策者 |
| 🟡 **需求分析** | 40% | 需求已被记录 |
| 🔵 **提案** | 60% | 报价已发送 |
| 🟣 **谈判** | 80% | 正在协商定价和条款 |
| 🟢 **赢单** | 100% | **交易赢得** *(最终阶段)* |
| 🔴 **输单** | 0% | **交易失去** *(最终阶段)* |

你可以从任何开放阶段直接移动到**输单**（交易随时可能失去），但你不能向前跳过——你必须一次一个阶段地走过漏斗。系统会拦截无效跳转，以保持你的预测真实可靠。

## 商机记录存储的内容

详情界面有 7 个区块：

| 区块 | 字段 |
| --- | --- |
| **基本信息** | 名称、客户、主要联系人、负责人 |
| **财务** | 金额、预期营收 *(自动)*、概率 *(从阶段自动得出)* |
| **销售流程** | 阶段、成交日期、创建日期、当前阶段停留天数 |
| **分类** | 类型（新业务 / 升级 / 续约 / 扩展）、线索来源 |
| **竞争与营销活动** | 竞争对手、来源营销活动 |
| **备注与后续步骤** | 描述、后续步骤 |
| **预测与指标** | 行项目合计、审批状态 |

## 商机类型

| 类型 | 含义 |
| --- | --- |
| **新业务** | 全新的品牌 / 客户 |
| **现有 - 升级** | 现有客户升级到更高层级 |
| **现有 - 续约** | 现有合同续约 |
| **现有 - 扩展** | 现有客户增加新产品线 |

按类型拆分交易对于准确的营收预测至关重要——新业务和续约的赢单率差异很大。

## 自动发生的事

你无需记住其中任何一项——系统会为你完成：

- 每当你推进交易时，**概率**会从阶段中设定（如果你有特殊情况，*可以*手动覆盖，但下次阶段变化时它会重置）。
- **预期营收** = 金额 × 概率 ÷ 100，每当金额或概率变化时重新计算。
- **当前阶段停留天数**每天重新计算——它能暴露停滞的交易。
- 当你将一笔交易标记为**赢单且金额超过 $100K** 时，销售管理层会收到邮件。
- 当金额超过 **$500K** 时，交易会自动进入 [折扣审批](/zh-Hans/docs/revenue/approvals) 流程。

## 行项目——实际在销售什么

每个商机可以有行项目——每个所售产品一项。每一行存储：

- 产品（来自目录）
- 数量
- 单价（默认为产品的标价，可以被覆盖）
- 折扣 %
- 行合计

所有行项目之和汇总到商机**金额**中。如果你更愿意直接手动键入金额而不配置行项目，也可以——两种方式都行。

## 高价值交易的折扣审批

如果一笔交易的**金额超过 $500,000**，商机会被自动路由进行审批：

1. 商机被**锁定**——无人可以编辑它。
2. **销售经理**首先审核。
3. 如果批准，**销售总监**签字确认。
4. 最终批准后，阶段会被自动设为**赢单**。
5. 如果在任何步骤被拒绝，交易会被退回给销售代表重新论证。

审批状态会显示为商机详情界面顶部的横幅。完整流程参见 [Revenue › Approvals](/zh-Hans/docs/revenue/approvals)。

## 共享——谁能看到哪笔交易

默认情况下商机是**私有**的——只有负责人以及角色层级中位于其之上的人才能看到。

在此之上：

- **$100K 或以上的开放商机**会以*只读*方式与销售总监及层级中位于其之下的所有人共享。这样领导层无需跟进就能看到大单。
- **审批中的高价值交易**无论归属如何，审批人都可见。

## 标准列表视图

- **我的商机**——你负责的商机。
- **本季度销售管道**——本季度成交的开放交易。
- **本月成交**——本月成交的开放交易。
- **有风险**——已过成交日期但仍开放。
- **按金额排名的顶级交易**——最大的在前。
- **销售管道看板**——按阶段分组的看板（也可通过侧边栏快捷方式"销售管道"访问）。

## 商机详情布局

当你打开一个商机时，会看到：

- **头部**——名称、带 7 阶段路径的阶段徽章、金额、成交日期、负责人。点击路径上的任意阶段可直接跳转到它。
- **销售路径**——一键阶段推进。
- **报价**相关列表——带有一个**生成报价**按钮，可运行 [报价生成流程](/zh-Hans/docs/sales/quotes#generating-a-quote)。
- **行项目**——带有一个**添加产品**按钮。
- **活动时间线**——统一汇集评论、已记录通话（`sys_activity`）、外发邮件（`sys_email`）、任务完成以及字段历史审计条目。商机上每个被跟踪的更改（阶段、金额、成交日期、负责人）都会自动出现在这里；没有单独的"历史"标签页。
- **竞争对手与备注**——带有谈话要点的侧边面板。
- **AI 参考栏**——Sales Copilot 建议（Customer 360、营收预测、相关信号）。

## AI Copilot 如何提供帮助

当你打开一个商机时，可以提问：

- *"What's at risk here?"*——营收预测技能会检查阶段停留时长、竞争对手信号和成交日期滑移。
- *"Draft a follow-up email"*——邮件起草技能会撰写下一条外发消息。
- *"Summarise this account"*——Customer 360 技能给你一屏的客户历史简报。

## 给销售代表的提示

- ✅ **及时推进阶段**——如果你的阶段错了，概率就是错的。
- ✅ **添加行项目**以进行恰当的营收预测；汇总后的金额更准确。
- ✅ **填写后续步骤**——这是交接和站会中最有用的单个字段。
- ✅ **选择竞争对手**——AI 会用它来呈现制胜策略。
- ❌ 不要仅仅因为交易在滑移就更改成交日期。**有风险**视图的存在就是为了暴露真实的滑移。

## 给管理员的提示

- 阶段列表和默认概率位于商机对象的自动化中。参见 [Customization › Extending Objects](/zh-Hans/docs/customization/extending-objects) 来更改它们——你需要同步更新工作流规则和状态机。
- $500K 折扣审批阈值可以在 [审批流程配置](/zh-Hans/docs/revenue/approvals) 中更改。
- $100K 大单通知阈值位于商机工作流规则中。
