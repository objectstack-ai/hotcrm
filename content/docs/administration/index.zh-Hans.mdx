# 系统管理

系统管理部分面向 **CRM 管理员** —— 即为团队配置权限档案、共享规则、自动化和流程治理的人员。无需编写代码。

## 你将在这里找到什么

| 页面 | 涵盖内容 |
| --- | --- |
| [**设置清单**](/zh-Hans/docs/administration/setup) | 让 HotCRM 为你的团队做好准备的第一周任务 |
| [**权限档案**](/zh-Hans/docs/administration/profiles) | 六种内置权限档案以及如何分配用户 |
| [**共享与安全**](/zh-Hans/docs/administration/sharing-and-security) | 组织范围默认值、岗位、共享规则、FLS |
| [**自动化**](/zh-Hans/docs/administration/automation) | 流程、对象钩子、计划作业 |
| [**状态机**](/zh-Hans/docs/administration/state-machines) | 状态转换与强制执行 |

## 本部分面向谁

- **CRM 管理员** —— 你的日常手册。
- **销售 / 服务运营** —— 用于理解为什么事情会以特定方式运作。
- **实施顾问** —— 在初始上线期间。

如果你是用代码 **扩展 HotCRM 的开发者**，请改前往 [自定义](/zh-Hans/docs/customization/extending-objects)。

## 管理员的心智模型

HotCRM 建立在三个核心抽象之上：

1. **对象** —— 数据实体（客户、联系人、商机、工单）。
2. **自动化** —— 对象变更时发生的事情（流程、对象钩子、状态机）。
3. **安全** —— 谁能查看和编辑什么（权限档案、共享规则、字段级安全）。

大多数管理任务都属于这其中之一。本部分的页面会向你展示每一类的控制项。

## 你拥有的工具

- **设置 UI** —— 在齿轮图标下（右上角）找到它。所有管理任务的主中枢。
- **审计日志** —— 每一次配置变更都会记录谁/何时/做了什么。
- **沙箱** —— 在生产上线之前安全地测试配置变更。

## 从这里开始

1. 全新安装？遵循 [设置清单](/zh-Hans/docs/administration/setup)。
2. 需要给某个用户不同的访问权限？参见 [权限档案](/zh-Hans/docs/administration/profiles)。
3. 在梳理谁能看到什么？参见 [共享与安全](/zh-Hans/docs/administration/sharing-and-security)。
