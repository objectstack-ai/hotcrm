# 項目計劃

項目的計劃就是它的 **Project Tasks**（項目任務）。任務出現在項目的 **Related** 分頁中，也出現在 Project Delivery 應用的 **Project Plan**（甘特圖）和 **Task Tree** 中（包含所有項目）。項目自己的頁面不畫甘特圖：要在甘特圖上看一個項目的計劃，打開 **Project Plan**，在 **Project** 篩選裡選中這個項目。

## 誰來寫計劃

| 誰 | 能做什麼 |
| --- | --- |
| 項目經理、項目負責人、管理員 | 新增、修改和刪除任務。寫任務需要有項目的編輯權限 |
| 被安排在項目上的人 | 查看所有任務，但不能修改，進度請告訴項目經理 |
| 財務總監、項目總監、項目管理辦公室 | 查看所有項目的計劃 |

## 一項任務

| 欄位 | 含義 |
| --- | --- |
| **Task Name** | 這項工作是什麼 |
| **Parent Task** | 這項任務所屬的任務。有子任務的任務是彙總任務 |
| **Task Owner** | 完成這項任務或對它負責的人 |
| **Status** | Not Started、In Progress、On Hold、Completed 或 Cancelled |
| **Milestone** | 一個檢查點而不是一項工作，畫成菱形 |
| **Planned Start**、**Planned End** | 任務計劃在什麼時候做 |
| **Predecessors** | 這項任務開始前必須完成的任務 |
| **Planned Hours** | 這項任務計劃投入的工時。項目的 Percent Complete 按它給每項任務加權 |
| **Percent Complete** | 這項任務完成了多少。標為 Completed 時設為 100 |
| **Actual Hours** | 記到這項任務上的工時 |

**Parent Task** 和每個 **Predecessor** 都必須是同一項目的任務。如果選的上級任務是這項任務自己的子任務，會被拒絕，否則計劃會繞成一個圈。

## 甘特圖

甘特圖畫出任務，前置任務畫成箭頭，里程碑畫成菱形。子任務和彙總任務並列顯示，而不是縮排在它下面：應用中的 **Task Tree** 顯示任務樹。任務條的顏色跟隨任務狀態，填充部分跟隨 Percent Complete。

- **拖動任務條**修改任務的計劃日期，**拖動進度把手**修改 Percent Complete，都會立即儲存。
- 甘特圖工具列上的**自動排期**會移動等待被移動任務的後續任務，並儲存。

> **只有甘特圖會重新排期。** 伺服器不會連帶調整：在任務表單裡、透過匯入或 API 修改日期，只移動這一項任務，後續任務的日期保持不變，直到有人去移動它們。

## 記到任務上的工時

工時明細有一個可選的 **Task**，從工時單所屬項目的任務中選擇；選別的項目的任務會被拒絕。任務的 **Actual Hours** 彙總所有選了它的工時明細，不管工時單處於什麼狀態。成本仍然只在工時單批准後才計入（見[工時與費用](/zh-Hant/docs/projects/time-and-expenses)）。

## Percent Complete

項目的 **Percent Complete**（完成百分比）由任務計算，不能手工填寫。每次任務變化時：

1. 取沒有子任務的任務，去掉 Cancelled 的任務。彙總任務透過它的子任務計入，所以同一工時不會算兩次。
2. 用每項任務的 Planned Hours 給它的 Percent Complete 加權，Completed 的任務按 100 計。
3. 除以計劃工時總數。

| 任務 | Percent Complete |
| --- | --- |
| 設計，40 小時，50%；啟動，10 小時，Completed | (40 × 50 + 10 × 100) ÷ 50 = **60%** |
| 同上，設計也已 Completed | **100%** |

如果計入的任務都沒有計劃工時，每項任務權重相同。沒有可計入任務的項目不顯示百分比。
