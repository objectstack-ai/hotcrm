# 销售管道管理

销售管道是你所有开放商机的总和。HotCRM 为你提供一个受治理的销售管道，其中阶段推进、赢单概率和预测值都会自动保持同步——销售代表专注于销售，而非数据卫生。

## 概率是如何设定的

赢单概率会**根据阶段自动设定**，因此每位销售代表的预测都使用相同的数字：

| 阶段 | 默认赢单概率 |
| --- | --- |
| 开发期 | 10 % |
| 资格审核 | 25 % |
| 需求分析 | 40 % |
| 提案 | 60 % |
| 谈判 | 80 % |
| 赢单 | 100 % |
| 输单 | 0 % |

如果你有特殊情况，可以在单笔交易上手动覆盖概率，但下次阶段变化时该覆盖会被重置。这能防止销售代表手动抬高其预测。

> 管理员可以按阶段调整百分比——参见 [Administration › Automation](/zh-Hans/docs/administration/automation)。

## 预期营收是如何计算的

**预期营收 = 金额 × 概率 ÷ 100**

这个数字是加权预测的核心。每当金额或概率变化时（包括来自阶段变化的自动更新），它都会自动重新计算。

**销售仪表盘**会在开放销售管道上对*预期营收*求和，从而给你本季度的加权预测。

## 销售管道看板视图

**销售管道看板**（侧边栏快捷方式**销售管道**）将销售管道显示为 7 列——每个阶段一列。每张卡片显示：

- 商机名称
- 客户
- 金额
- 成交日期
- 负责人头像

要推进一笔交易，只需**拖动卡片**到下一列。系统会强制执行阶段规则，因此你无法从*开发期*直接拖到*赢单*。

在每列顶部，你会看到两个数字：

- **未加权合计**（金额之和）
- **加权合计**（预期营收之和）

## 销售管道健康信号

一些派生字段会暴露交易风险，让你能在每周回顾中据此采取行动：

| 信号 | 它告诉你什么 |
| --- | --- |
| **当前阶段停留天数** > 30 | 交易停滞——推进或关闭它。 |
| **成交日期已过** 且阶段仍开放 | 预测有误；重设日期或接受失单。 |
| **金额 > $500K** 但未提交审批 | 在此交易可成交之前需要折扣审批。 |
| **已设置竞争对手** 但无制胜计划 | Sales Copilot 可以建议一个策略。 |

当你提问 *"what's slipping?"* 或 *"how does my pipeline look?"* 时，Sales Copilot 会呈现有风险的交易。

## 值得收藏的销售管道报告

你会在侧边栏的**报告**部分找到这些：

| 报告 | 它显示什么 |
| --- | --- |
| **销售管道覆盖率（季度）** | 我们对即将到来的季度是否覆盖了 3 倍配额？季度 × 阶段矩阵。 |
| **按负责人 → 阶段的漏斗** | 每位销售代表的漏斗健康——发现漏水的阶段。 |
| **按阶段的商机** | 按阶段的销售管道柱状图。 |
| **按负责人的赢单** | 用于季末表彰的排行榜。 |
| **客户流失信号** | 现有客户的开放案例 + 低 NPS = 流失风险。 |

详情参见 [Analytics › Reports](/zh-Hans/docs/analytics/reports)。

## 推荐的销售管道节奏

| 节奏 | 该做什么 |
| --- | --- |
| **每日** | 打开销售管道看板。找出停滞的卡片（阶段内 > 14 天）。推进或关闭。 |
| **每周** | 运行*销售管道覆盖率*。向 Sales Copilot 提问：*"what's at risk?"* |
| **每月** | 运行*按负责人 → 阶段的漏斗*。对漏斗漏水的销售代表进行一对一辅导。 |
| **季末** | 运行*按负责人的赢单*以计算提成。归档输单交易并附上*失单原因*。 |

## 预测汇总

销售经理 / 总监的预测视图由以下部分构建：

- **商机**分析立方体（度量：金额之和，维度：阶段）
- **销售仪表盘**小部件（按阶段的销售管道、赢单率、顶级交易）
- **销售管道覆盖率**报告（季度 × 阶段矩阵）

它们共同回答：*"我们是否有足够的销售管道来完成本季度，以及风险在哪里？"*

## 给销售代表的提示

- ✅ 及时推进阶段——如果你的阶段错了，你的预测就是错的。
- ✅ 使用*后续步骤*——你的经理每周一站会都会读它。
- ❌ 不要滑动成交日期来掩盖滑移；使用*输单*并附上原因。

## 给销售经理的提示

- ✅ 每月运行*按负责人 → 阶段的漏斗*，以发现漏斗漏水的销售代表。
- ✅ 在 QBR 中使用*按季度的销售管道覆盖率*来设定下一季度的目标。
- ✅ 辅导销售代表填写*竞争对手*——它能显著提升 Copilot 的质量。

## 给管理员的提示

- 添加或移除阶段？你需要更新三处：商机对象上的选择列表、设定概率的工作流规则，以及控制状态转换的状态机。参见 [Customization › Extending Objects](/zh-Hans/docs/customization/extending-objects)。
- $100K *大单*通知阈值位于商机工作流规则中。
