# 出差申请

出差申请在出差之前提出：去哪里、什么时候、为什么、大约花多少钱。你的上级在花钱之前批准或驳回；为项目出差时，由项目的项目经理审批。它在**费用报销**应用的**出差申请**下。

出差申请不是必需的。没有申请也可以录入和提交费用。

## 填写申请

打开**我的出差申请**，点**新建**：

| 字段 | 填写什么 |
| --- | --- |
| **出差事由** | 为什么去（必填） |
| **目的地** | 去哪里（必填） |
| **开始日期**和**结束日期** | 出差的第一天和最后一天（必填）。**天数**首尾两天都算 |
| **预计金额** | 整次出差的一个总数，使用贵公司的本位币，不论每一部分由谁支付（必填） |
| **客户** | 为哪个客户出差，可选 |
| **项目** | 为哪个项目出差，可选（启用项目交付时才有）。不提供已关闭或已取消的项目 |
| **行程** | 用你自己的话写的计划 |
| **备注** | 其他内容 |

在**附件**标签页上传文件。**来源**说明这条记录从哪里来，**检查提示**是助手或规则写给审批人看的发现。两者都不影响任何判断：助手可以以你的身份通过接口起草申请、估算金额或检查，决定仍由审批人做出。

## 行程明细

一次出差有好几程时，可以在申请页面的**行程明细**下逐程列出。每一程点一次**新建**：

| 字段 | 填写什么 |
| --- | --- |
| **类型** | 航班、火车、用车、酒店或其他（必填） |
| **出发地**和**到达地** | 这一程从哪里出发、到哪里；酒店的**到达地**填酒店所在地（**到达地**必填） |
| **开始日期**和**结束日期** | 这一程的日期（必填），酒店另填退房日期 |
| **要求** | 座位、想住的酒店或其他要求 |
| **预订号** | 订好之后的确认号 |

各程按出行顺序列出。行程明细不带金额：申请上的**预计金额**是唯一的总数。行程明细是可选的，没有明细的申请也是完整的。

## 提交和审批

| 状态 | 含义 |
| --- | --- |
| **草稿** | 还在填写 |
| **已提交** | 已交给审批人，等待期间锁定 |
| **已批准** | 同意。计划不再改动 |
| **已驳回** | 被退回。改回草稿，修改计划后重新提交 |
| **已取消** | 批准后不去了。最终状态 |
| **已关闭** | 出差已结束。最终状态 |

点**提交**即送审。由谁决定取决于**项目**：

- **有项目**：由项目的**项目经理**决定。项目经理也审批这个项目上的费用，所以出差和它的花费交给同一个人。项目没有项目经理，或者是项目经理自己出差，则由管理员决定。
- **没有项目**：由**你的上级**（你用户记录上的**上级**）决定；没有上级时，改由**财务控制**决定。

无论哪种，都只有一个人在**收件箱**中决定，不会两人都审。只有一级：财务在之后的费用上把关，不审批出差申请。**待我审批的出差申请**列出等待你审批的申请。不能审批自己的申请，也没有人能手动设置**已批准**或**已驳回**。

**等待期间改主意了？**在收件箱中撤回，申请回到**草稿**。

**只有一个人的组织。** 没有人能审批自己提交的申请，管理员也一样，所以出差申请需要另一位能审批它的用户：你的上级、一位财务控制或一位管理员；项目上的出差申请则是项目的项目经理或一位管理员。在这个人加入之前，提交的申请停在**已提交**，没有人能决定它：请在收件箱中撤回，等这个人加入后再次提交。

**只有草稿状态的申请可以删除。**申请一经提交就保留在记录中，连同它的审批和报销单。要取消已批准的出差，请选择**取消出差**；被驳回的申请要先退回**草稿**。

## 批准之后

批准针对的是这份计划，所以已批准申请的**出差事由**、**目的地**、日期、**预计金额**和**项目**都不再改动。从提交那一刻起，各程也一样被锁定：类型、地点、日期和要求都不再改动，也不能再添加或删除行程。要改计划，请点**取消出差**，再重新申请。出差结束后，点**关闭**。

每一程的**预订号**都可以填写，只有申请等待审批期间除外：这时每一程都被锁定，预订号也不例外，改动会被拒绝，直到审批有了结果。订好之后，由你本人、以你的身份通过接口办事的助手、你的审批人或代订人把确认号写在这里，批准之后也可以。

## 报销这次出差

用**按出差申请报销**提交这次出差的费用，并选这张申请（见[费用](/zh-Hans/docs/expenses#expenses-of-a-trip)）。之后申请会对照预计金额显示花费：

| 字段 | 显示什么 |
| --- | --- |
| **已申报金额** | 引用本申请、已提交、已批准或已付款的报销单合计。草稿或被驳回的报销单，重新提交后才计入 |
| **与预计的差额** | 已申报减去预计：大于零就是超出预计 |
| **超出预计** | 已申报超出预计时打勾 |

申请页面上列出它的报销单，每张报销单也给审批人看同样的数字。超出预计只是提醒审批人，不会拦住。

财务把一张报销单标记为已付款时，如果这张申请下没有其他报销单还处于草稿、已提交或已批准，申请会自动**关闭**。已取消或已关闭的申请不能再报销。

## 谁能看到

你能看到自己的申请及其行程明细，以及请你审批的申请。财务能在**全部出差申请**里看到所有申请，销售经理和销售领导也一样；他们都不能修改别人的申请。出差申请不出现在销售、客服、市场应用里，也不出现在客户页面上。

启用项目交付时，项目人员在**项目交付**应用的**我的费用**旁边也能找到**我的出差申请**，项目页面的**相关**标签页列出这个项目的出差申请（每个人看到的范围同上）。出差申请不计入项目成本：成本随费用而来。不启用项目交付时，没有**项目**字段，所有申请都交给出差人的上级。
