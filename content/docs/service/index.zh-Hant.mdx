# 服務雲

服務模組幫助你的支援團隊**接收客戶問題、確定優先順序、在 SLA 內解決問題，並在出現狀況時升級處理**。每個工單都關聯回對應的客戶和聯絡人，因此你在解決問題時始終能看到完整的客戶歷史。

| [**知識庫**](/zh-Hant/docs/service/knowledge-base) | AI 服務 Copilot 讀取的支援知識。 |

## 一個典型工單的生命週期

```
New ──► In Progress ──► Waiting on Customer ──► Resolved ──► Closed
                  ╲                          ╱
                   ╲ Escalated ────────────╱
```

1. **建立工單**（透過電子郵件、網頁表單、電話記錄，或由 **Service Copilot** 對來訪訊息進行分流）。
2. **分配優先順序**——低、中、高或緊急。*緊急*會立即提醒支援經理。
3. **計算 SLA 目標**——每個工單都會根據優先順序獲得一個截止時間。
4. **客服處理工單**，隨進度推進狀態。
5. **如果卡住了**（或緊急，或來自客戶），[升級流程](/zh-Hant/docs/service/sla-and-escalation#case-escalation)會將其重新分配給資深客服。
6. **記錄解決方案**，自動標記解決時間，並關閉工單。

## 系統為你做的事

- **自動確定優先順序**——透過工單分流技能（Service Copilot 閱讀工單並推薦優先順序）。
- **自動升級**——將緊急工單或高優先順序客戶工單升級給資深客服。
- **緊急時通知**——每當工單被設為緊急時，向支援經理發送郵件。
- **升級時通知**——每當工單被升級時，向升級團隊發送郵件。
- **標記解決時間**——工單關閉時自動標記。
- **標記 SLA 違約**——一旦 SLA 目標時間過去，顯示紅色橫幅。
- **阻止錯誤關閉**——未填寫解決方案就不能將工單標記為已關閉。

## Service Copilot

[服務技能](/zh-Hant/docs/ai-copilot/service-copilot) 內建於每個工單中。你可以問助手：

- *"分流這個工單"*——根據主題、描述和客戶等級分配優先順序。
- *"建議一個解決方案"*——搜尋支援知識庫並起草客戶回覆。
- *"總結這個客戶"*——包括過往工單和未結商機的 Customer 360 檢視。

## 標準儀表板與報表

- **服務儀表板**——按優先順序劃分的未結工單、SLA 表現、頂尖客服、最久未結工單。
- **每日 × 優先順序開單數**——每日流入量。
- **按狀態 × 優先順序劃分的工單**——當前快照。
- **SLA 表現**——在 SLA 目標內解決的工單百分比。

參見 [分析 › 儀表板](/zh-Hant/docs/analytics/dashboards) 與 [報表](/zh-Hant/docs/analytics/reports)。
