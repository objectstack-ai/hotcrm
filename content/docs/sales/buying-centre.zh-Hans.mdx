# 采购决策圈

凡是大到一个人签不了字的采购，都是**若干人一起决定**的，而这些人各自想要的东西并不一样。这群人就叫**采购决策圈**，它是 B2B 销售里最老的一个概念：你卖的从来不是"一家公司"，而是五六个具体的人，他们最后必须达成一致。

HotCRM 把这群人记录在联系人上，用三个字段回答三个不同的问题：

- **采购角色**——这个人在这次决策里*做什么*。
- **对我司态度**——他*站在哪一边*。
- **与销售关系强度**——我们*到底有多熟*。

三个都填上，一个客户就不再是一张电话清单，而是一张开会之前就能读的地图。

## 为什么只有职位不够

联系人上本来就有**职位**和**部门**。那是关于这个人的雇主的事实，而且相当稳定：一位"区域 IT 经理"在你以后跟这家公司做的每一单里都还是区域 IT 经理。

采购决策圈恰恰不稳定，这正是它的价值。同一位经理，可能在你的基础设施单子里是拍板的人，在你的分析单子里却在默默地挡着。你要记下来的是他在**这一次**采购里的位置，而职位字段承载不了这件事。

**主要联系人**标志同样承载不了。那个标志只回答一个问题——默认联系谁——客户处其余的人一个都没被描述。一个比特不是一张地图。

## 每个人在决策里做什么

按你正在推进的这单采购，挑这个人扮演的那一个角色。选项是通用的，因为它们在任何行业里都成立：

| 采购角色 | 实际指的是谁 |
| --- | --- |
| **决策者** | 他说"可以"，争论就结束了。往往不是场上职级最高的那个名字。 |
| **预算决策人** | 钱从他的预算里出。有时和上面是同一个人，更多时候不是——而且永远不要默认是。 |
| **技术评估人** | 判断东西到底能不能用：安全评审、集成、概念验证。很少能拍板说行，却很容易说不行。 |
| **使用者** | 买回去之后天天要用的人。他会告诉所有人这到底是不是个好主意。 |
| **影响者** | 在流程上没有名分，实际分量却很重——一位受信任的架构师、一位外部顾问、一位说话有人听的同事。 |
| **守门人** | 控制的是"能不能接触到"，不是"结果是什么"：行政助理、采购专员、必须先被说服你才约得上会的安全负责人。 |

一个人确实可能同时是其中两种。请记下**决定这一单成败的那一种**，其余的交给职位字段去承载。

## 他站在哪一边

**对我司态度**是一条五级阶梯，从最好到最差：**拥护者** · **支持** · **中立** · **存疑** · **反对者**。

拥护者不等于"对你客气的人"。拥护者是在你不在场的会议上会替你说话的人——这就是全部的判据，也是这一级比其他几级都重要的原因。反对者是它的镜像，早一点知道你的反对者是谁，比再做一次演示值钱得多。

真的还不知道的时候，就**留空**。留空和*中立*是两件不同的事：前者说没人形成过判断，后者说你见过他，而他无动于衷。

## 我们到底有多熟

**与销售关系强度**依次是**疏远** · **一般认识** · **工作往来** · **关系紧密** · **可信顾问**。

这说的是关系，不是活动量。联系人上的**最近联系时间**是记录通话或会议时自动写上的，它量的是*近度*，完全是另一回事。每周都通话却永远不会站在你这边的人，不算关系紧密；一个季度吃一次饭、但招标出去之前会先给你打个电话的人，才算。

## 把一个客户读成一张地图

打开**联系人**。默认视图**全部联系人**按所属客户分组、分组默认折叠——展开你正在跟的那个客户，这三列就排在职位和部门旁边，一屏之内回答：

- 这个客户上到底有没有**决策者**？还是我们只见过使用者？
- 谁是我们的**拥护者**——有没有人是**反对者**？
- 我们关系最好的那几个人，是真正拍板的人，还是只是最好说话的人？

缺口往往就是答案。一个客户下面四个联系人，全是使用者、全是中立，无论活动记录多热闹，都算不上一个被覆盖住的客户。

> **这里没有任何东西会拦住保存。** 三个字段都是普通的可选字段——没有规则校验它们，没有自动化替你填，三个全空的联系人和以前一样能存下来。这是刻意的：采购决策圈是你的团队写下来的判断，不是机器能算出来的状态；一个会拦下保存的产品，只会教会所有人往框里随便塞一个值。

## 给销售的建议

- ✅ **开完会就填**，趁印象还新。每个字段都只要几秒。
- ✅ 盯着**缺的那个人**看，而不是已经填上的那些——一单里没有预算决策人，就是这一单还没有人问过钱的事。
- ✅ 单子卡住的时候回头看一眼态度那一列。卡住通常是因为有个没人写下来的反对者。
- ⛔ 不要因为对方客气就标成拥护者。要问的是：在你不在场的会上，他会不会替你说话。

## 给管理员的建议

- 三个字段在联系人表单和详情页上自成一个**采购决策圈**分区。该分区由对象的字段分组派生，不需要手工排版。
- 三个字段在四种随附语言里都是普通选项列表。要改措辞或加值，参见 [Customization › Extending Objects](/zh-Hans/docs/customization/extending-objects)。
- 它们背后没有自动化，也不打算有。如果你想要一个"未识别拥护者"的预警，那是一张读这些值的报表或仪表板，而不是联系人上的一条规则。
