# AI 與智能體

本應用未隨附繁體中文語言包，因此本頁出現的介面名詞依固定順序取用：zh-CN 語言包已收錄者，採其用詞的繁體寫法；未收錄者，保留產品內的英文原名，不另造譯名。

**HotCRM 為智能體而建，但它不自帶智能體。** 它提供智能體工作所需的三樣東西：**物件**（每一個客戶、商機、訂單、合約、發票、項目、費用和工單），一個人從按鈕上執行的**動作**，以及教智能體理解 CRM 的六項**技能**。智能體本身是你的：可以是你透過 MCP 接入的那個，也可以是平台提供的助手。

## 為什麼這樣設計

辨識一張票據、按差旅制度核對一筆費用、起草一封回覆、催收一張逾期發票：這些都是智能體每個月都做得更好的工作，沒有一件需要內建進 CRM。HotCRM 保留智能體無法憑空造出的東西 —— 紀錄、守護這些紀錄的規則，以及誰可以做什麼 —— 把推理留給智能體。

所以你在 HotCRM 裡找不到內建的票據辨識、制度引擎或聊天助手。你會找到：

| HotCRM 提供 | 在哪裡閱讀 |
| --- | --- |
| 每一個物件，透過 MCP，在呼叫者的權限之下 | [接入你的智能體](/zh-Hant/docs/ai-copilot/connect-your-agent) |
| 智能體可以執行的動作，以及它在不可撤銷的動作前如何先確認 | [對智能體開放的動作](/zh-Hant/docs/ai-copilot/agent-actions) |
| 平台智能體攜帶的六項技能 | [技能](/zh-Hant/docs/ai-copilot/skills) |
| 智能體可以寫入結論的欄位，例如報銷單或出差申請上的 **Review Notes** | [費用報銷](/zh-Hant/docs/expenses) |

## 唯一的規則：智能體就是一個人

智能體**以某個人的身分**接入 —— 用登入工作階段或這個人的 API 金鑰 —— 並以這個人的身分行事。它讀這個人能讀的，寫這個人能寫的，在這個人會被拒絕的地方被拒絕，提示也一樣。它寫下的紀錄帶著這個人的名字。沒有權限更寬的智能體帳戶，也沒有能開出這種帳戶的開關。

所以「我的智能體能做什麼？」和「這個人能做什麼？」答案相同：看他的權限集、職位和共用規則。參見[共用與安全](/zh-Hant/docs/administration/sharing-and-security)。

## 平台助手額外帶來什麼

ObjectStack 環境可以執行一個平台助手（`ask`）。HotCRM 不為它編寫智能體；它的六項技能附著在這個助手上，教它審查線索資格、起草郵件、預測營收、產生客戶 360° 和分流工單。本機社群版啟動時不執行任何助手（`GET /api/v1/ai/agents` 回傳空清單）：這時，智能體就是你接入的那個。

> **沒有應用自有的智能體。** HotCRM 曾定義過兩個自己的智能體——「銷售 Copilot」和「服務 Copilot」。它們已被退役，其能力遷移到了附著於平台助手的技能中。
