# 产品

**产品**是你销售的任何东西——软件、硬件、服务、订阅、支持套餐。产品目录会输入到报价和商机中：当销售构建报价时，他们从这个目录中挑选产品，而不是手动输入名称。

## 产品记录存储的内容

详情界面有 3 个区块：

| 区块 | 字段 |
| --- | --- |
| **Product Information** | 产品编码 *(自动)*、名称、描述、类别、产品系列 |
| **Pricing & Billing** | 标价、成本、SKU、计费类型、计量单位、税率、应税标记 |
| **Resources** | 产品图片、规格表、产品经理 |

## 类别和产品系列

用两种方式对产品分类：

**类别（Category）**——产品如何交付：

- **Software** *(默认)*——已安装或下载的软件
- **Hardware**——物理设备
- **Service**——咨询、培训、专业服务
- **Subscription**——经常性访问
- **Support**——付费支持等级

**产品系列（Family）**——产品在你产品组合中的定位：

- **Enterprise Solutions**
- **SMB Solutions**
- **Professional Services**
- **Cloud Services**

类别和产品系列让你能按产品组合切分报表——*"本季度我们记入了多少 SMB 等级的订阅营收？"*

## 计费类型

| 计费类型 | 用于 |
| --- | --- |
| **One-Time** *(默认)* | 永久许可、一次性购买 |
| **Monthly** | 月度订阅 |
| **Quarterly** | 季度订阅 |
| **Annual** | 年度订阅 |
| **Usage** | 基于用量（按 API 调用、按 GB 等） |

计费类型驱动报价如何计算总额（一次性费用 vs. 经常性），并输入到营收确认报表中。

## 计量单位

指定产品如何销售：

- **Each** *(默认)*——每数量一个单位
- **License**——按软件许可
- **Seat**——按命名用户
- **Hour**——用于服务
- **Day**——用于服务
- **Month**——用于有时限的订阅

## 定价字段

| 字段 | 用途 |
| --- | --- |
| **List Price** | 标准公布价——默认显示在报价上的价格 |
| **Cost** | 你的成本——用于利润计算 |
| **Default Tax Rate %** | 自动应用到报价明细行 |
| **Taxable** | 如果未勾选，则不添加税（零税率产品） |

如果成本大于标价（这会是一笔亏本的销售），系统会警告你。

## 库存跟踪

针对物理产品：

- **Quantity on Hand**——当前库存。
- **Reorder Point**——何时补货。

这些字段是可选的——对于非库存项（软件、服务）保持为空。

## 产品图片和规格表

两个附件字段让你上传：

- **Product Image**——显示在报价明细行和产品列表视图上。
- **Datasheet**——通常是 PDF；提供给 Sales Copilot 用于 AI 起草的邮件和提案。

产品信息知识库会读取这些规格表，因此准确、最新的文档会让 Copilot 更智能。

## 内置规则

- **标价必须大于零**——你不能销售一个免费产品（如果你确实需要，可使用 $0.01 的标价配合 100% 折扣）。
- **成本不能超过标价**——仅警告，不阻止保存。
- **商机 / 报价明细行上的单价必须为零或正数**——基本验证。

## 共享——产品默认公开

产品目录对整个组织是**公开只读**的。销售代表可以查看和使用任何产品；只有市场/产品经理可以编辑。

## 标准列表视图

- **Active Products**——`is_active = true`。
- **By Category**——分组。
- **By Family**——分组。
- **Subscriptions**——`category = subscription OR billing_type IN [monthly, quarterly, annual]`。
- **Low Stock**——`quantity_on_hand < reorder_point`（针对库存产品）。

## 给产品经理的提示

- ✅ **保持规格表最新**——Sales Copilot 用它来起草面向客户的内容。
- ✅ **使用产品图片**——它能显著改善面向客户的报价的外观。
- ✅ **将旧产品标记为非活跃**，不要删除它们——过往的报价和合同仍引用它们。

## 给销售代表的提示

- ✅ 使用目录中的产品，而不是手动输入明细行——定价和税会被自动填充。
- ✅ 在提案前检查规格表——它通常包含你提案所需的确切规格表。

## 给管理员的提示

- 类别、产品系列、计费类型和计量单位选项列表都可以扩展。参见 [定制 › 扩展对象](/zh-Hans/docs/customization/extending-objects)。
- 一个产品可以关联到多个商机和报价——停用不会破坏历史记录。
