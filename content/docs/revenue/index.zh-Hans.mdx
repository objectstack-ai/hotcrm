# 营收云

营收模块涵盖**销售说"我们赢了"之后**发生的一切：管理产品目录和价格、治理合同和续约，以及审批高价值折扣。

## 包含内容

| 领域 | 作用 |
| --- | --- |
| [**产品**](/zh-Hans/docs/revenue/products) | 你所销售内容的目录——名称、编码、标价、SKU。 |
| [**合同**](/zh-Hans/docs/revenue/contracts) | 与客户签署的协议——条款、价值、续约。 |
| [**审批**](/zh-Hans/docs/revenue/approvals) | 针对高价值折扣的多步骤审批。 |
| [**计费交接**](/zh-Hans/docs/revenue/billing-handoff) | CRM 范围的终点——把赢单商机与已激活合同交给计费系统的两个出站事件。 |

## 营收生命周期

```
Product (catalog)
   │
   ▼
Quote with line items
   │ (accepted)
   ▼
Contract (Activated)
   │
   ▼ (renewal_notice_days before end_date)
Renewal task ──► Renewal opportunity
```

1. **建立目录**——带编码、标价、SKU 的产品。
2. **构建报价**——使用目录中的明细行（参见 [报价](/zh-Hans/docs/sales/quotes)）。
3. **接受时**系统会以报价的条款创建一份合同。
4. **合同被激活**——账户被提升为 *Customer*。
5. **合同结束前**，系统会安排一个续约任务和一个续约提醒。
6. **续约商机**可在客户希望延期时创建。

## 系统为你做的事

- **自动提升账户**——合同被激活的那一刻将账户提升为 *Customer*。
- **自动盖签署日期**——同一次激活会在**合同**上写入当天日期，且仅当合同上还没有签署日期时才盖。**账户**上不会盖任何日期：没有 *Customer Since* 字段，也没有任何其它名字的字段记录账户何时成为客户，所以做同期群分析只能读合同的**签署日期**或**开始日期**。
- **每日到期扫描**——午夜时分，超过结束日期的合同被标记为 *Expired* 并通知所有者。
- **每日续约提醒**——当合同进入它自己的通知窗口（**续约通知（天）**，不改就是 30 天）时，**合同负责人**会收到一个续约任务和一条提醒（站内收件箱 + 邮件）。除他之外无人被通知——账户所有者不会，账户上的续约负责人也不会。
- **折扣审批**——超过 $500K 的商机自动路由给经理 + 总监签批。

## 在哪里找到这些内容

HotCRM 应用里**没有 Products（产品）分组**。产品目录在侧边栏上唯一的入口是 **Marketing**（市场营销）分组下的 **Products**（产品）——参见 [Marketing](/zh-Hans/docs/marketing/index)。除了这一项和全局搜索之外，只能从报价或商机的明细行反查到产品记录。

**Contracts**（合同）挂在 **Sales**（销售）分组下，与 Leads、Accounts、Contacts、Opportunities、Pipeline、Quotes 并列——因为合同属于销售流程。这也是整个应用侧边栏里通往合同的唯一入口。

**Approvals**（审批）分组只有一项：

- **Inbox**——点开后进入平台的**审批中心**，在那里把等着你处理的审批批准或拒绝。侧边栏上的 label 就是 **Inbox**，简体中文界面下显示为**待我审批**；应用里没有任何条目叫 *Approval Requests*（审批请求）。

本页过去列出的另外两个名字，不在这个分组里：

- **Action History**（操作历史）——侧边栏上没有叫这个名字的条目。审批的操作留痕本身是真实数据，由审批插件以 `sys_approval_action` 存储，但本应用里没有任何导航条目能打开它。
- **Processes**（流程）——是被**刻意删掉**的，不是漏掉的：任何已安装的插件里都不存在 `sys_approval_process` 对象，该条目的 *requires object* 守卫会在每一次安装里把它永远隐藏。除非将来有这样一个对象上线，它不会回来。

**Marketing** 与 **Approvals** 两个分组都**默认折叠**——与 Sales、My Work、Activity、Service 不同，它们不会在应用加载时自动展开。先把分组点开，再判断某样东西在不在这里。
