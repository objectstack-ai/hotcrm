# AI Skills

AI skills 位于拥有它的那个包的 `skills/` 目录下——今天是 `src/sales/skills/` 与 `src/service/skills/`——每个包各自从该目录的 `index.ts` 重新导出自己的 skill。

HotCRM **不定义任何自己的 agent** —— 不存在 `src/agents/` 目录。Skills 附着在每个
ObjectStack 环境已自带的平台助手（`ask`）之上。把 skill 注册进所属包的 skill 清单就是全部
的接线工作。

## 新增 skill

```ts
// src/sales/skills/renewal_pitch.skill.ts
import { defineSkill } from '@objectstack/spec';

export const RenewalPitchSkill = defineSkill({
  name: 'renewal_pitch',
  label: 'Renewal Pitch',
  description: 'Drafts renewal talk tracks from account and contract context.',
  instructions: `When asked for a renewal pitch, inspect the current
account and contract records, summarize risk, and draft a concise
  customer-facing talk track.`,
  tools: ['describe_object', 'query_records'],
});
```

## 注册

注册分两步，漏掉第二步会让这个 skill 被静默丢弃。先从它自己所在包的 barrel 重新导出，再把它加入
所属包的 skill 清单——app 包（sales、revenue、marketing）是 `objectstack.composition.ts` 里的
`appSkills`，服务模块是 `src/service/index.ts` 里的 `serviceSkills`。正是这份清单、而不是那个
barrel，被交给该包自己的 `defineStack({ skills })`：

```ts
// src/sales/skills/index.ts —— 包自己的 barrel：只做重新导出，别无其它
export { RenewalPitchSkill } from './renewal_pitch.skill.js';
```

```ts
// objectstack.composition.ts —— app 包的那份清单
import { RenewalPitchSkill } from './src/sales/skills/index.js';

export const appSkills = [
  // …已有的 skills
  RenewalPitchSkill,
];
```

若希望该 skill 只在特定记录上激活（而非处处可用），在它上面声明 `triggerConditions`
即可，例如 `{ field: 'objectName', operator: 'eq', value: 'crm_contract' }`。
