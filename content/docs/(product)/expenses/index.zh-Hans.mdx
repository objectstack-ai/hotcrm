# 费用报销

费用报销面向每一位为公司花钱的员工，不只是项目人员。它是 HotCRM 的一个模块，有自己的应用**费用报销**，管理员可以把它关掉。

出差前先申请，请填写[出差申请](/zh-Hans/docs/expenses/travel-requests)。

## 记录一笔费用

在**费用报销**应用里打开**我的费用**，点**新建**：

| 字段 | 填写什么 |
| --- | --- |
| **描述** | 这笔钱花在哪里 |
| **日期** | 什么时候花的 |
| **类别** | 差旅、住宿、餐饮、设备或其他 |
| **金额** | 花了多少，使用贵公司的本位币。外币票据请先换算再录入 |
| **付款方** | **员工**（你先垫付，再报销给你，默认值）或**公司**（例如用公司卡支付） |
| **商户** | 在哪里花的，可选 |
| **票据号** | 票据上的号码，如有 |
| **可计费** | 是否向客户收取 |

在**附件**标签页上传票据。**来源**说明这条记录从哪里来：你手工填写时是**手工录入**，由助手或导入写入时是**智能体**或**导入**。启用项目交付后，表单上还有**项目**：见[项目上的费用](#on-a-project)。

**检查提示**用来写下检查这笔费用时发现的情况，由助手或你本人填写：超出某条[费用标准](#expense-standards)、票据号以前出现过、缺少票据等。审批人在报销单的费用列表里阅读它。HotCRM 自己不会往这里写任何内容；报销单提交后，它和这笔费用的其他内容一起锁定，所以检查提示要在每条费用提交之前写好。报销单自己也有**检查提示**，但审批中的报销单整张锁定，审批人也不例外：只有报销单退回草稿时才能填写。

## 提交报销

在**我的费用**里勾选你的费用，在选择栏中点**提交报销**。只报一笔时，记录页上也有同一个按钮。不需要再填写任何内容：这些费用放进一张**报销单**，报销单在同一次点击中送审。在**我的报销单**里跟进。

- **每个项目一张报销单。**启用项目交付后，每个项目的费用各自放进一张报销单，其余的另放一张；一次出差涉及两个项目，就生成两张报销单。见[项目上的费用](#on-a-project)。
- 报销单的**标题**是这些费用的日期范围。**合计**汇总单上每一笔费用；**应报销**只汇总员工垫付的费用。
- 只能提交你自己的、尚未放进报销单且未批准的费用。勾选的费用中只要有一笔不符合，就一笔也不提交，提示会逐笔写明原因。

费用的状态跟随所在的报销单，你不需要自己设置。

| 报销单状态 | 含义 |
| --- | --- |
| **草稿** | 已撤回，或被驳回后重新打开。单上的费用可以再次修改 |
| **已提交** | 等待审批。报销单及其费用被锁定 |
| **已批准** | 已批准，等财务把钱报销给你 |
| **已付款** | 财务已记录钱报销给你。最终状态 |
| **已驳回** | 被退回。点**退回草稿**，修改费用后再点**提交** |

## 出差的费用 [#expenses-of-a-trip]

如果这些费用属于你事先申请过的一次出差，在**提交报销**旁边改选**按出差申请报销**，再选[出差申请](/zh-Hans/docs/expenses/travel-requests)。只列出你自己**已批准**的申请。报销单的生成和送审与上面完全一样，只是写明这张申请；一次出差可以分几张报销单报销，一张报销单最多对应一张申请。申请在提交时选择，事后不能再加到报销单上。没有出差的费用，**提交报销**仍然一键完成。

这样的报销单会给审批人看出差的预计金额、这次出差已申报多少、是否超出预计。超出只是提醒，不会拦住。

## 由谁审批

- **你的上级**，即你用户记录上的**上级**。没有上级时，改由**财务控制**决定。
- **合计**达到 **2,000** 或以上的报销单，随后还要交给**财务控制**审批，他们也批准后才算批准。

审批人在**待我审批**（在**我的工作**下）里点**批准**或**驳回**。**待我审批的报销单**列出等你审批的报销单，可以先打开查看，单上的每一笔费用也都能打开。没有人审批自己的报销单，也没有人能手动设置**已批准**或**已驳回**。

**想撤回？**在等待期间从待我审批里撤回报销单，它连同费用回到**草稿**；点**提交**即可再次送审。只有草稿状态的报销单可以删除，单上的费用会保留，可以再次提交。

**管理员**也可以删除等待审批或已驳回的报销单，用来修复。单上的费用回到**草稿**，可以再次提交。已批准或已付款的报销单不能删除，管理员也不能：它连同单上的费用保留在记录中。

**只有一个人的组织。** 没有人能审批自己提交的报销单，管理员也一样，所以报销单需要另一位能审批它的用户：你的上级、一位财务控制或一位管理员；项目上的报销单则是项目的项目经理或一位管理员。**合计**达到 **2,000** 或以上时，还需要一位财务控制或管理员。在这个人加入之前，提交的报销单停在**已提交**，没有人能决定它：请在待我审批里撤回，等这个人加入后再次提交。

## 报销付款

已批准的报销单列在**财务控制**和**应收会计**的**待付款的报销单**里。钱到了员工手上之后，他们点**标记已付款**，填写付款日期，如有付款参考号也一并填写。HotCRM 只记录这次付款：不会转出任何款项，也不记账。已付款的报销单不能再修改。

## 费用标准 [#expense-standards]

**费用报销**应用里的**费用标准**列出公司的花费标准，一条规定一行：

| 字段 | 内容 |
| --- | --- |
| **名称** | 这条规定，例如「住宿，一线城市」 |
| **类别** | 针对的费用类别；留空表示所有类别 |
| **限额**和**计算单位** | 最多可花多少，使用贵公司的本位币，按每晚、每天、每笔或每次出差计算。只有文字的规定（例如「火车二等座」）没有限额 |
| **适用范围** | 用文字写明适用于谁、哪里，例如「经理及以上」 |
| **说明** | 数字说不清的部分 |
| **启用** | 取消勾选即可停用一条标准，而不必删除 |

有**费用报销**应用的人都能查看全部费用标准。由**财务控制**和**应收会计**维护，管理员也可以。

标准只是参考：HotCRM 从不拿费用和标准比较，超出标准的费用照常保存、照常提交。为你工作的助手查阅标准、进行比较，在你提交之前把发现写进这笔费用的**检查提示**；为审批人工作的助手把发现告诉审批人。由审批人做决定。

## 借助助手 [#with-an-assistant]

有两项技能教助手使用本模块，无论是平台助手，还是你通过 MCP 接入的自己的智能体（见[技能](/zh-Hans/docs/ai-copilot/skills#expense-filing)）：

- **费用代填**（Expense Filing），给花钱的人：它按票据记下费用（**来源**为助手），检查有没有相同票据号、或相同日期、金额和商户的费用，给你一个一次性链接附上票据，并把对照费用标准的发现写进这条费用的**检查提示**。它也可以起草出差申请。**提交报销**、**按出差申请报销**等发送类步骤，要你同意后它才执行。
- **费用检查**（Expense Check），给审批人和财务：它列出报销单里值得一看的地方（超出标准、可能重复、缺少票据、出差超出预计），不改动任何东西。它会给出一段文字，审批人可以放进自己的审批意见；它从不审批、驳回或标记已付。

**标记已付款**不对任何助手开放。智能体可以执行的全部动作见[对智能体开放的动作](/zh-Hans/docs/ai-copilot/agent-actions)。

## 谁能看到什么

你能看到自己的费用和报销单，以及请你审批的报销单。财务在**全部费用**里能看到所有费用，也能看到所有报销单，销售经理和销售管理层也能看到。没有人手工新建报销单：报销单由**提交报销**生成。

## 项目上的费用 [#on-a-project]

启用[项目交付](/zh-Hans/docs/projects)后，费用可以选择一个**项目**。项目人员在项目交付应用的**工时与费用**下也能找到**我的费用**和**待我审批的报销单**。

项目带来三处变化，它们和项目的工时一起，只在[工时与费用](/zh-Hans/docs/projects/time-and-expenses#费用)里讲一次：

- **由谁审批。**提交报销会把每个项目的费用各自放进一张报销单，交给该项目的项目经理审批，而不是你的上级。
- **项目成本。**报销单批准后，单上的费用计入项目成本；标记已付款不会改变这些数字。
- **锁定与项目结束。**项目被锁定、已关闭或已取消时，它的报销单不能提交：提交会当场被拒绝并说明原因，报销单仍是**草稿**。**提交报销**和**按出差申请报销**仍会提交你其他项目的报销单；这次点击以一条写明未提交报销单的错误提示结束。

有一条规则属于报销单本身：

- 费用在报销单上时（哪怕报销单是**草稿**），不能改它的**项目**：报销单按提交时的项目交给审批人。要改项目，先删除这张草稿报销单（费用会被释放），再改项目、重新提交。

关闭项目交付后，费用和报销单上都不显示项目字段，每次勾选只生成一张报销单，所有报销单都交给你的上级审批。费用和报销单原来选的项目会保留，重新启用项目交付后再次显示。

## 从逐笔审批升级

在有报销单之前，每笔费用单独提交、单独审批。**已批准**的费用保持已批准，仍计入所在项目的成本；它不在任何报销单上，因此没有付款记录。已驳回的费用和其他费用一样提交。升级时**正在等待审批**的费用已无法再审批：批准它原来的请求，会提示该审批已无法继续。提交人用**提交报销**把它报上去（提交报销接受不在任何报销单上的已提交或已驳回费用，把它和其他费用一起报销），然后在待我审批里撤回原来的请求，让它从审批人的列表中消失（管理员也可以撤回）。只撤回不提交报销时，费用保持**已提交**。
