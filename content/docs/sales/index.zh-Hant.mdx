# 銷售雲

銷售模組涵蓋完整的**從潛在客戶到回款**旅程。同一筆記錄從首次入站詢問一路流轉到簽署合約，每位團隊成員都能清楚看到每筆交易所處的位置。

## 全局概覽

一筆典型交易看起來是這樣的：

```
Lead  ──►  Account + Contact  ──►  Opportunity  ──►  Quote  ──►  Contract
(prospect)   (qualified)           (active deal)     (proposal)   (signed)
```

你引入潛在客戶、對其進行資格審核、將其轉化為客戶、推動商機走過 7 個銷售階段、發送報價，並最終以合約形式成交。活動（電話、會議、跟進）掛接在每一個步驟上。

| [**客戶**](/zh-Hant/docs/sales/accounts) | 你與之開展業務的公司——潛在客戶、客戶、合作夥伴。 |

| [**銷售管道管理**](/zh-Hant/docs/sales/pipeline-management) | 階段、機率與預測的運作機制。 |
| [**預測**](/zh-Hant/docs/sales/forecasting) | 按負責人與週期的銷售管道快照——配額、承諾金額、最佳情況與達成率。 |

## 系統自動為你完成的事

這些你無需手動操作——HotCRM 會在後台處理：

- **潛在客戶評分**——每筆新潛在客戶都會根據公司規模、產業、職位和互動情況獲得 0-100 的評分。
- **熱門潛在客戶提醒**——評級為 4 星及以上的潛在客戶會將下次跟進日期設為今天並通知負責人。
- **機率更新**——當你將商機移動到新階段時，贏單機率會自動更新（尋找客戶 10% → 成交 100%）。
- **預期營收**——`amount × probability` 會為你計算好。
- **大單通知**——當一筆超過 $100K 的交易被標記為成交時，銷售管理層會收到郵件通知。
- **報價到期**——超過有效期的報價每晚會被自動標記為已過期。
- **折扣審批**——金額超過 $500K 的商機會自動路由給你的銷售經理和總監進行審批。

## Sales Copilot

[銷售技能](/zh-Hant/docs/ai-copilot/sales-copilot) 已內建於平台助手。當你打開一筆潛在客戶、客戶或商機時，它可以：

- 使用 BANT 方法（預算、決策權、需求、時間線）**審核潛在客戶資格**並給出評分。
- **起草外撥郵件**，針對聯絡人進行個人化，並以產品目錄為依據。
- **預測營收**並標記看起來有風險的交易。
- 在你下次會議之前**總結某個客戶**（Customer 360）。

只需在聊天中輸入：*"qualify this lead"*、*"draft a follow-up email"*、*"what's at risk this quarter?"*

## 在哪裡找到這些功能

**Enterprise CRM 應用**的側邊欄將所有內容歸到**銷售**之下：

- 潛在客戶 · 客戶 · 聯絡人 · 商機 · 報價 · 合約
- **銷售管道**（Pipeline）——商機的看板視圖。側邊欄上的 label 就是這個；它打開的那個視圖自身的 label 是**銷售流水線**（Sales Pipeline，`pipeline_kanban`）。
- **銷售業績**（Sales Performance）——你的每日 KPI，來自 `sales_dashboard` 儀表板。沒有任何側邊欄條目叫 *銷售儀表板* / *Sales Dashboard*。

## 從這裡開始

如果你是新手，請按以下順序閱讀：

1. [潛在客戶](/zh-Hant/docs/sales/leads)——每筆交易開始的地方。
2. [商機](/zh-Hant/docs/sales/opportunities)——你每天都要處理的核心記錄。
3. [銷售管道管理](/zh-Hant/docs/sales/pipeline-management)——漏斗是如何被治理的。
4. [報價](/zh-Hant/docs/sales/quotes)——如何發送一份提案。
