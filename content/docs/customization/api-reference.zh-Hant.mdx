# API 參考

本應用未隨附繁體中文語言包，因此本頁出現的介面名詞依固定順序取用：zh-CN 語言包已收錄者，採其用詞的繁體寫法；未收錄者，保留產品內的英文原名，不另造譯名。

HotCRM 執行在 ObjectStack 上。Web UI、自動化、動作和 AI skills 都使用 `objectstack.config.ts` 註冊的同一套物件中繼資料。

## 本機地址

本機執行：

```bash
pnpm dev
```

應用地址：

```text
http://localhost:4001
```

物件 API 由 ObjectStack runtime 提供。路由形態可能隨 runtime 版本和啟用能力變化，因此在環境中可用時，請優先使用 runtime API explorer。

## 目前物件

物件清單在此**不再**轉抄 —— `src/*/objects/*.object.ts` 是它的事實來源，一個物件一個檔案，
各自註冊以 `crm_` 為前綴的 `name`。資料模型涵蓋四個業務領域：銷售、服務、市場和營收。

## ObjectQL 形態

在 actions、flows、hooks 和整合中呼叫 ObjectStack 資料層時，使用 ObjectQL 風格的過濾和欄位選擇。

```json
{
  "filters": [
    ["stage", "in", ["proposal", "negotiation"]],
    ["amount", ">", 100000]
  ],
  "sort": [{ "field": "amount", "direction": "desc" }],
  "limit": 50,
  "fields": ["id", "name", "amount", "stage", "crm_account"]
}
```

常用操作符包括 `=`, `!=`, `>`, `>=`, `<`, `<=`, `in`, `not_in`, `between`, `contains`, `starts_with`, `ends_with`, `is_null`, `is_not_null`。

## 動作體

HotCRM actions 可以包含帶受限能力的可執行中繼資料體。

```ts
export const MarkPrimaryContactAction = {
  name: 'mark_primary',
  objectName: 'crm_contact',
  type: 'script',
  body: {
    language: 'js',
    capabilities: ['api.write'],
    source: `
      const id = ctx.recordId;
      await ctx.api.object('crm_contact').update({ id, is_primary: true }, { where: { id } });
      return { ok: true, id, is_primary: true };
    `,
  },
};
```

動作體以系統權限執行。凡是代表呼叫者寫入、應由呼叫者自己的權限來決定的動作，都不寫成動作體：**Add to Campaign**（`create_campaign`、`add_contact_to_campaign`）是一個流程動作，它呼叫的流程以呼叫者身分執行；**Mark Responded**（`mark_responded`）是一個宣告式更新。Add to Campaign 以 `campaignId` 接收行銷活動，回傳該流程的結果：新加入的成員 `output.enrolled` 為 `true`，已在該活動中的人為 `false`。

## 驗證

修改面向 API 的中繼資料後執行：

```bash
pnpm validate
pnpm typecheck
pnpm test
```

發布前執行 `pnpm verify`。
