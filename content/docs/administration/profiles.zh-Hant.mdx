# 權限設定檔

**權限設定檔** 是指派給使用者的權限集合。它控制使用者在整個 CRM 中能檢視、編輯、刪除和設定的內容。每個使用者都恰好擁有一個權限設定檔。

## 六種內建權限設定檔

| 權限設定檔 | 面向 | 典型使用者 |
| --- | --- | --- |
| 👑 **System Administrator** | CRM 管理員 | IT、營運、實施負責人 |
| 👔 **Executive** | C 級高管 | CEO、CRO、銷售/服務副總裁 |
| 💼 **Sales User** | 銷售代表 | AE、SDR、BDR |
| 🎧 **Service User** | 服務專員 | 支援專員、成功經理 |
| 📣 **Marketing User** | 行銷人員 | 需求生成、活動經理 |
| 👀 **Read Only** | 稽核員、觀察者 | 財務審查員、外包人員 |

## 每種權限設定檔能做什麼

### 👑 System Administrator

- 對 **所有** 物件擁有完整的讀/寫/刪除權限
- 可以設定 **一切**：物件、欄位、權限設定檔、共用、自動化、AI 技能
- 可以模擬其他使用者（用於支援 / 除錯）
- 繞過共用規則和欄位級安全

⚠️ **謹慎使用** —— 通常每個組織 2–3 人。

### 👔 Executive

- 對所有 CRM 物件擁有完整 **讀取** 權限（涵蓋全公司）
- 僅對自己擁有或所屬團隊的記錄有 **編輯** 權限
- 存取所有 **儀表板** 和 **報表**，包括高管記分卡
- 不能刪除記錄
- 不能設定系統

為 *「看到一切，不改任何東西」* 的領導層設計。

### 💼 Sales User

- 對自己擁有或所屬團隊的 **客戶** 擁有完整讀/寫權限
- 對與其客戶關聯的 **聯絡人**、**商機**、**報價**、**合約** 擁有完整讀/寫權限
- 對自己擁有的 **潛在客戶** 擁有完整讀/寫權限
- 讀/寫 **任務** 和 **事件**
- **提交審批**（例如折扣審批）
- 對 **產品**（目錄）擁有讀取權限
- 不能刪除記錄（經理權限）
- 無設定存取權限

### 🎧 Service User

- 對其佇列中或指派給自己的 **案例** 擁有完整讀/寫權限
- 對與這些案例關聯的 **客戶**、**聯絡人**、**合約** 擁有完整讀取權限
- 對 **知識庫** 文章擁有讀/寫權限（受 KB 工作流約束）
- 對 **產品** 擁有讀取權限
- 對與客戶關聯的 **商機** 擁有讀取權限（用於了解背景）
- 無設定存取權限

### 📣 Marketing User

- 對 **活動** 和 **活動成員** 擁有完整讀/寫權限
- 對 **潛在客戶**（尤其是無所有者的）擁有完整讀/寫權限
- 對 **聯絡人**、**客戶**、**商機** 擁有讀取權限（用於 ROI 分析）
- 對 **銷售知識** 和 **競爭情報** 知識庫擁有讀/寫權限
- 無設定存取權限

### 👀 Read Only

- 對 **所有** 標準物件擁有讀取權限
- 無編輯、刪除或建立權限
- 對儀表板和報表擁有讀取權限
- 無匯出權限（可設定）

## 指派權限設定檔

1. 前往 **設定 → 使用者**。
2. 開啟使用者記錄。
3. 從下拉選單中選擇 **權限設定檔**。
4. 儲存 —— 變更立即生效。

一個使用者一次只能擁有 **一個權限設定檔**。要在其基礎權限設定檔之上授予額外權限，請使用 **權限集**（即 *「額外帽子」* 機制）。

## 複製權限設定檔

如果某個內建權限設定檔 *幾乎* 合適但需要微調：

1. **設定 → 權限設定檔**。
2. 開啟該權限設定檔並點擊 **複製**。
3. 重新命名（例如 *「高級銷售代表」*）。
4. 調整權限。
5. 儲存並指派給使用者。

⚠️ **不要修改內建權限設定檔** —— 複製它們。HotCRM 的更新可能會重置內建權限設定檔的設定。

## 權限設定檔裡有什麼

每個權限設定檔控制：

| 權限領域 | 控制項 |
| --- | --- |
| **物件權限** | 對每個物件的讀取、建立、編輯、刪除 |
| **欄位級安全** | 每個欄位的可見性和讀取/編輯 |
| **應用存取** | 使用者可以開啟哪些應用（Enterprise CRM、Admin 等） |
| **系統權限** | 特殊能力（批量編輯、匯出、檢視所有資料、修改所有資料） |
| **AI 權限** | 使用者可以呼叫哪些 AI 技能 |
| **審批權限** | 提交、批准、撤回 |

## 權限設定檔 vs 角色 vs 共用 —— 有什麼區別？

這會讓新管理員犯迷糊。簡短的答案：

- **權限設定檔** = *你能做什麼*（動詞：建立、編輯、刪除、提交審批）。
- **角色** = *你在階層中的位置*（決定你能看到誰的記錄）。
- **共用規則** = *例外情況*（例如「即便不在角色階層中，EU 中的每個人都能看到 EU 客戶」）。

一個銷售代表擁有 **Sales User 權限設定檔**（讓其能編輯商機）以及一個像 *AE - East* 這樣的 **角色**（控制 *誰的* 商機）。兩者都必須允許存取，他們才能看到 + 編輯某條記錄。

關於角色 + 共用這一面，參見 [共用與安全](/zh-Hant/docs/administration/sharing-and-security)。

## 給管理員的提示

- ✅ **從內建權限設定檔開始** —— 除非必要，否則不要自訂。
- ✅ 拿不準時，**複製** 而非修改。
- ✅ 對於一次性授權（「Sarah 在第三季度需要匯出權限」），使用 **權限集** 而非建立新的權限設定檔。
- ✅ **每季度稽核權限設定檔** —— 當人們換崗位時，他們的權限設定檔往往沒變。
- ✅ 將 System Administrator 限制在 **最多 2–3 人** —— 這是通往王國的鑰匙。

## 給使用者的提示

如果你無法做某件你認為自己應該能做的事：

1. 檢查你的權限設定檔（右上角 → 你的名字 → 權限設定檔）。
2. 詢問管理員你的權限設定檔對你的崗位是否正確。
3. 如果權限設定檔正確但你仍然看不到某條特定記錄，那是一個 [共用](/zh-Hant/docs/administration/sharing-and-security) 問題，而非權限設定檔問題。
