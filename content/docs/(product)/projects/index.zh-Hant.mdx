# 項目交付

項目交付回答的是交付團隊在贏單之後關心的問題：**誰在做這個項目，到目前為止花了多少錢，預算還剩多少，項目還賺不賺錢？**它是 HotCRM 的一個模組，有自己的應用 **Project Delivery**，項目經理、顧問和財務在這裡工作。

## 包含哪些紀錄

| 紀錄 | 是什麼 | 誰來填寫 |
| --- | --- | --- |
| **Project**（項目） | 為客戶做的一次項目：售前、交付或內部工作 | 項目經理 |
| **Project Member**（項目成員） | 投入某個項目的一個人，以及他的職責和費率卡 | 該項目的項目經理 |
| **Rate Card**（費率卡） | 一個工作職級，帶有按小時或按天的成本單價和計費單價 | 財務、項目管理辦公室 |
| **Timesheet**（工時單） | 一個人在一個項目上某個期間（例如一週）的工時 | 工作的本人 |
| **Time Entry**（工時明細） | 工時單上某一天的工時 | 工作的本人 |
| **Expense**（費用） | 一個人為項目花的錢：差旅、住宿、餐飲。費用報銷是獨立的模組（[費用報銷](/zh-Hant/docs/expenses)），項目交付為它加上項目 | 花錢的本人 |

項目掛在**客戶**下面，還可以寫明它來自哪個**商機**、交付哪份**合約**或哪張銷售**訂單**。打開客戶、商機、合約或訂單，**Projects** 分頁會列出相關項目。

| 頁面 | 內容 |
| --- | --- |
| [項目與人員安排](./projects-and-staffing) | 新建項目、項目類型和狀態、按費率卡安排人員、預算 |
| [項目預算](./budgets) | 按版本和明細編製預算、隨項目一起審批、用追加預算調整 |
| [工時與費用](./time-and-expenses) | 填報工時和費用、提交與審批、成本怎麼計算 |

## 在哪裡找到

| 誰 | 在哪裡 |
| --- | --- |
| 項目經理、項目成員、財務控制 | **Project Delivery** 應用：**Projects** 群組下的 **All Projects**、**My Projects** 和 **Staffing**；**Time and Expenses** 群組下的 **My Timesheets**、**My Expenses**、**Timesheets to Approve** 和 **Reports to Approve**；**Rates** 群組下的 **Rate Cards**；項目所屬的 **Accounts**、**Opportunities** 和 **Contracts**；以及 **My Work** 群組下的 **Inbox**，項目、工時單和費用都在這裡審批。 |
| 銷售經理 | 啟動器上有 Project Delivery 應用，並且可以查看每個項目，從而了解團隊贏下的單子交付得怎麼樣。 |
| 銷售代表、服務、行銷、應收會計 | 啟動器上沒有。 |
| 管理員 | 全部可見。 |

啟動器決定的是提供哪些應用，而不是能打開哪些：啟動器上沒有的應用，用位址照樣能打開；每筆紀錄的存取權限仍由它的共用規則決定。

## 誰能做什麼

項目是私有的。一個人能查看某個項目，是因為他是項目負責人、被安排在這個項目上，或者是它的項目經理；項目經理還可以編輯項目。財務和交付管理層可以查看每個項目。

| 人員 | 項目 | 人員安排 | 費率卡 | 工時與費用 |
| --- | --- | --- | --- | --- |
| 項目成員 | 查看自己參與的項目，**看不到成本和毛利** | 查看 | 查看，**看不到成本單價** | 填報自己的 |
| 項目經理 | 新建項目；編輯自己負責的項目 | 為自己負責的項目安排人員 | 查看 | 填報自己的；審批團隊的 |
| 財務控制 | 查看每個項目和預算；審批 100,000 及以上的項目和增幅 10% 及以上的追加預算 | 查看 | 新建和編輯 | 查看全部；審批合計 2,000 及以上的報銷單 |
| 項目總監、項目管理辦公室 | 兼有以上兩者；審批新項目 | 兼有 | 兼有 | 兼有 |
| 銷售經理 | 查看每個項目 | 查看 | — | 查看全部 |
| 管理員 | 全部 | 全部 | 全部 | 全部 |

管理員在 **Setup → Position Holders** 中用**職位**給人員授權：**Project Team Member**、**Project Manager**、**Finance Controller**、**Project Director** 或 **PMO**。

> **項目成員永遠看不到同事的成本。**成本單價、每筆工時明細的成本、工時單的總成本，以及項目的成本和毛利，對 Project Team Member 職位都是隱藏的。他們能看到工時、計費單價和可計費金額。

> **項目成員看得到客戶，看不到商機。**Project Team Member 職位可以唯讀檢視全部客戶，所以項目上的**客戶**會顯示名稱；客戶的 **Invoiced**、**Received**、**Unpaid** 和 **Uninvoiced** 對他們隱藏。商機仍對他們關閉：他們的項目頁上不顯示**商機**和**訂單**欄位，也打不開項目的商機，**Project Delivery** 選單裡也沒有**商機**入口。

## 項目上的金額 [#money]

項目上只有 **Planned Revenue**（計劃收入）是手工填寫的，其餘數字都隨工時、費用或預算版本的批准自動變化：

| 欄位 | 統計什麼 |
| --- | --- |
| **Approved Budget**（批准預算） | 項目基線[預算版本](./budgets)的合計 |
| **Labor Cost**（人工成本） | 項目上 **Approved** 工時單的工時成本 |
| **Expense Cost**（費用成本） | 項目上 **Approved** 的費用 |
| **Actual Cost**（實際成本） | 人工成本加費用成本 |
| **Budget Remaining**（剩餘預算） | 批准預算減實際成本 |
| **Budget Used %**（預算使用率） | 實際成本佔批准預算的百分比 |
| **Gross Margin**（毛利） | 計劃收入減實際成本 |
| **Gross Margin %**（毛利率） | 毛利佔計劃收入的百分比 |
| **Approved to Bill**（已批准待開票） | 已批准的可計費工時按計費單價計算的金額，加上已批准的可計費費用 |
| **Budget Status**（預算狀態） | On Track；達到批准預算的 80% 為 Warning，達到 100% 為 Exceeded。進入其中任一狀態都會通知項目經理和財務 |

金額使用貴公司的本位幣。項目只產出 **Approved to Bill** 這個數字：給客戶開票在[訂單與回款](/zh-Hant/docs/order-to-cash)中完成。

## 不是每個客戶都用

不做項目的公司，可以由管理員停用這個模組。它的應用、紀錄，以及客戶、商機、合約和訂單上的 Projects 分頁都會隨之消失；訂單頁面本身不受影響。
