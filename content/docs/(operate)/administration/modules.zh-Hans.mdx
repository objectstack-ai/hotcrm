# 启用和停用模块

HotCRM 作为一个产品发布：核心的**销售**应用，加上六个模块。不用某个模块的公司可以把它关掉，需要时再打开。不会卸载任何东西，也不会删除任何东西。

| 模块 | 在软件包列表里的名称 | 它带来什么 |
| --- | --- | --- |
| 服务 | **HotCRM Service** | **服务**应用：工单、SLA、知识库 |
| 产品与报价 | **HotCRM Revenue** | 产品、价格表和报价单，位于**销售**应用内 |
| 营销 | **HotCRM Marketing** | **营销**应用：营销活动及其成员 |
| 订单与回款 | **HotCRM Order to Cash** | **订单与回款**应用：回款计划、发票、回款 |
| 费用报销 | **HotCRM Expenses** | **费用报销**应用：费用、报销单、出差申请 |
| 项目交付 | **HotCRM Project Delivery** | **项目交付**应用：项目、人员安排、预算、工时单 |

客户、联系人、线索、商机、合同、订单和任务属于核心，始终开启。

## 关闭或打开一个模块

开关在**软件包**页面上，那是平台列出全部已安装内容的清单。在 ObjectStack 18.6.0 上，系统设置菜单和 Studio 里都没有通向这个页面的入口（[objectstack#35196](https://github.com/objectstack-ai/objectstack/issues/35196)）。**系统设置 → 已安装应用**打开的列表只包含从应用市场安装的应用，也没有放宽筛选的控件。HotCRM 从代码加载时（软件包页面的**来源**列显示**代码**），那个列表是空的。

管理员打开 `/_console/apps/com.objectstack.setup/component/developer/packages`，即标题为**软件包**的页面，打开模块，选择**禁用**并确认。模块的**状态**随即显示**已禁用**；在同一个面板上选择**启用**即重新打开。脚本可以用同一个开关：`PATCH /api/v1/packages/<id>/disable`（以及 `/enable`），id 为 `app.objectstack.hotcrm.<模块>`：`service`、`revenue`、`marketing`、`o2c`、`expense` 或 `psa`。

开关立即生效，对所有人生效，管理员也不例外。

## 模块关闭期间什么会消失

在 ObjectStack 18.6.0 上用演示数据逐个模块实测：

- **它的应用**从应用启动器上消失。即服务、营销、订单与回款、费用报销或项目交付应用；产品与报价没有自己的应用。
- **它的记录**无法打开或列出。请求其中一条会返回 `404 OBJECT_PACKAGE_DISABLED`。平台的 REST 搜索仍会返回这些记录（[objectstack#35195](https://github.com/objectstack-ai/objectstack/issues/35195)）。
- **它放在其它应用里的侧边栏条目**也会消失：

  | 关闭的模块 | 从其它应用消失的条目 |
  | --- | --- |
  | 服务 | **销售**里销售代表专用的**知识库** |
  | 产品与报价 | **销售**里的**报价**、**产品**、**价格表**、**产品目录**和**收入手册** |
  | 订单与回款 | **销售**里的**回款计划**分组（**回款计划**）和**订单与回款手册** |
  | 费用报销 | **项目交付**里的**我的费用**、**待我审批的报销单**和**我的出差申请** |

- **它的按钮**会消失，包括它放在核心记录上的按钮：产品与报价关闭时，商机上的**生成报价单**；营销关闭时，线索和联系人上的**加入营销活动**。
- **它加到其它记录上的字段**会从那些记录上消失：

  | 关闭的模块 | 消失的字段 |
  | --- | --- |
  | 订单与回款 | 合同上的**计划回款**、**已开票**、**已回款**和**应收余额**；客户上的**已开票**、**已回款**和**应收余额** |
  | 项目交付 | 费用、报销单和出差申请上的**项目** |

  项目交付关闭时，显示**项目**列的费用报销列表照常打开，只是没有这一列，列表上方有一行说明原因：“未显示 crm_project，也未按其筛选、排序或分组：添加该字段的软件包已停用，启用后即恢复。”这行字用字段的 API 名称来称呼它；`crm_project` 就是**项目**列。

## 什么会保留

- **记录。**关闭模块不会删除任何东西。重新打开后，它的记录、应用、条目、按钮和字段原样回来。
- **核心记录上指向该模块的字段**会保留，值也保留。营销关闭期间，商机的**营销活动**仍然写着原来的营销活动，商机照样可以编辑；在营销重新打开之前，选择框找不到新的营销活动。服务关闭时，任务上的关联工单也是如此。
- **另一个模块存下的内容。**项目交付关闭时，费用仍保留它写明的项目，项目交付重新打开后再次显示。费用报销关闭时，项目保留最后一次统计的费用成本；费用报销重新打开后才会继续变化。

## 互相依赖的模块

项目交付会用到费用报销：项目的费用成本来自已批准的报销单。平台不会阻止你在项目交付开启时关闭费用报销。项目仍可打开、列出和编辑，只是它们的费用数字停止变化，直到费用报销重新打开。

项目交付关闭、费用报销开启时，费用照常记录和提交，只是不带项目：每次勾选只生成一张报销单，所有报销单都交给报销人的上级审批。
