## 前置条件

- Node.js 20+
- pnpm 10+
- 已克隆 `objectstack-ai/hotcrm`

## 本地运行

```bash
git clone https://github.com/objectstack-ai/hotcrm.git
cd hotcrm
pnpm install
pnpm dev
```

打开 http://localhost:4001。应用会在首次启动时加载种子数据。

## 仓库结构

HotCRM 构建出**一个** ObjectStack 制品，里面装着**七个包**（ADR-0130）：`src/sales/` 里的 `type: app` 包 `app.objectstack.hotcrm`，以及六个模块：`src/service/` 里的服务、`src/revenue/` 里的收入（产品和报价）、`src/marketing/` 里的营销、`src/o2c/` 里的订单与回款、`src/expense/` 里的费用和 `src/psa/` 里的项目交付。每个包各有一个 `index.ts`，各自调用 `defineStack()`；`objectstack.composition.ts` 构建这些包，`objectstack.config.ts` 把它们组合成制品。`src/` 下的一个目录就是一个包。每一项都由其所在目录的包注册：应用包的动作启动模块的流程、应用包的仪表盘磁贴绑定模块的数据集，都在制品内跨包解析。一个文件只能从自己的目录或 `src/sales/` 导入，模块之间不得横向导入；唯一的例外是项目交付，它建立在费用之上。

```text
hotcrm/
├── objectstack.config.ts
├── objectstack.composition.ts
├── src/
│   ├── sales/          # `type: app` 包 —— 客户、联系人、线索、商机、合同、订单、任务、活动
│   ├── service/        # 模块 —— 工单和知识库
│   ├── revenue/        # 模块 —— 产品、价格表、报价
│   ├── marketing/      # 模块 —— 营销活动及其成员
│   ├── o2c/            # 模块 —— 回款计划、发票、回款
│   ├── expense/        # 模块 —— 费用、报销单、出差申请
│   ├── psa/            # 模块 —— 项目、人员安排、预算、工时
│   └── docs/           # 随构建产物一起分发的应用文档
├── apps/docs/          # Fumadocs 应用
└── content/docs/       # 文档内容
```

每个包内是它用到的元数据类型子目录，后缀协议在每个包内都一样：

```text
src/sales/
├── objects/            # *.object.ts 模型，以及紧挨着各自模型的 *.hook.ts
├── actions/            # UI 动作和可执行动作体
├── flows/              # 自动化流程
├── skills/             # AI skills
├── apps/, views/, pages/
├── dashboards/, reports/, datasets/
├── mappings/           # 数据导入的列到字段映射
├── profiles/, sharing/
├── translations/
├── data/               # 种子数据
└── interfaces/         # 共享类型（目前是空 barrel）
```

HotCRM 只定义 skills，不定义 agent：应用自带的两个 copilot 及其所在目录已被移除。skill 在环境运行平台助手时附着到它上面；任何通过 MCP 接入的智能体，都在同样的对象和动作上工作。参见 [AI Skills](/zh-Hans/docs/developers/ai-skills) 和 [AI 与智能体](/zh-Hans/docs/ai-copilot/index)。

## 文件后缀协议

| 后缀 | 定义 |
| --- | --- |
| `*.object.ts` | 数据模型 |
| `*.hook.ts` | 服务端生命周期逻辑 |
| `*.actions.ts` | UI 动作和 AI 可调用动作体 |
| `*.flow.ts` | 自动化 |
| `*.skill.ts` | AI skill |
| `*.page.ts` | UI 页面 |
| `*.view.ts` | 列表或看板视图 |
| `*.dashboard.ts` | 仪表盘 |
| `*.report.ts` | 报表 |
| `*.sharing.ts` | 共享规则 |
| `*.profile.ts` | 权限档案 |

## 常见任务

### 新增或修改对象

在 `src/*/objects/` 下编辑或新增文件，然后从 `src/*/objects/index.ts` 导出。

```ts
import { ObjectSchema, Field } from '@objectstack/spec/data';

export const Warranty = ObjectSchema.create({
  name: 'crm_warranty',
  label: 'Warranty',
  fields: {
    name: Field.text({ label: 'Warranty Name', required: true }),
    crm_account: Field.lookup('crm_account', { label: 'Account' }),
  },
});
```

### 新增 AI skill

创建 `src/*/skills/<name>.skill.ts`，并从 `src/*/skills/index.ts` 导出。从这个 barrel 导出就是全部的接线工作——skill 会附着到平台助手（`ask`）上，本应用不定义任何自己的 agent。

### 新增 UI 元数据

使用 `src/*/views/` 定义列表和看板视图，使用 `src/*/pages/` 定义记录页面，使用 `src/*/actions/` 定义按钮和弹窗动作。

## 基本规则

- HotCRM 的对象名使用 `crm_` 前缀。
- 使用 ObjectQL 和 ObjectStack API，不写原生 SQL。
- 元数据从相应的 `src/**/index.ts` 导出。
- 新增用户可见的标签时同步更新翻译。
- 发布前运行 `pnpm verify`。

## 验证改动

```bash

```
