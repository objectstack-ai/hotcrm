# 面向開發者

本頁面面向使用 HotCRM 原始碼倉庫的工程師。

## 前置條件

- Node.js 20+
- pnpm 10+
- 已克隆 `objectstack-ai/hotcrm`

## 本機執行

```bash
git clone https://github.com/objectstack-ai/hotcrm.git
cd hotcrm
pnpm install
pnpm dev
```

打開 http://localhost:4001。應用會在首次啟動時載入種子資料。

## 倉庫結構

HotCRM 是一個單體 ObjectStack 應用。`objectstack.config.ts` 是註冊 `src/` 中全部中繼資料的唯一事實來源。

```text
hotcrm/
├── objectstack.config.ts
├── src/
│   ├── objects/        # *.object.ts 和物件生命週期 hooks
│   ├── actions/        # UI 動作和可執行動作體
│   ├── flows/          # 自動化流程
│   ├── agents/         # AI agents
│   ├── skills/         # AI skills
│   ├── apps/, views/, pages/
│   ├── dashboards/, reports/, cubes/
│   ├── profiles/, sharing/
│   ├── translations/
│   └── data/
├── apps/docs/          # Fumadocs 應用
└── content/docs/       # 文件內容
```

## 檔案後綴協議

| 後綴 | 定義 |
| --- | --- |
| `*.object.ts` | 資料模型 |
| `*.hook.ts` | 服務端生命週期邏輯 |
| `*.actions.ts` | UI 動作和 AI 可呼叫動作體 |
| `*.flow.ts` | 自動化 |
| `*.skill.ts` | AI skill |
| `*.agent.ts` | AI agent |
| `*.page.ts` | UI 頁面 |
| `*.view.ts` | 清單或看板視圖 |
| `*.dashboard.ts` | 儀表板 |
| `*.report.ts` | 報表 |
| `*.sharing.ts` | 共享規則 |
| `*.profile.ts` | 權限設定檔 |

## 常見任務

### 新增或修改物件

在 `src/objects/` 下編輯或新增檔案，然後從 `src/objects/index.ts` 匯出。

```ts
import { ObjectSchema, Field } from '@objectstack/spec/data';

export const Warranty = ObjectSchema.create({
  name: 'crm_warranty',
  label: 'Warranty',
  fields: {
    name: Field.text({ label: 'Warranty Name', required: true }),
    crm_account: Field.lookup('crm_account', { label: 'Account' }),
  },
});
```

### 新增 AI skill

建立 `src/skills/<name>.skill.ts`，從 `src/skills/index.ts` 匯出，並把 skill 名稱加入 `src/agents/` 中對應的 agent。

### 新增 UI 中繼資料

使用 `src/views/` 定義清單和看板視圖，使用 `src/pages/` 定義記錄頁面，使用 `src/actions/` 定義按鈕和彈窗動作。
