# HotCRM Deployment

> Current deployment notes for the single ObjectStack marketplace app.

## Local Development

Install dependencies and start the ObjectStack runtime:

```bash
pnpm install
pnpm dev
```

The local server runs on <http://localhost:4001>.

Useful commands:

```bash
pnpm validate
pnpm typecheck
pnpm build
pnpm test
```

## Build Artifact

HotCRM is published as an ObjectStack package artifact generated by:

```bash
pnpm build
```

The build command runs `objectstack build` and produces the compiled artifact consumed by ObjectStack package publishing. Treat [`objectstack.config.ts`](../objectstack.config.ts) and `src/` as source, and the generated artifact as the deployable output.

## Local Production Start

To run the app with the production-style ObjectStack start command:

```bash
pnpm build
pnpm start
```

The configured `start` script runs ObjectStack on port `4001`.

## Reset Demo Data

For a clean local demo database:

```bash
pnpm demo:reset
pnpm dev
```

This removes `.objectstack/data`, rebuilds the app, and lets seed data load on first boot.

## Marketplace Deployment

The normal distribution path is the ObjectStack marketplace:

```bash
objectstack cloud login
pnpm build
pnpm publish:marketplace
```

For a dry run:

```bash
pnpm publish:marketplace:dry-run
```

The publish script lives at [`scripts/publish-marketplace.mjs`](../scripts/publish-marketplace.mjs).

## Runtime Configuration

| Setting | Current source |
| --- | --- |
| App id | `objectstack.config.ts` manifest id |
| App version | `package.json` and `objectstack.config.ts` |
| Capabilities | `requires` in `objectstack.config.ts` |
| Local dev port | `package.json` scripts |
| Seed data | `src/data/index.ts` |

## Verification Before Release

Run:

```bash
pnpm verify
```

The script currently chains:

```text
pnpm validate && pnpm typecheck && pnpm build && pnpm test
```

If `pnpm verify` fails, fix the first failing stage before publishing.
