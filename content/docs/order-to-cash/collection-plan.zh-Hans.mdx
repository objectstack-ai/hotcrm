# 回款计划

合同的**回款计划**由一组**回款节点**组成：每个节点写明销售预计在哪一天收多少钱。一笔软件交易可能是预付款 30%、上线 40%、验收 25%，一年后再收 5% 质保金；订阅则每个计费周期一个节点。

回款计划属于销售。财务的发票和回款会对照它统计，但从不修改它。

## 制定回款计划 [#building-the-plan]

在合同上打开**回款节点**标签页，为付款安排的每一部分添加一个节点：

| 字段 | 填写什么 |
| --- | --- |
| **节点名称** | 合同里这一步的说法：「预付款 30%」「上线」「第二年」 |
| **计划金额** | 这一步应收多少 |
| **计划日期** | 预计哪天收到 |
| **验收日期** | 按验收付款的节点：客户签字验收的日期。由你记录，系统不会代填 |
| **备注** | 团队需要知道的其他信息 |

保存时，节点的**客户**会从合同带入。

只要你能编辑合同所属的客户，就能在该合同上添加、修改或删除回款节点。合同变更后，请相应修订回款计划：回款计划是预测，从来不是账本。

## 数字统计什么 [#figures]

每个节点显示三个数字。它们不需要你填写，而是跟随财务的记录变化。

| 数字 | 统计什么 |
| --- | --- |
| **已开票** | 财务关联到这个节点的**已开具**发票的金额。已作废的发票不计入。 |
| **已回款** | 计入这个节点的回款：财务直接关联到它的回款（开票前收到的预付款），以及针对这个节点的发票收到的回款。 |
| **未回款** | **计划金额**减去**已回款**。收到的比计划多时会小于零。 |

针对发票收到的回款会自动计入这张发票所属的节点，财务只需关联发票。如果财务之后把发票改到另一个节点，已记录的回款保留原来的节点；在这样的回款上重新选择一次发票，它也会随之改过去。

## 本月计划回款 [#planned-this-month]

**订单与回款 → 回款计划**下的**本月计划回款**列表，按日期先后列出你能看到的、**计划日期**在当前自然月内的所有节点，以及目前已开票和已回款的金额。它随日历变化：每月 1 日起显示新的月份。
