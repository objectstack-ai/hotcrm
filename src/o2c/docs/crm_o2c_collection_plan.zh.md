# 回款计划——合同签订后销售看到什么

写给销售代表和销售经理。「订单与回款」在每份合同上显示：开票了没有、回款了没有、哪些已经逾期。财务在别处记账，并把发票和回款记录到这里；销售维护的只有一样东西——合同的**回款计划**，即一组**回款节点**。

## 谁可以修改回款计划

只要你能编辑合同所属的客户，就能添加、修改和删除该合同的回款节点。能查看合同的人都能查看它的回款节点。财务可以查看，但从不修改。

## 数字统计什么

| 数字 | 统计什么 |
| --- | --- |
| **已开票** | 关联到该节点、状态为**已开具**的发票。已作废的发票不计入。 |
| **已回款** | 关联到该节点的回款：财务直接关联的，以及针对该节点发票的每一笔回款。 |
| **未回款** | **计划金额**减去**已回款**。小于零表示收到的比计划多。 |

这些数字都不用填写：财务保存发票或回款时，它们随之变化。针对发票的回款会自动带上发票的回款节点。如果财务之后把发票改到另一个节点，已记录的回款保留原来的节点，直到在这些回款上重新选择一次发票。

**验收日期**是客户签字验收这个节点的日期。由人记录，系统不会代填。

## 本月计划回款

**订单与回款 → 回款计划 → 本月计划回款**列出**计划日期**在当前自然月内的回款节点。每月 1 日起切换到新的月份。
