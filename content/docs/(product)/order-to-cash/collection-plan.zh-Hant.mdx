# 回款計劃

本應用未隨附繁體中文語言包，因此本頁出現的介面名詞依固定順序取用：zh-CN 語言包已收錄者，採其用詞的繁體寫法；未收錄者，保留產品內的英文原名，不另造譯名。

一筆交易的回款計劃由若干條**回款計劃**（**Payment Plan**）紀錄組成，每條是計劃中的一個節點：它寫明業務預計在哪一天收多少錢。回款計劃做在**訂單**（**Order**）上；交易沒有訂單時，做在**合約**上。一筆軟體交易可能是預付款 30%、上線 40%、驗收 25%，一年後再收 5% 保留款；訂閱則每個計費週期一個節點。回款計劃屬於客戶，所以客戶頁面會列出它所有訂單和合約的回款計劃。

回款計劃屬於業務。財務的回款會對照它統計，但從不修改它；發票與它並行，填的是訂單或合約。

## 制定回款計劃 [#building-the-plan]

在訂單上打開 **Payment Plans** 分頁，為付款安排的每一部分新增一個節點；沒有訂單的交易，在合約上同樣操作。節點總要寫明它的訂單或合約：兩者都沒有的節點會被拒絕。

**一筆交易的回款計劃只放在一個地方：有訂單時放在訂單上，沒有訂單時才放在合約上。** 系統不會攔著你在另一筆紀錄上為同一筆交易再做一份計劃，所以請只做一份：否則兩個頁面會各顯示一份計劃。

| 欄位 | 填寫什麼 |
| --- | --- |
| **Milestone** | 合約裡這一步的說法：「預付款 30%」「上線」「第二年」 |
| **Planned Amount** | 這一步應收多少 |
| **Planned Date** | 預計哪天收到 |
| **Accepted Date** | 按驗收付款的節點：客戶簽字驗收的日期。由你記錄，系統不會代填 |
| **Notes** | 團隊需要知道的其他資訊 |

選擇 **Order** 或 **Contract** 會帶出節點的 **Account**。選擇另一個客戶的訂單或合約會被拒絕，並寫明是哪一個。訂單歸在某份合約（框架合約或訂閱合約）下時，節點也會帶上這份合約，所以訂單頁面顯示它自己的計劃，合約頁面彙總它所有訂單的計劃，每個節點只計一次。填了訂單、卻填了另一份合約的節點會被拒絕；訂單和合約屬於不同客戶時也會被拒絕。

業務代表、業務經理和管理員，只要能查看這個客戶，就能在它上面新增、修改或刪除回款計劃，不需要能編輯客戶或合約。財務可以查看回款計劃，但從不修改。合約變更後，請相應修訂回款計劃：回款計劃是預測，從來不是帳本。

## 訂單確認時產生的節點 [#confirmed-order]

訂單變為 **Confirmed**、而且還沒有回款計劃時，HotCRM 會新增一個節點：金額是訂單的 **Total Price**，計劃日期是今天加上訂單的 **Payment Terms**（Net 15、30、60 或 90 天；Due on Receipt 或沒填付款條款時為今天）。已經有回款計劃的訂單不會再產生，再次確認也不會再產生。分期由你自己安排：修改這個節點的金額，再新增其他節點。

訂單的總金額之後有變化時，如果這個節點是訂單唯一的節點，並且還沒有收到任何回款，它會跟著改成新的總金額。否則回款計劃保持不變；只要訂單已有的節點合計不等於總金額，訂單上就顯示 **Payment Plan Differs**：請修改、拆分或新增節點，直到合計相等。

## 數字統計什麼 [#figures]

每個節點顯示兩個數字。它們不需要你填寫，而是跟隨財務的回款變化。

| 數字 | 統計什麼 |
| --- | --- |
| **Received** | 填了這個節點的回款。 |
| **Open** | **Planned Amount** 減去 **Received**。收到的比計劃多時會小於零。 |

**Open** 儲存在節點上，所以任何回款計劃清單都可以按它篩選和排序。

## 本月計劃回款 [#planned-this-month]

**本月計劃回款**清單（Order to Cash 應用的 **Follow-up → Planned This Month**，也是 **Payment Plans** 清單上的一個分頁，即 **Sales** 應用的 **Collection Plan → Payment Plans**），按日期先後列出你能看到的、**Planned Date** 在目前自然月內的所有節點，以及目前已回款的金額。它隨日曆變化：每月 1 日起顯示新的月份。

## 逾期回款計劃 [#overdue]

**逾期回款計劃**清單（Order to Cash 應用的 **Follow-up → Overdue Payment Plans**，也是 **Payment Plans** 清單上的一個分頁），按日期先後列出你能看到的、**Planned Date** 早於今天且仍有 **Open** 金額的所有節點，最早的排在前面。回款付清這個節點的當天，它就離開清單。
