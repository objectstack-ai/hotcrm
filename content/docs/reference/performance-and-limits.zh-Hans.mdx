# 性能与限制

以下限制为**默认企业版套餐**。其他套餐有所不同；自托管没有平台施加的上限，但瓶颈会转移到你的基础设施上。

| 项目 | 限制 |
| --- | --- |
| 单文件上传 | **2 GB** |
| 每条记录的附件 | 无限制 |
| 总文件存储 | 按套餐（通常为每个租户 TB 级） |

## 如何保持在限制范围内

### 分页

当获取 >2,000 条记录时：

```http
GET /api/v1/opportunities?limit=200&cursor=eyJpZCI6...
```

请始终分页；切勿一次性加载所有记录。

### 退避

当你遇到 429 时：

```js
async function callApi(fn, retries = 5) {
  try { return await fn(); }
  catch (e) {
    if (e.status === 429 && retries > 0) {
      await sleep(Math.min(60000, 1000 * Math.pow(2, 5 - retries)));
      return callApi(fn, retries - 1);
    }
    throw e;
  }
}
```

或使用自动处理退避的平台 SDK。

### 批量操作

对于 >100 条记录，使用**批量 API**而非 100 次单独调用。

### AI 调用批处理

在分流大量记录时，使用**批量技能**调用 —— 它在底层进行批处理并计为 N 次调用（因此仍遵守每用户配额），但使用连接池实现约 10× 的加速。

### 字段索引

对于你频繁查询的自定义字段，将其标记为**索引** —— 加快列表筛选和报表执行。

### 归档旧数据

超出你运营窗口的记录（例如，关闭超过 2 年的案例）可以被**归档**：

- 从热存储中移除；仍可通过**归档 API** 查询。
- 释放索引并提升性能。
- 可按对象配置自动归档策略。

## 监控你的使用情况

每个租户在 **Setup → Usage** 处都有一个**使用情况仪表盘**：

- 按用户划分的每分钟 / 每天 / 每月 API 调用。
- 按技能划分的 AI 技能调用。
- 存储增长。
- 按记录创建 / API 消耗排名的顶级用户。
- 异常告警。

企业版租户可与客户团队进行季度**使用情况评审**。

## 当你超出这些限制时

- **纵向** —— Enterprise+ 套餐扩展大多数配额。
- **分片** —— 用于 >10 亿条记录的多区域部署。
- **自托管** —— 消除平台上限；瓶颈变为基础设施。

请联系你的客户团队或在 [GitHub](https://github.com/objectstack-ai/hotcrm/issues) 上提交问题。
