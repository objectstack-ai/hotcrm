# 行銷活動

**行銷活動**是任何行銷舉措——一次郵件群發、一場網路研討會、一個展會展位、一次內容下載、一個付費社交廣告活動。每個行銷活動都有預算、目標受眾、持續時間和可衡量的結果（收入、潛在客戶、商機）。

## 4 種行銷活動狀態

| 狀態 | 含義 |
| --- | --- |
| ⚪ **Planning** | 設計中——受眾、預算、內容 *(預設)* |
| 🟠 **In Progress** | 進行中——成員已加入，正在追蹤互動 |
| 🟢 **Completed** | 已完成——指標最終確定，ROI 已計算 |
| 🔴 **Aborted** | 完成前已取消 |

系統會在行銷活動結束日期的次日自動將其從 *In Progress* 移至 *Completed*——這樣你就不必記著了。

## 8 種行銷活動類型

| 類型 | 用途 |
| --- | --- |
| **Email** *(預設)* | 通訊、滴灌計畫、廣播郵件 |
| **Webinar** | 帶註冊和出席追蹤的虛擬活動 |
| **Trade Show** | 在產業活動上的線下展位展示 |
| **Conference** | 演講席位、贊助 |
| **Direct Mail** | 實體信件、禮品、包裹 |
| **Social Media** | 付費或自然社交行銷活動 |
| **Content Marketing** | 部落格文章、電子書、白皮書、門控內容 |
| **Partner Marketing** | 與通路合作夥伴的聯合行銷活動 |

以及 5 個主要通路：**Digital · Social · Email · Events · Partner**。選擇最能描述行銷活動如何觸達受眾的通路——它被通路組合報表使用。

## 行銷活動記錄儲存什麼

詳情畫面有幾個部分：

| 部分 | 欄位 |
| --- | --- |
| **Basic** | 行銷活動代碼、名稱、描述、類型、通路、狀態 |
| **Schedule** | 開始日期、結束日期 |
| **Budget** | 預算成本、實際成本、預期收入、實際收入 *(彙總)* |
| **Audience** | 目標規模、傳送數量 |
| **Engagement** *(彙總)* | 開啟、點擊、回應、轉換 |
| **Attribution** *(彙總)* | 產生的潛在客戶、建立的商機、成交贏單收入 |

**Campaign Code** 是自動產生的（例如 CAMP-000123），因此每個行銷活動都有一個唯一的簡短引用，用於郵件主旨行和追蹤 URL。

## 內建規則

- **結束日期必須在開始日期當天或之後** — 基本的合理性檢查。
- **超預算警告** — 如果實際成本超過預算成本，記錄上會顯示警告。它不會阻止儲存，但會標記該行銷活動以供財務審查。

## 自動發生的事

- **自動完成** — 每天凌晨 2 點，任何超過結束日期的 *In Progress* 行銷活動都會被標記為 *Completed*。行銷活動的最終指標（傳送、回應、轉換、ROI）在那一刻快照。
- **成員加入** — 當行銷活動進入 *In Progress* 時，[Campaign Enrollment flow](#campaign-enrollment-flow) 每週一早上 9 點執行並新增新的符合受眾成員。
- **ROI 計算** — 行銷活動的實際收入是相關成交贏單商機金額的彙總總和。ROI =（實際收入 − 實際成本）÷ 實際成本。

## 行銷活動加入流程

當你啟動一個行銷活動（狀態 → *In Progress*）時，系統會將你的目標受眾批次加入為 [行銷活動成員](/zh-Hant/docs/marketing/campaign-members)。

該流程按排程執行（預設週一早上 9 點）並：

1. 讀取行銷活動的目標受眾條件（例如"所有評級 ≥ 3 的 Technology 產業潛在客戶"）。
2. 查找符合的潛在客戶和聯絡人。
3. 為每個人建立一條狀態 = *Sent* 的行銷活動成員記錄。
4. 可選地觸發行銷活動的傳送操作（郵件傳送、郵件派發等）。

對於即時行銷活動（例如帶註冊表單的網路研討會），你也可以從行銷活動詳情頁**手動**新增成員，或透過任何潛在客戶/聯絡人上的 **Add to Campaign** 操作新增。

## 衡量行銷活動

行銷活動詳情頁的右側面板顯示：

- **Sent** — 加入的成員數量。
- **Open rate** — 狀態 ≥ Opened 的成員百分比。
- **Click rate** — 狀態 ≥ Clicked 的成員百分比。
- **Response rate** — 狀態 ≥ Responded 的成員百分比。
- **Conversion rate** — 狀態 = Converted 的成員百分比（即成為商機）。
- **Opportunities generated** — 以該行銷活動為來源的商機數量。
- **Pipeline value** — 這些商機金額的總和。
- **Closed-won revenue** — 這些商機中階段 = closed_won 的金額總和。
- **ROI** —（成交贏單收入 − 實際成本）÷ 實際成本。

## 歸因：從行銷活動到收入

連接點是商機上的 **Source Campaign** 查閱欄位。當業務代表轉換一個來自行銷活動的潛在客戶時——或在商機上手動設定來源行銷活動時——系統會將收入歸功於該行銷活動。

對於受多個行銷活動影響的交易（多接觸點），慣例是記錄**末次接觸點**行銷活動（最接近轉換的那個）。要實現完整的多接觸點歸因，可考慮使用行銷活動影響聯結物件擴充模型——請參閱 [自訂](/zh-Hant/docs/customization/extending-objects)。

## 標準清單檢視

- **Active Campaigns** — 狀態 = *In Progress*。
- **Upcoming Campaigns** — 開始日期在未來，狀態 = *Planning*。
- **Completed This Quarter** — 狀態 = *Completed* 且結束日期在本季。
- **Over Budget** — 實際成本 > 預算成本。
- **By Type** — 已分組。
- **Best ROI** — 按 ROI 降序排列。

## 共享——行銷活動預設公開

行銷活動對整個組織**公開唯讀**。銷售中的任何人都可以看到行銷正在執行什麼，並在客戶對話中使用該背景。編輯權限保留給行銷使用者。

## 給行銷人員的提示

- ✅ 在啟動時**設定預期收入**——這是財務預測行銷活動貢獻的依據。
- ✅ **一旦知道就記錄實際成本**——如果欄位為空，超預算警告就無濟於事。
- ✅ 如果你提前結束，請**將行銷活動狀態更新為 *Completed***；不要等待自動完成。
- ✅ 在描述中**記錄有效的做法**——未來的你和未來的同事會感謝你。

## 給業務代表的提示

- ✅ 當一個潛在客戶到來時，檢查他們是否在某個行銷活動中——它會告訴你他們已經看過什麼。
- ✅ 在你成交的商機上設定 **Source Campaign**——沒有它行銷就無法衡量 ROI。

## 給管理員的提示

- 自動完成 cron（每天凌晨 2 點）和加入 cron（週一早上 9 點）是可設定的。請參閱 [Administration › Automation](/zh-Hant/docs/administration/automation)。
- 要新增新的行銷活動類型或通路，請編輯行銷活動物件的選項清單。請參閱 [自訂 › 擴充物件](/zh-Hant/docs/customization/extending-objects)。
- 對於多接觸點歸因，請參閱自訂指南。
