**Project Delivery: a project task no longer shows a Schedule Type field (#2769).** Before, the **Schedule** section of a project task's page, and of the panel that opens from a row of the Project Plan Gantt, showed **Schedule Type** with the value `task` or `milestone`: an internal value the Gantt reads, in English whatever your language, repeating what the **Milestone** checkbox already says. Now the field is off the page, the panel and the form. The Gantt is unchanged: a task with **Milestone** ticked is still drawn as a diamond. No setup is needed.
