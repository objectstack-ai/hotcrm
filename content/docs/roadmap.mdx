# HotCRM Roadmap

HotCRM is evolving rapidly. Having established the core **6-Cloud Architecture** (Sales, Marketing, Revenue, Service, HR, AI) with **65 production-ready objects**, our focus shifts towards deeper intelligence, broader integration, and enhancing the developer experience.

> **Protocol Version**: @objectstack/spec v2.0.6 | **Tests**: 933 passing | **Last Updated**: February 11, 2026

## ✅ Phase 1: Core Foundation (Completed)

We have successfully established the metadata-driven runtime and the core business logic for all primary clouds.

### Business Clouds (6 Completed)
- **Sales Cloud** ✅: 8 objects - Lead-to-Cash capability, Pipeline management, Opportunity lifecycle, Activity tracking
- **Marketing Cloud** ✅: 7 objects - Campaign management, Lead nurturing, Email automation, Form & Landing page
- **Revenue Cloud** ✅: 13 objects - CPQ (Configure-Price-Quote), Contract lifecycle, Invoice & Payment tracking
- **Service Cloud** ✅: 21 objects - Case management, SLA tracking, Knowledge base, Omni-channel routing
- **HR Cloud** ✅: 16 objects - Recruitment, Onboarding, Performance, Payroll, Training
- **AI Cloud** ✅: Unified AI service layer with 5 pre-registered ML models

### Platform Foundation (Completed)
- **Metadata Engine** ✅: TypeScript-native object definitions (`.object.ts`)
- **ObjectQL** ✅: Type-safe query language replacing SQL
- **Plugin Architecture** ✅: Independent packages with dependency management
- **Model Registry** ✅: Centralized ML model configuration and versioning
- **Prediction Service** ✅: Unified interface for all ML predictions with caching

### Total Delivered
- **65 Core Objects** across 6 business clouds
- **500+ Fields** for comprehensive data capture
- **5 AI Models** pre-registered and production-ready
- **8 Currency Support** for global operations

## ✅ Phase 2: Deep Intelligence (Completed)

"Active Intelligence"—moving from recording data to acting on it.

### 🤖 AI Agent Integration
- **Inbox Agent** ✅: Automatically categorize emails and draft replies for Support Cases.
- **Sales Co-Pilot** ✅: Suggest next-best-actions based on Opportunity stage and deal velocity.
- **Recruitment Assistant** ✅: Auto-screen resumes and schedule interviews based on fit scores.
- **GenAI Reporting** ✅: Natural language queries for complex data analytics ("Show me Q3 revenue by region vs last year").
- **Performance Coach** ✅: AI-driven OKR recommendations and performance insights.

### ⚡ Automation & Workflow
- **Advanced Approvals** ✅: Parallel approval chains and smart delegation.
- **SLA Enforcement** ✅: Automated escalation triggers for Service Cloud.
- **HR Workflows** ✅: Onboarding automation, time-off approvals, performance review cycles.
- **Contract Renewals** ✅: Automatic renewal opportunity creation 90 days before expiration.

### 🎯 Enhanced Analytics
- **Revenue Dashboards** ✅: TCV, ARR, Quote-to-Close ratios
- **Sales Performance** ✅: Pipeline metrics, win rates, forecast accuracy
- **Service Metrics** ✅: First Response Time, CSAT, SLA compliance
- **HR Analytics** ✅: Time-to-hire, attrition rates, performance trends
- **Marketing ROI** ✅: Campaign attribution, Cost Per Lead, conversion funnels

## 🔧 Phase 3: Quality & Protocol Compliance (Current Focus)

Ensuring every module strictly follows the @objectstack/spec v2.0.6 protocol and meets enterprise quality standards.

### Recently Completed
- ✅ **@objectstack v2.0.6 Upgrade**: All 10 packages upgraded with zero breaking changes and 933 tests passing.
- ✅ **@objectstack v2.0.0 Migration**: Major version upgrade with Hook API migration (HookContext redesign).
- ✅ **Protocol Compliance**: All 65 objects fully compliant with ObjectSchema.parse() validation.
- ✅ **Field.lookup() Standardization**: All lookup references now use snake_case consistently.
- ✅ **TypeScript Config**: Root tsconfig.json with correct path mappings for all 9 packages.

### 🔴 P0 — Code Quality & Consistency

1. **Translate Chinese Text**: CRM package has Chinese text in `lead.schema.ts` (30 fields) and `ai_smart_briefing.action.ts` (50+ strings). All labels should be in English.
2. **Error Handling**: Add try-catch to `marketing/roi.hook.ts` (currently has no error handling).
3. **Resolve TODO**: Implement full lead conversion logic in `crm/hooks/lead.hook.ts`.

### 🟡 P1 — Test Coverage & Reliability

4. **Hook Tests**: Add tests for 19 hook files across all 6 packages. Priority: CRM (5 hooks), Products (3 hooks), Finance (2 hooks).
5. **Action Tests**: Add tests for remaining untested action files. Priority: CRM (5 actions), Marketing (3 actions), Finance (2 actions).
6. **Target**: 80%+ test coverage across all 6 active business packages (currently 48 test files, 933 tests).

### 🟢 P2 — Architecture Improvements

7. **Plugin Registration**: Register missing hooks and actions in `plugin.ts` for HR, Marketing, Products, and Support packages.
8. **DB Shim Migration**: Migrate 6 `db.ts` shim files to direct `@objectstack/runtime` broker API.
9. **Hook Coverage**: Add hooks for 40+ unhook-ed business objects (only 29% of objects currently have hooks).
10. **Workflow Coverage**: Add missing automation workflows for Marketing (campaign automation), Support (case escalation), and Finance (payment reminders).

### 🔵 P3 — Documentation

11. **HR Cloud Technical Specs**: Create architecture documentation for Recruitment, Performance, Payroll, and Employee objects.
12. **AI Cloud Technical Specs**: Create architecture documentation for AI service layer, Model Registry, and Prediction Service.
13. **Field-Level API Reference**: Generate per-object field documentation for all 65 objects.
