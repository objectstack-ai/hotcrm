**A project names the order it delivers (REQ-0010 stage 2, #2561).** Projects gain an optional **Order** (`crm_project.crm_sales_order`) beside **Contract**, offered from the project's account, for a project sold on an order with no contract. The order's page lists its projects under **Projects**, and **All Projects** shows the column. Project managers now read every order and its lines, as they read every contract, so they can pick the order and see what was sold; the Order field is left off a project team member's page, as the Opportunity is, and team members get no order access. Every other set that reads projects already reads orders. With the Project Delivery module disabled, the order page loses the Projects list and nothing else changes.
