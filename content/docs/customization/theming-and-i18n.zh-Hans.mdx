# 主题与 i18n

当前仓库主要维护元数据标签和 locale bundles。运行时主题由 ObjectStack shell 处理；应用内文案放在翻译文件中。

## 应用翻译

Locale bundles 位于 `src/translations/`。

```text
src/translations/
├── en.ts
├── zh-CN.ts
├── es-ES.ts
├── ja-JP.ts
└── crm.translation.ts
```

新增带用户可见标签的对象、动作、页面、视图、仪表盘或报表时，请同步更新相关翻译文件。

## 文档翻译

产品文档位于 `content/docs/`。

| 语言 | 文件模式 |
| --- | --- |
| 英文 | `*.mdx` |
| 简体中文 | `*.zh-Hans.mdx` |
| 繁体中文 | `*.zh-Hant.mdx` |

导航元数据遵循同样模式：

```text
meta.json
meta.zh-Hans.json
meta.zh-Hant.json
```

## 工作流

1. 先更新英文源页面。
2. 在本地化页面中同步结构变化。
3. 链接保持 locale-aware，例如 `/zh-Hans/docs/...`。
4. 运行文档类型检查或构建。

```bash
pnpm --filter @hotcrm/docs types:check
pnpm --filter @hotcrm/docs build
```

## 验证

应用元数据：

```bash
pnpm validate
pnpm typecheck
```

文档：

```bash
pnpm --filter @hotcrm/docs types:check
```
