# 费用——录入、审批与项目

写给每个为公司花钱的人、他们的上级，以及财务。一笔费用就是一项开支及其票据。你录入并提交，由合适的人在**收件箱**中审批。

## 录入费用

打开「费用报销」应用中的**我的费用**，选择**新建**：填写**描述**、**日期**、**类别**、**金额**，也可以填写**商户**、**票据号**和**付款方**（默认是你本人，也可以是公司）。在**文件**页签上传票据。项目上的费用请同时选择**项目**；其他费用留空即可。

金额使用贵组织的币种。外币票据请先换算再录入。

**来源**表示这条记录是怎么来的：手工录入、智能体写入或导入。它不影响任何判断。

## 由谁审批

把**状态**设为**已提交**。等待审批期间，费用被锁定。

- **有项目**：由项目的**项目经理**审批。
- **没有项目**：由你的**上级**审批，即你用户记录上的上级。没有填写上级时，改由**财务控制**审批。
- **2,000 及以上**：在第一位审批人之后，**财务控制**也要审批，他们批准后才计入。
- **不能审批自己的费用。**项目经理在自己项目上的费用转给管理员。

提交时，审批人会写入**审批人**字段，费用出现在他们的**待我审批的费用**里。**已驳回**表示退回：把它改回**草稿**，修改后再次提交。等待期间，你也可以在收件箱中**撤回**。没有人能手动设置**已批准**或**已驳回**；只有管理员可以这样做，用来修复无法运行审批的费用。

## 项目

启用「项目交付」时，项目上已批准的费用计入项目的**费用成本**；**可计费**的还计入**已批准待开票**。公司付款的同样计入。

- **项目**选择框只列出未**关闭**、未**取消**的项目。
- 在已**关闭**、已**取消**或勾选了**锁定工时与费用**的项目上提交费用，会直接退回**草稿**，你会收到一条写明项目的收件箱通知。请保留为草稿，或改挂到进行中的项目后再提交。

停用「项目交付」后，费用上不再有**项目**字段，所有费用都交给提交人的上级审批。
