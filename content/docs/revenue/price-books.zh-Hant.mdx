# 價格表

本應用未隨附繁體中文語言包，因此本頁出現的介面名詞依固定順序取用：zh-CN 語言包已收錄者，採其用詞的繁體寫法；未收錄者，保留產品內的英文原名，不另造譯名。

**價格表**（**Price Book**）是一組命名的產品價格。產品目錄中每個產品只有一個 **List Price**；價格表讓同一產品面向不同對象有不同價格——夥伴等級、某個區域，或在兩個日期之間有效的促銷。

價格表中每個產品對應一條**價格表條目**（**Price Book Entry**）：產品、它在這本價格表中的 **List Price**，以及該條目是否 **Active**。

## 標準價格表 [#standard-book]

有且只有一本價格表是 **Standard** 價格表，HotCRM 保證它唯一：

- 不能再把第二本價格表標記為 **Standard**。儲存會被拒絕，並指出目前的標準價格表是哪一本。
- 不能取消標準價格表的 **Standard** 標記，也不能刪除它。不想再使用時，請關閉 **Active**。

HotCRM 的範例資料包含一本名為 **Standard** 的價格表，範例目錄中的每個產品在其中都有一條條目，價格等於該產品的 **List Price**。範例資料為簡體中文的組織，拿到的是同一份範例目錄的中文版（產品名稱與說明為中文，價格不變），價格表名為 **标准价格表**。已有資料的單一組織部署在升級後第一次啟動時會獲得這本價格表，且只產生一次；此後你在其中修改的價格會保留。

此後，Standard 價格表跟隨產品目錄。之後新增的產品在儲存時就會按其 **List Price** 在 Standard 價格表中取得條目；修改產品的 **List Price**，它在 Standard 價格表中的條目也隨之改價。產品的 **List Price** 就是標準價，「標價不得低於成本」的規則也仍在產品上：要改標準價，請在產品上改。

## 每個產品一條條目 [#one-entry-per-product]

一本價格表中每個產品只有一個價格。為價格表中已有價格的產品再新增一條條目會被拒絕，提示中會寫明價格表和產品，方便你去編輯已有的那條。同一產品當然可以在每本價格表中各有一條條目。

## 有效期 [#validity]

**Valid From** 和 **Valid To** 記錄這本價格表適用的時間段，例如促銷的開始和結束。兩者都可以留空，表示不限期；**Valid To** 不能早於 **Valid From**。

## 按價格表報價 [#quoting-from-a-price-book]

每張報價單都從一本價格表取價，顯示為報價單上的 **Price Book** 欄位。

- **新報價單預設使用 Standard 價格表。** **Price Book** 留空儲存，報價單就會帶上 Standard 價格表。要按另一本價格表報價，請在新增明細行之前在報價單上選好它。只能選擇啟用的價格表。
- **明細行的標價取自價格表。** 在報價明細行上選擇產品時，**List Price** 就是該產品在報價單所選價格表中的價格；新明細行的 **Sales Price** 也從這個價格開始。之後照常議價。
- **價格表中沒有價格的產品會被拒絕。** 如果報價單所選價格表中沒有該產品的啟用條目，明細行不會儲存，提示會寫明價格表和產品。請把產品加入這本價格表，或改用另一本價格表報價。
- **更換價格表。** 報價單還沒有明細行時可以更換價格表。一旦有了明細行，它們是按原價格表定價的，更換會被拒絕：先移除明細行，選好價格表，再重新新增。
- **已報出的價格不變。** 修改條目價格或編輯價格表，只影響之後寫入的明細行。已有明細行保留當時的價格，與修改產品 **List Price** 時一樣。
- **已結束的報價單保留其價格表。** 報價單一旦已接受、已拒絕或已過期就被凍結，**Price Book** 也隨之凍結。

只要有報價單使用某本價格表，它就不能刪除；提示會寫明有多少張報價單在用。不想再用它報價時，請關閉 **Active**：它會從報價單的選擇清單中消失，已經使用它的報價單保持不變。

商機不讀取價格表。商機的產品明細仍從產品取標價，也就是標準價。

在報價開始讀取價格表之前建立的報價單，自身沒有 **Price Book**。它新增的明細行按 Standard 價格表定價。

## 向價格表新增產品 [#adding-products-to-a-book]

在價格表的記錄頁上，**Add Products** 一步就能把產品目錄定價到這本價格表中。你只需填寫一個數字——**Price as % of List Price**：夥伴等級比標準價低 20% 就填 80，某個區域比標準價高就填 110。這本價格表中尚未定價的每個啟用產品，都會按其 **List Price** 的這個比例新增一條條目，四捨五入到分。已有價格的產品保持原價，所以新產品上架後再執行一次，只會補上缺的。結果頁會寫明新增了多少個產品、多少個已有價格。

要手動設定某個產品的價格，請開啟價格表的 **Price Book Entries** 分頁編輯那條條目，或在那裡新增一條。產品的記錄頁在 **Price Book Entries** 下列出它在每本價格表中的條目。

## 誰可以修改價格表 [#who-can-change-price-books]

| 角色 | 價格表及其條目 |
| --- | --- |
| **System Administrator** | 建立、編輯、刪除任意價格表和條目。 |
| **Sales Manager** | 建立價格表，並編輯自己擁有的價格表：新增、改價、移除其中的條目，並在其上執行 **Add Products**。 |
| **Sales Rep** | 檢視所有價格表和條目，並為自己的報價單選擇價格表。 |

價格表對所有有權檢視的人可見，與產品目錄的共享方式相同；能檢視、編輯某本價格表的人，也能檢視、編輯其中的條目。**Add Products** 以執行者本人的身分新增每條條目：在無權編輯的價格表上執行，每個產品都會被拒絕，執行結束時會給出各項數量。

## 幣別 [#currency]

價格表沒有自己的幣別。所有價格表中的價格都使用組織的預設幣別，與 HotCRM 中的所有金額一致。多幣別定價要等 ObjectStack 平台支援記錄級幣別和匯率後再做。
