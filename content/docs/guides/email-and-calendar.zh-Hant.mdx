# 郵件與行事曆

HotCRM 整合了 **Gmail**（Google Workspace）和 **Outlook**（Microsoft 365），使每一封客戶郵件和會議都能自動匯入正確的記錄 —— 無需複製貼上。

## 你將獲得什麼

- ✉️ **雙向郵件同步** —— 與客戶之間往來的郵件會顯示在聯絡人、客戶和商機記錄上。
- 📅 **雙向行事曆同步** —— 你的會議會顯示在 HotCRM 中，反之亦然。
- 👀 **郵件追蹤** —— 查看收件人何時開啟了你的郵件或點擊了連結。
- 🤖 **AI 起草的回覆**，直接從你的收件匣傳送。
- 📥 **入站工單郵件** —— `support@yourcompany.com` 會自動變成一個工單。

## 連接你的收件匣

1. 點擊你的頭像 → **設定 → 郵件與行事曆**。
2. 點擊 **連接 Gmail** 或 **連接 Outlook**。
3. 在 OAuth 彈出視窗中授權該整合。
4. 選擇要同步的內容：
   - **所有郵件**（預設）—— 與你 CRM 中任何人的每一次會話。
   - **僅追蹤的郵件** —— 僅你明確新增追蹤像素的郵件。
   - **白名單網域** —— 僅與特定客戶網域往來的郵件。
5. 選擇要同步到行事曆的內容：
   - **僅客戶會議** —— 至少有一名外部與會者的事件。
   - **所有事件** —— 包括內部會議（雜訊更多）。

## 郵件記錄的運作原理

當連接器發現你與某個已知聯絡人（按郵件地址比對）之間的一封郵件時：

- 郵件本文會儲存在聯絡人、客戶以及任何未結商機 / 工單的**活動時間軸**上。
- 附件會儲存為檔案。
- 該郵件會對**任何**擁有這些記錄共享存取權限的人可見（這樣業務代表可以看到前任傳送了什麼）。

你也可以透過將郵件轉寄到一個個人化地址（例如 `you@hotcrm-log.io`）來**手動記錄**郵件 —— 它會自動比對聯絡人並建立關聯。

## 郵件追蹤

在 HotCRM 內部撰寫郵件時：

- ✅ **追蹤開啟** —— 收件人開啟時收到通知。
- ✅ **追蹤點擊** —— 他們點擊追蹤連結時收到通知。
- ✅ **定時傳送** —— 選擇一個時間。
- ✅ **提醒** —— 如果對方在 N 天內未回覆，將郵件重新置頂回你的收件匣。

追蹤事件會儲存在郵件活動、聯絡人以及來源行銷活動（如果有）上。

## AI 起草的郵件

在任何記錄上，請助手起草郵件——郵件撰寫技能由 [銷售技能](/zh-Hant/docs/ai-copilot/sales-copilot) 和 [服務技能](/zh-Hant/docs/ai-copilot/service-copilot) 共用：

1. 選擇一個目標（*「發現階段跟進」*、*「續約推介」*、*「問題解決」*）。
2. 審閱草稿 —— 編輯、替換、重新生成。
3. 點擊 **傳送** —— 郵件透過你已連接的收件匣傳送，*而非* HotCRM 中繼，因此能保持你的寄件人聲譽。
4. 會話會被自動記錄。

## 從聯絡人或工單「傳送郵件」

任何你看到 **傳送郵件** 操作的地方（在聯絡人、工單、商機上），其流程為：

1. 該操作會開啟一個模態框，其中 **收件人 / 主旨 / 本文** 會根據記錄（以及你選擇的任何郵件範本）預先填入。
2. 提交後，郵件會透過平台 `sys_email` 服務排隊。它**不會**直接傳送到你的收件匣 —— 佇列工作程序負責處理重試、退信和速率限制。
3. 新的郵件列會在 **關聯物件** 下連結回源記錄，並且在該記錄的 **活動** 索引標籤上會顯示一條對應條目，附帶當前的投遞狀態（已排隊 / 已傳送 / 已退信 / 失敗）。
4. 投遞成功後，回覆會透過上述常規雙向同步比對回來，並串聯到同一條記錄上。

> 管理員可以在 **設定 → 系統郵件佇列** 中查看所有已排隊 / 失敗的郵件，並從那裡重新驅動失敗的批次。

## 從任何記錄「記錄通話」

**記錄通話** 操作可以在不離開記錄的情況下記錄一次外撥或來電。提交後，會向 `sys_activity` 寫入一條類型為 **completed** 的條目（kind = *call*），包含主旨、時長和結果。它會顯示在該記錄的 **活動** 索引標籤上，並計入銷售 / 服務儀表板上業務代表的活動指標。



在 **設定 → 郵件範本** 中儲存可重複使用的郵件範本：

- 合併欄位（`{{Contact.FirstName}}`、`{{Opportunity.Amount}}`）。
- HTML + 純文字版本。
- 按團隊劃分的資料夾。
- 針對法律敏感內容的需審核範本。

範本可以**由 AI Copilot 個人化** —— 選擇一個範本，新增一個目標，Copilot 會用正確的情境將其填充完整。

## 行事曆同步

連接你的行事曆後：

- HotCRM 會在你的 Google/Outlook 帳戶中建立一個 **HotCRM Events** 行事曆。
- 在 HotCRM 中建立的事件會顯示在那裡。
- 在你的原生行事曆中建立、並以 **CRM 聯絡人作為與會者** 的事件，會作為事件同步到 HotCRM 中那些聯絡人/客戶上。
- 衝突（同一時間的兩個事件）會被標記出來。

## 入站工單郵件

在 **設定 → 郵件 → 入站工單郵件** 中進行設定：

1. 選擇一個地址（例如 `support@yourcompany.com`）。
2. 將該地址轉寄到所顯示的入站地址。
3. 設定預設佇列、優先級和指派規則。

現在每一封發往 support@ 的郵件都會變成一個工單：

- 寄件人會被比對（或自動建立）為一個聯絡人。
- 主旨 → 工單主旨；本文 → 工單描述；附件 → 工單檔案。
- 工單討論串上的回覆會透過郵件返回給客戶，並保留該討論串。

## 隱私與政策

- 郵件本文內容與你的 CRM 記錄儲存在同一個資料庫中，並遵循你的共享規則。
- 你可以**排除**特定地址或網域（人力資源、個人）。
- 密件副本 / 隱藏的收件人**不會**被記錄。
- 對於 GDPR —— 你可以透過聯絡人的 *刪除個人資料* 操作清除該聯絡人的郵件歷史。
