# Welcome to HotCRM

**HotCRM** is the open-source alternative to Salesforce, re-engineered for the AI era.

We combine the enterprise-grade reliability of a **Metadata-Driven Architecture** with the revolutionary power of **Agentic AI** — delivering 66 business objects across 6 clouds, all powered by a unified AI intelligence layer.

## The HotCRM Difference

<Cards>
  <Card title="No-SQL Data Layer" icon="database">
    Built on **ObjectStack Protocol**. We replaced complex SQL with **ObjectQL** — a type-safe, JSON-based query language that AI understands perfectly.
  </Card>
  <Card title="AI as a Colleague" icon="sparkles">
    Not just a chatbot. AI Agents proactively score leads, draft emails, route cases, predict churn, and optimize pricing — all autonomously.
  </Card>
  <Card title="Code-Based & Low-Code" icon="code">
    Define your entire business logic in **TypeScript** files (`.object.ts`, `.hook.ts`, `.action.ts`) for version control, or use the UI for quick changes.
  </Card>
  <Card title="100% Extensible" icon="blocks">
    Everything is an object. Extend standard clouds or build completely new ones using the same platform tools we use.
  </Card>
</Cards>
