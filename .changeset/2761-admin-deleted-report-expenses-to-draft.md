**Expenses: an expense released by deleting a sent report goes back to Draft.** An administrator can delete an expense report that has been sent, to repair. Its expenses were released from the report but kept the status it had given them, so an expense on no report still read Submitted or Rejected. Now the expenses of a report deleted while it waited for approval or was rejected go back to **Draft**, free to be submitted again. Deleting an approved or paid report is unchanged: its expenses stay **Approved**. The expense manual now states the administrator exception and both outcomes.
