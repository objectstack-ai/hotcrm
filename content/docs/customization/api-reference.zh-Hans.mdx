# API 参考

HotCRM 运行在 ObjectStack 上。Web UI、自动化、动作和 AI skills 都使用 `objectstack.config.ts` 注册的同一套对象元数据。

## 本地地址

本地运行：

```bash
pnpm dev
```

应用地址：

```text
http://localhost:4001
```

对象 API 由 ObjectStack runtime 提供。路由形态可能随 runtime 版本和启用能力变化，因此在环境中可用时，请优先使用 runtime API explorer。

## 当前对象

对象清单在此**不再**转抄 —— `src/objects/*.object.ts` 是它的事实来源，一个对象一个文件，
各自注册以 `crm_` 为前缀的 `name`。数据模型覆盖四个业务领域：销售、服务、市场和营收。

## ObjectQL 形态

在 actions、flows、hooks 和集成中调用 ObjectStack 数据层时，使用 ObjectQL 风格的过滤和字段选择。

```json
{
  "filters": [
    ["stage", "in", ["proposal", "negotiation"]],
    ["amount", ">", 100000]
  ],
  "sort": [{ "field": "amount", "direction": "desc" }],
  "limit": 50,
  "fields": ["id", "name", "amount", "stage", "crm_account"]
}
```

常用操作符包括 `=`, `!=`, `>`, `>=`, `<`, `<=`, `in`, `not_in`, `between`, `contains`, `starts_with`, `ends_with`, `is_null`, `is_not_null`。

## 动作体

HotCRM actions 可以包含带受限能力的可执行元数据体。

```ts
export const CreateCampaignAction = {
  name: 'create_campaign',
  objectName: 'crm_lead',
  type: 'modal',
  body: {
    language: 'js',
    capabilities: ['api.write'],
    source: `
      await ctx.api.object('crm_campaign_member').insert({
        crm_campaign: input.campaign,
        crm_lead: input.leadId,
        status: 'sent'
      });
    `,
  },
};
```

## 验证

修改面向 API 的元数据后运行：

```bash
pnpm validate
pnpm typecheck
pnpm test
```

发布前运行 `pnpm verify`。
