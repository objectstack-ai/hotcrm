**A project's Overview shows its fields again.** The project page's Overview tab drew only the Gantt on @objectstack 18.5.0: its field block was authored bare, and since 18.5.0 a bare block draws only the highlight fields not already shown in the header strip, which for a project is none. It now names the project's five field groups (Project, Customer, Plan, Financials, Team), as the default record page does, so the fields sit above the Gantt as they did before.
