**Expenses: Mark as Paid explains a refusal in your language (#2763).** Before, when **Mark as Paid** on an expense report refused, a Chinese, Japanese or Spanish user read the reason in English: that only finance marks a report as paid, that the report has to be open, that the report no longer exists, or that the report is not approved. Now each of these reasons is shown in the language you use, and the one about approval still names the report. English users read the same sentences as before, and nothing changes about who can mark a report as paid or when. No setup is needed.
