# 面向開發者

本頁面向**工程師**。終端使用者和管理員可以跳過。

## 前置條件

- **Node.js 20+**
- **pnpm 9+**（工作區套件管理器）
- `objectstack-ai/hotcrm` 儲存庫的複製

## 本地設定

```bash
git clone https://github.com/objectstack-ai/hotcrm.git
cd hotcrm
pnpm install
pnpm dev
```

打開 http://localhost:3000 —— 應用在你首次註冊時會隨種子資料啟動。

## 儲存庫中有什麼

```
hotcrm/
├── packages/             # Business capability packages
│   ├── crm/              # Sales objects, flows, sharing, approvals
│   ├── finance/          # Contracts, revenue
│   ├── products/         # Product catalog
│   ├── service/          # Cases, knowledge base
│   ├── marketing/        # Campaigns
│   └── ai/               # Copilot agents, skills, knowledge bases
└── apps/
    ├── crm/              # The CRM application
    └── docs/             # This documentation site
```

每個套件都遵循**檔案後綴協定**：

| 後綴 | 定義 |
| --- | --- |
| `*.object.ts` | 資料模型 |
| `*.hook.ts` | 伺服器端生命週期邏輯 |
| `*.action.ts` | API 端點 / 可供 AI 呼叫的工具 |
| `*.flow.ts` | 多步驟自動化 |
| `*.skill.ts` | AI 技能 |
| `*.agent.ts` | 複合型 AI 代理 |
| `*.page.ts` | UI 頁面版面 |
| `*.view.ts` | 清單檢視 |
| `*.dashboard.ts` | 儀表板 |
| `*.sharing.ts` | 共享規則 |
| `*.approval.ts` | 審批流程 |
| `*.statemachine.ts` | 狀態轉換 |

## 核心平台：ObjectStack

HotCRM 執行於 [**@objectstack/runtime**](https://github.com/objectstack-ai/framework) —— 一個中繼資料優先的執行時，負責持久化、共享、驗證、自動化和 AI。我們*不*修改執行時；我們**定義中繼資料**，由執行時執行。

關鍵概念：

- **物件**是 TypeScript 檔案（無 YAML、無 JSON、無 UI 點擊）。
- **ObjectQL** 是資料存取 API —— `broker.find('crm_opportunity', {...})` 而非 SQL。
- **鉤子**在生命週期事件（`before_create`、`after_update` 等）上觸發。
- **流程**以視覺化方式編排多步驟業務邏輯，並在 TS 中定義。
- 每個中繼資料檔案在編譯時都會針對 `@objectstack/spec` schema 進行**驗證**。

## 常見任務

### 向現有物件加入欄位

```ts
// packages/your-extension/src/opportunity.object.ts
import { defineObject, Field, ObjectSchema } from '@objectstack/spec/data';

export default ObjectSchema.parse(defineObject({
  name: 'crm_opportunity',
  extends: 'crm.opportunity',
  fields: {
    custom_priority: Field.select({
      options: [
        { value: 'a', label: 'A' },
        { value: 'b', label: 'B' },
      ],
    }),
  },
}));
```

➜ 完整指南：[擴展物件](/zh-Hant/docs/customization/extending-objects)

### 加入 AI 技能

```ts
// packages/your-extension/src/your_skill.skill.ts
import { defineSkill } from '@objectstack/spec/ai';

export default defineSkill({
  name: 'your_skill',
  // ...
});
```

➜ 完整指南：[建構 AI 技能](/zh-Hant/docs/customization/ai-skills)

### 客製化頁面

```ts
// packages/your-extension/src/opportunity.page.ts
import { definePage, PageSchema } from '@objectstack/spec/ui';

export default PageSchema.parse(definePage({
  object: 'crm_opportunity',
  // ...
}));
```

➜ 完整指南：[UI 擴展](/zh-Hant/docs/customization/ui-extensions)

## 驗證你的變更

```bash
pnpm typecheck       # validates all metadata against @objectstack/spec
pnpm test            # unit tests
pnpm lint            # code style
pnpm build           # full build
```

CI 在每個 PR 上執行相同的檢查。

## 把客製化放在哪裡

在 `packages/` 下加入一個**新套件**，而不是編輯核心套件。這能讓你在 HotCRM 發布更新時保持可升級。

```bash
packages/
  acme-crm-extension/    # your customisations
```

你的套件可以 `extends:` 任何核心物件，針對現有 Copilot 註冊新技能，並在內建的頁面/檢視/儀表板旁邊加入新的。
