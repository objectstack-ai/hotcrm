# 費用報銷

費用報銷面向每一位為公司花錢的員工，不只是項目人員。它是 HotCRM 的一個模組，有自己的應用 **Expenses**，管理員可以把它關掉。

出差前先申請，請填寫[出差申請](/zh-Hant/docs/expenses/travel-requests)。

## 記錄一筆費用

在 **Expenses** 應用裡打開 **My Expenses**，點 **New**：

| 欄位 | 填寫什麼 |
| --- | --- |
| **Description** | 這筆錢花在哪裡 |
| **Date** | 什麼時候花的 |
| **Category** | Travel、Lodging、Meals、Equipment 或 Other |
| **Amount** | 花了多少，使用貴公司的本位幣。外幣票據請先換算再錄入 |
| **Paid By** | **Employee**（你先墊付，再報銷給你，預設值）或 **Company**（例如用公司卡支付） |
| **Merchant** | 在哪裡花的，可選 |
| **Receipt Number** | 票據上的號碼，如有 |
| **Billable** | 是否向客戶收取 |

在 **Files** 分頁上傳票據。**Source** 說明這筆記錄從哪裡來：你手動填寫時是 **Manual**，由助手或匯入寫入時是 **Agent** 或 **Import**。啟用項目交付後，表單上還有 **Project**：見[項目上的費用](#on-a-project)。

## 提交報銷

在 **My Expenses** 裡勾選你的費用，在選擇列中點 **Submit for Reimbursement**。只報一筆時，記錄頁上也有同一個按鈕。不需要再填寫任何內容：這些費用放進一張**報銷單**（Expense Report），報銷單在同一次點擊中送審。在 **My Reports** 裡跟進。

- **每個項目一張報銷單。**啟用項目交付後，每個項目的費用各自放進一張報銷單，其餘的另放一張；一次出差涉及兩個項目，就生成兩張報銷單。見[項目上的費用](#on-a-project)。
- 報銷單的 **Title** 是這些費用的日期範圍。**Total** 彙總單上每一筆費用；**To Pay Back** 只彙總員工墊付的費用。
- 只能提交你自己的、尚未放進報銷單且未批准的費用。勾選的費用中只要有一筆不符合，就一筆也不提交，提示會逐筆寫明原因。

費用的狀態跟隨所在的報銷單，你不需要自己設定。

| 報銷單狀態 | 含義 |
| --- | --- |
| **Draft** | 已撤回，或被駁回後重新打開。單上的費用可以再次修改 |
| **Submitted** | 等待審批。報銷單及其費用被鎖定 |
| **Approved** | 已批准，等財務把錢報銷給你 |
| **Paid** | 財務已記錄錢報銷給你。最終狀態 |
| **Rejected** | 被退回。點 **Back to Draft**，修改費用後再點 **Submit** |

## 由誰審批

- **你的上級**，即你使用者記錄上的 **Manager**。沒有上級時，改由 **Finance Controller** 決定。
- **Total** 達到 **2,000** 或以上的報銷單，隨後還要交給 **Finance Controller** 審批，他們也批准後才算批准。

審批人在 **Inbox**（在 **My Work** 下）裡點 **Approve** 或 **Reject**。**Reports to Approve** 列出等你審批的報銷單，可以先打開查看，單上的每一筆費用也都能打開。沒有人審批自己的報銷單，也沒有人能手動設定 **Approved** 或 **Rejected**。

**想撤回？** 在等待期間從 Inbox 裡撤回報銷單，它連同費用回到 **Draft**；點 **Submit** 即可再次送審。只有 Draft 狀態的報銷單可以刪除，單上的費用會保留，可以再次提交。

## 報銷付款

已批准的報銷單列在 **Finance Controller** 和 **AR Accountant** 的 **Reports to Pay** 裡。錢到了員工手上之後，他們點 **Mark as Paid**，填寫付款日期，如有付款參考號也一併填寫。HotCRM 只記錄這次付款：不會轉出任何款項，也不記帳。已付款的報銷單不能再修改。

## 誰能看到什麼

你能看到自己的費用和報銷單，以及請你審批的報銷單。財務在 **All Expenses** 裡能看到所有費用，也能看到所有報銷單，銷售經理和銷售管理層也能看到。沒有人手動新建報銷單：報銷單由 **Submit for Reimbursement** 產生。

## 項目上的費用 [#on-a-project]

啟用[項目交付](/zh-Hant/docs/projects)後，費用可以選擇一個 **Project**。項目人員在項目交付應用的 **Time and Expenses** 下也能找到 **My Expenses** 和 **Reports to Approve**。

- **Submit for Reimbursement** 會把每個項目的費用各自放進一張寫明該項目的報銷單。這張報銷單由**該項目的項目經理**審批，而不是你的上級；Total 達到 2,000 或以上再交給財務。
- 報銷單批准後，單上的費用計入項目成本：見[工時和費用如何成為項目的成本](/zh-Hant/docs/projects/time-and-expenses#如何成為項目的成本)。標記已付款不會改變這些數字。
- **Project** 選擇框不提供 Closed 或 Cancelled 的項目。如果仍在這樣的項目上，或在勾選了 **Lock Time and Expenses** 的項目上提交了報銷單，報銷單會退回 **Draft**，你會在 Inbox 裡收到一條寫明項目名稱的通知。項目被鎖定時，等解除鎖定後再次提交；項目已關閉或已取消時，刪除這張報銷單，把費用改掛到進行中的項目後重新提交。
- 費用在報銷單上時（哪怕報銷單是 **Draft**），不能改它的 **Project**：報銷單按提交時的項目交給審批人。要改項目，先刪除這張 Draft 報銷單（費用會被釋放），再改項目、重新提交。

關閉項目交付後，費用和報銷單上都不顯示項目欄位，每次勾選只產生一張報銷單，所有報銷單都交給你的上級審批。費用和報銷單原來選的項目會保留，重新啟用項目交付後再次顯示。

## 從逐筆審批升級

在有報銷單之前，每筆費用單獨提交、單獨審批。**Approved** 的費用保持已批准，仍計入所在項目的成本；它不在任何報銷單上，因此沒有付款記錄。Rejected 的費用和其他費用一樣提交。升級時**正在等待審批**的費用已無法再審批：批准它原來的請求，會提示該審批已無法繼續。提交人用 **Submit for Reimbursement** 把它報上去（它接受不在任何報銷單上的 Submitted 或 Rejected 費用，把它和其他費用一起報銷），然後在 Inbox 裡撤回原來的請求，讓它從審批人的列表中消失（管理員也可以撤回）。只撤回不提交報銷時，費用保持 **Submitted**。
