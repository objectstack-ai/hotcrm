# 项目概览——仪表盘统计什么

写给项目总监、项目管理办公室、财务和项目经理。**项目交付**应用中的**项目 → 项目概览** 显示你能查看的所有项目的预算、成本、毛利和工时。

## 金额统计哪些项目

- **只统计正在花钱的项目。** 金额磁贴统计**进行中**、**暂停**和**已完成**的项目。草稿或审批中的项目有预算但还没有成本；已关闭或已取消的项目已经结束。**按状态统计项目**是唯一统计所有项目的磁贴。
- **只统计已批准的成本**，与项目记录上显示的数字相同：草稿或等待审批的工时单还不算成本。
- **预算使用率是整个项目组合的。** 它是所统计项目的实际成本合计除以批准预算合计，而不是各项目百分比的平均值，所以大项目的权重比小项目大。
- **按预算状态统计项目**不包括没有预算的项目。

## 统计哪些工时

- **只统计已批准的工时单。** **每周已批准工时**和**各人员可计费占比**统计已批准工时单上的工时；已提交和草稿状态的工时在批准之前不计入。每条工时计在它实际发生的那一周，所以一张跨周的工时单会分到两周里。
- **可计费占比**是每个人的计费工时占全部工时的比例。不计费人员安排的工时计入总数，但不计入计费部分。

## 没有日期筛选

一个项目要持续好几个月，按日期截取项目会把正在进行的项目排除在它自己的数字之外，所以仪表盘没有日期筛选。工时磁贴改为按周排列。

## 谁能看到什么

仪表盘统计你能查看的内容。项目经理统计自己管理的项目；财务、项目总监和项目管理办公室统计所有项目。只作为团队成员被安排在项目上的人，在记录上看不到项目成本，也不会看到这个仪表盘；通过链接打开时，只显示不含成本的磁贴。
