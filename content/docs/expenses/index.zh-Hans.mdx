# 费用报销

费用报销面向每一位为公司花钱的员工，不只是项目人员。它是 HotCRM 的一个模块，有自己的应用**费用报销**，管理员可以把它关掉。

## 记录一笔费用

在**费用报销**应用里打开**我的费用**，点**新建**：

| 字段 | 填写什么 |
| --- | --- |
| **描述** | 这笔钱花在哪里 |
| **日期** | 什么时候花的 |
| **类别** | 差旅、住宿、餐饮、设备或其他 |
| **金额** | 花了多少，使用贵公司的本位币。外币票据请先换算再录入 |
| **付款方** | **员工**（你先垫付，再报销给你，默认值）或**公司**（例如用公司卡支付） |
| **商户** | 在哪里花的，可选 |
| **票据号** | 票据上的号码，如有 |
| **可计费** | 是否向客户收取 |

在**附件**标签页上传票据。**来源**说明这条记录从哪里来：你手工填写时是**手工录入**，由助手或导入写入时是**智能体**或**导入**。启用项目交付后，表单上还有**项目**：见[项目上的费用](#on-a-project)。

## 提交和审批

| 状态 | 含义 |
| --- | --- |
| **草稿** | 还在填写 |
| **已提交** | 已送审，等待期间锁定 |
| **已批准** | 最终状态 |
| **已驳回** | 被退回。改回草稿，修改后重新提交 |

把状态改为**已提交**即送审。由谁决定：

- **你的上级**，即你用户记录上的**上级**。没有上级时，改由**财务控制**决定。
- 金额达到 **2,000** 或以上的费用，随后还要交给**财务控制**审批，他们也批准后才算批准。

审批人在**待我审批**（在**我的工作**下）里点**批准**或**驳回**。**待我审批的费用**列出等你审批的费用，可以先打开查看。没有人审批自己的费用，也没有人能手动设置**已批准**或**已驳回**。

**想撤回？**在等待期间从待我审批里撤回，费用回到**草稿**。

## 谁能看到什么

你能看到自己的费用，以及请你审批的费用。财务在**全部费用**里能看到所有费用，销售经理和销售管理层也能看到。

## 项目上的费用 [#on-a-project]

启用[项目交付](/zh-Hans/docs/projects)后，费用可以选择一个**项目**。项目人员在项目交付应用的**工时与费用**下也能找到**我的费用**和**待我审批的费用**。

- 项目上的费用由**该项目的项目经理**审批，而不是你的上级；金额达到 2,000 或以上再交给财务。
- 批准后计入项目成本：见[工时和费用如何成为项目的成本](/zh-Hans/docs/projects/time-and-expenses#如何成为项目的成本)。
- **项目**选择框不提供已关闭或已取消的项目。如果仍在这样的项目上，或在勾选了**锁定工时与费用**的项目上提交了费用，费用会退回**草稿**，你会在待我审批里收到一条写明项目名称的通知。

关闭项目交付后，表单上不显示项目字段，所有费用都交给你的上级审批。费用原来选的项目会保留，重新启用项目交付后再次显示。
