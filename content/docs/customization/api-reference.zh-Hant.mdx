# API 參考

HotCRM 執行在 ObjectStack 上。Web UI、自動化、動作和 AI skills 都使用 `objectstack.config.ts` 註冊的同一套物件中繼資料。

## 本機地址

本機執行：

```bash
pnpm dev
```

應用地址：

```text
http://localhost:4001
```

物件 API 由 ObjectStack runtime 提供。路由形態可能隨 runtime 版本和啟用能力變化，因此在環境中可用時，請優先使用 runtime API explorer。

## 目前物件

物件清單在此**不再**轉抄 —— `src/objects/*.object.ts` 是它的事實來源，一個物件一個檔案，
各自註冊以 `crm_` 為前綴的 `name`。資料模型涵蓋四個業務領域：銷售、服務、市場和營收。

## ObjectQL 形態

在 actions、flows、hooks 和整合中呼叫 ObjectStack 資料層時，使用 ObjectQL 風格的過濾和欄位選擇。

```json
{
  "filters": [
    ["stage", "in", ["proposal", "negotiation"]],
    ["amount", ">", 100000]
  ],
  "sort": [{ "field": "amount", "direction": "desc" }],
  "limit": 50,
  "fields": ["id", "name", "amount", "stage", "crm_account"]
}
```

常用操作符包括 `=`, `!=`, `>`, `>=`, `<`, `<=`, `in`, `not_in`, `between`, `contains`, `starts_with`, `ends_with`, `is_null`, `is_not_null`。

## 動作體

HotCRM actions 可以包含帶受限能力的可執行中繼資料體。

```ts
export const CreateCampaignAction = {
  name: 'create_campaign',
  objectName: 'crm_lead',
  type: 'modal',
  body: {
    language: 'js',
    capabilities: ['api.write'],
    source: `
      await ctx.api.object('crm_campaign_member').insert({
        crm_campaign: input.campaign,
        crm_lead: input.leadId,
        status: 'sent'
      });
    `,
  },
};
```

## 驗證

修改面向 API 的中繼資料後執行：

```bash
pnpm validate
pnpm typecheck
pnpm test
```

發布前執行 `pnpm verify`。
