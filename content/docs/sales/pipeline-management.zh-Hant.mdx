# 銷售管道管理

銷售管道是你所有開放商機的總和。HotCRM 為你提供一個受治理的銷售管道，其中階段推進、贏單機率和預測值都會自動保持同步——銷售代表專注於銷售，而非資料衛生。

## 機率是如何設定的

贏單機率會**根據階段自動設定**，因此每位銷售代表的預測都使用相同的數字：

| 階段 | 預設贏單機率 |
| --- | --- |
| 開發期 | 10 % |
| 資格審核 | 25 % |
| 需求分析 | 40 % |
| 提案 | 60 % |
| 談判 | 80 % |
| 贏單 | 100 % |
| 輸單 | 0 % |

如果你有特殊情況，可以在單筆交易上手動覆蓋機率，但下次階段變化時該覆蓋會被重置。這能防止銷售代表手動抬高其預測。

> 管理員可以按階段調整百分比——參見 [Administration › Automation](/zh-Hant/docs/administration/automation)。

## 預期營收是如何計算的

**預期營收 = 金額 × 機率 ÷ 100**

這個數字是加權預測的核心。每當金額或機率變化時（包括來自階段變化的自動更新），它都會自動重新計算。

**銷售儀表板**會在開放銷售管道上對*預期營收*求和，從而給你本季度的加權預測。

## 銷售管道看板視圖

**銷售管道看板**（側邊欄快捷方式**銷售管道**）將銷售管道顯示為 7 列——每個階段一列。每張卡片顯示：

- 商機名稱
- 客戶
- 金額
- 成交日期
- 負責人頭像

要推進一筆交易，只需**拖動卡片**到下一列。系統會強制執行階段規則，因此你無法從*開發期*直接拖到*贏單*。

在每列頂部，你會看到兩個數字：

- **未加權合計**（金額之和）
- **加權合計**（預期營收之和）

## 銷售管道健康訊號

一些衍生欄位會暴露交易風險，讓你能在每週回顧中據此採取行動：

| 訊號 | 它告訴你什麼 |
| --- | --- |
| **當前階段停留天數** > 30 | 交易停滯——推進或關閉它。 |
| **成交日期已過** 且階段仍開放 | 預測有誤；重設日期或接受失單。 |
| **金額 > $500K** 但未提交審批 | 在此交易可成交之前需要折扣審批。 |
| **已設定競爭對手** 但無制勝計劃 | Sales Copilot 可以建議一個策略。 |

當你提問 *"what's slipping?"* 或 *"how does my pipeline look?"* 時，Sales Copilot 會呈現有風險的交易。

## 值得收藏的銷售管道報告

你會在側邊欄的**報告**部分找到這些：

| 報告 | 它顯示什麼 |
| --- | --- |
| **銷售管道覆蓋率（季度）** | 我們對即將到來的季度是否覆蓋了 3 倍配額？季度 × 階段矩陣。 |
| **按負責人 → 階段的漏斗** | 每位銷售代表的漏斗健康——發現漏水的階段。 |
| **按階段的商機** | 按階段的銷售管道柱狀圖。 |
| **按負責人的贏單** | 用於季末表彰的排行榜。 |
| **客戶流失訊號** | 現有客戶的開放案例 + 低 NPS = 流失風險。 |

詳情參見 [Analytics › Reports](/zh-Hant/docs/analytics/reports)。

## 推薦的銷售管道節奏

| 節奏 | 該做什麼 |
| --- | --- |
| **每日** | 打開銷售管道看板。找出停滯的卡片（階段內 > 14 天）。推進或關閉。 |
| **每週** | 執行*銷售管道覆蓋率*。向 Sales Copilot 提問：*"what's at risk?"* |
| **每月** | 執行*按負責人 → 階段的漏斗*。對漏斗漏水的銷售代表進行一對一輔導。 |
| **季末** | 執行*按負責人的贏單*以計算提成。歸檔輸單交易並附上*失單原因*。 |

## 預測彙總

銷售經理 / 總監的預測視圖由以下部分構建：

- **商機**分析立方體（度量：金額之和，維度：階段）
- **銷售儀表板**小工具（按階段的銷售管道、贏單率、頂級交易）
- **銷售管道覆蓋率**報告（季度 × 階段矩陣）

它們共同回答：*"我們是否有足夠的銷售管道來完成本季度，以及風險在哪裡？"*

## 給銷售代表的提示

- ✅ 及時推進階段——如果你的階段錯了，你的預測就是錯的。
- ✅ 使用*後續步驟*——你的經理每週一站會都會讀它。
- ❌ 不要滑動成交日期來掩蓋滑移；使用*輸單*並附上原因。

## 給銷售經理的提示

- ✅ 每月執行*按負責人 → 階段的漏斗*，以發現漏斗漏水的銷售代表。
- ✅ 在 QBR 中使用*按季度的銷售管道覆蓋率*來設定下一季度的目標。
- ✅ 輔導銷售代表填寫*競爭對手*——它能顯著提升 Copilot 的品質。

## 給管理員的提示

- 新增或移除階段？你需要更新三處：商機物件上的選擇列表、設定機率的工作流規則，以及控制狀態轉換的狀態機。參見 [Customization › Extending Objects](/zh-Hant/docs/customization/extending-objects)。
- $100K *大單*通知閾值位於商機工作流規則中。
