# 项目计划——任务、甘特图和完成百分比

写给项目经理，以及查看计划的团队成员。项目的计划就是它的**项目任务**：应用中的**项目计划**把这些任务画在甘特图上，项目的**完成百分比**也由它们计算。

## 谁来写计划

- **项目经理、项目负责人和管理员**可以新增、修改和删除任务：写任务需要有项目的编辑权限。
- **团队成员只读。** 被安排在项目上的人能看到所有任务，但不能修改，自己的进度请告诉项目经理。
- 财务、项目总监和项目管理办公室可以查看所有项目的计划。

## 一项任务

- **上级任务**把一项任务放到另一项任务下面。有子任务的任务是**汇总任务**：它自己的工时和百分比不计入任何地方。应用中的**任务树**把子任务显示在汇总任务下面。
- **前置任务**是这项任务开始前必须完成的任务。甘特图把每个前置任务画成一条指向这项任务的箭头。
- 上级任务和前置任务都必须是**同一项目**的任务。如果选的上级任务是这项任务自己的子任务，会被拒绝，否则计划会绕成一个圈。
- **里程碑**标记一个检查点，比如上线评审。它画成菱形，通常没有计划工时。
- 标为**已完成**的任务，**完成百分比**自动设为 100。**已取消**的任务留在计划里，但不再计入。

## 甘特图

- **在哪里看：** 应用中的**项目计划**显示你能查看的所有任务，前置任务画成箭头，里程碑画成菱形。在它的**项目**筛选里选中一个项目，就只看这个项目的计划；项目自己的页面在相关页签里列出任务，不画甘特图。子任务和汇总任务并列显示，而不是缩进在它下面；要看任务树，请打开**任务树**。
- **拖动任务条**会修改任务的计划日期，拖动进度手柄会修改完成百分比，都会立即保存。
- 甘特图工具栏上的**自动排期**会移动等待被移动任务的后续任务并保存。只有甘特图会这样做：在任务表单里、通过导入或 API 修改日期，只移动这一项任务，后续任务的日期保持不变，直到有人去移动它们。

## 记到任务上的工时

工时明细有一个可选的**任务**，从工时单所属项目的任务中选择。任务的**实际工时**汇总所有选了它的工时明细，不管工时单处于什么状态，所以项目经理能随时看到已投入的工作量。这些工时的成本仍然只在工时单批准后才计入。

## 项目的完成百分比

项目的**完成百分比**不再手工填写，每次任务变化时自动计算：

1. 取**没有子任务**的任务，去掉**已取消**的任务。
2. 用每项任务的**计划工时**给它的完成百分比加权（已完成的任务按 100 计）。
3. 除以计划工时总数。

所以一项 40 小时、完成一半的任务加上一项 10 小时、已完成的任务，结果是 60%，而不是简单平均的 75%。如果计入的任务都没有计划工时，每项任务权重相同。没有可计入任务的项目不显示百分比。
