# 项目与人员安排

## 新建项目

项目经理在**全部项目**中点**新建**，或者在客户、商机、合同的**项目**标签页中新建项目。项目需要填写**项目名称**和**客户**；**商机**和**合同**会从该客户下提供可选项。

每个项目都有一个**类型**：

| 类型 | 用途 |
| --- | --- |
| **售前** | 为赢单所做的工作：概念验证、试点、范围调研 |
| **交付** | 客户购买的工作。如果之前有售前项目，**来源售前项目**指向它 |
| **内部** | 为本公司做的工作：能力建设、培训、工具 |

三种类型的工时填报、人员安排和成本计算方式完全相同，所以售前和内部投入也会和交付一样体现为成本。**计费方式**（固定总价、按人天计费、包年服务、不计费）记录客户如何付费。

## 状态

项目从**草稿**开始，每次向前推进一步：

| 从 | 到 |
| --- | --- |
| 草稿 | 审批中、已取消 |
| 审批中 | 已批准、已驳回、退回草稿、已取消 |
| 已批准 | 进行中、已取消 |
| 已驳回 | 草稿、已取消 |
| 进行中 | 暂停、已完成、已取消 |
| 暂停 | 进行中、已取消 |
| 已完成 | 已关闭，或退回进行中 |
| 已关闭、已取消 | 终态 |

其他任何变更都会被拒绝，提示信息会列出这些步骤。项目经理不会删除项目：不再进行的项目设为**已取消**，完成的项目设为**已关闭**。

## 预算

**批准预算**是项目可以花的成本。请在项目处于**草稿**或**已驳回**时填写：从**审批中**开始它就变为只读，因为项目正是按这个数字获批的。**计划收入**是客户为这个项目支付的金额，毛利以它为基准计算。

项目的[成本和毛利字段](/zh-Hans/docs/projects#money)会随工时和费用的批准自动填写。项目花费超过批准预算时，**预算使用率**会超过 100%。

## 为项目安排人员

在项目的**项目成员**标签页或**人员安排**中为项目安排人员。每一行包括：

| 字段 | 含义 |
| --- | --- |
| **人员** | 安排的是谁 |
| **职责** | 他在项目上的角色：项目经理、项目总监、客户经理、架构师、顾问、质量保证、财务伙伴或分包商 |
| **费率卡** | 他的工作职级。他的工时按这张卡的单价计算成本和计费 |
| **投入比例** | 他投入这个项目的时间占比 |
| **开始日期**、**结束日期** | 他在项目上的时间 |
| **可计费** | 他的工时是否向客户计费。不可计费成员的工时仍然计入成本，但不计费 |

安排一个人会对项目产生两个效果：

- **他可以查看项目。**项目的**项目团队**列出所有被安排的人，每个人都能查看这个项目。删除这一行，他就失去这份访问权限。
- **职责为项目经理的成员成为项目的项目经理。**这个人可以编辑项目、安排人员，并审批项目的工时单和费用。项目上的这个字段是只读的：要改项目经理，就改人员安排。

> **先把自己安排上。**新项目在有人以项目经理职责被安排之前没有项目经理。新建项目的人作为项目负责人可以编辑它，但在安排项目经理之前创建的工时单和费用没有审批人。

只有被安排在项目上的人才能在这个项目上填报工时。

## 费率卡

**费率卡**是一个工作职级，带有两个价格：

| 字段 | 含义 |
| --- | --- |
| **成本单价** | 这个职级一小时或一天让公司付出的成本 |
| **计费单价** | 向客户收取的价格 |
| **单位** | 按小时或按天。一天按 8 小时计 |
| **职级** | 初级、中级、高级、资深或专家 |
| **内部** | 用于内部工作。只有内部费率卡的计费单价可以低于成本单价 |
| **生效日期**、**失效日期** | 这张卡的使用期间，仅供参考：以成员那一行上的费率卡为准 |

费率卡由财务和项目管理办公室维护。所有人都能查看，但成本单价对项目成员隐藏。

> **修改费率卡不会改变过去的成本。**每条工时明细在保存时都会复制当时有效的单价。修改之前填报的工时保留旧单价，修改之后填报的工时使用新单价。
