# 发票与回款——由谁录入，什么算逾期

写给销售，也写给财务（**应收会计**岗位）。发票和回款是财务在自己系统中开具和收到的记录。财务录入或导入它们；销售只查看、从不录入，所以销售看到的每个数字都是财务写的。

## 界面上看不出的规则

- **到期日。** 留空时，保存时自动填写：**开票日期**加上合同的**付款条件**（Net 15、30、60 或 90 天；Due on Receipt 即开票当天）。财务填写的日期会保留。
- 发票的**未付**是**金额**减去**已付**，每当针对它的回款保存时随之更新。**已作废**的发票未付为零，并退出所有统计。
- **逾期。** **订单与回款 → 发票 → 逾期发票**列出状态为**已开具**、**到期日**早于今天且仍有**未付**金额的发票。
- **每张发票一笔回款。** 一笔收款支付多张发票时，每张发票记录一笔回款；没有分摊。
- **回款的发票必须属于它的合同。** 否则保存会被拒绝，并写明是哪张发票。
- **票据。** **方式**为**票据**时，**票据到期日**必填：款项在回款日期即计为已回款，到期日说明它何时兑付为现金。

## 导入

财务使用 **Invoice Import (CSV)** 和 **Payment Import (CSV)** 导入。**ERP 编号**列是唯一键：编号已在某条记录上的行会更新这条记录，而不是新增一条。每条导入的记录**来源**为**导入**，并带有**同步时间**（导入的时刻）。合同用合同编号（CTR-0001）指定，发票用发票号码，回款节点用节点名称。
