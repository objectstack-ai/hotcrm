# 快速導覽

帶你導覽你每天都會用到的畫面。

## 1. 主頁儀表板

你看到的第一個東西是 **CRM Overview** 儀表板。它告訴你：

- 你有多少**開啟的線索**。
- 你的管道中有多少**商機**。
- 任何**等待你回應**的案例。
- 按管道價值排名的頂級客戶。
- 近期活動（最近的通話、會議、郵件）。

把它當作你每日開始工作的著陸頁。如果你是經理，你還會看到團隊級彙總。

➜ 了解更多：[儀表板](/zh-Hant/docs/analytics/dashboards)

## 2. 應用啟動器

點擊**應用啟動器**（左上角網格圖示）以在應用之間切換：

- **Enterprise CRM** —— 包含所有 CRM 功能的主應用。
- **Admin** —— 面向系統管理員。

在 Enterprise CRM 內，左側導覽按以下方式分組：

| 分組 | 內容 |
| --- | --- |
| **Sales** | Leads、Accounts、Contacts、Opportunities、Quotes、Contracts |
| **Service** | Cases、Knowledge Base |
| **Marketing** | Campaigns、Campaign Members |
| **Products** | Products |
| **Activities** | Tasks、Events |
| **Analytics** | Dashboards、Reports |
| **AI** | Copilot、Knowledge Bases |
| **Approvals** | Approval Requests、Action History |

## 3. 你的第一條線索

**線索**是已表達興趣但尚未通過資格審查的人。

1. 點擊 **Sales → Leads → New**。
2. 填寫 **Name**、**Company**、**Email**。
3. 儲存。線索會自動指派給你。
4. 在潛在客戶詳情頁上請助手 *「判定此潛在客戶資格」* —— [潛在客戶資格判定技能](/zh-Hant/docs/ai-copilot/sales-copilot) 會按 BANT 給出 0–100 的評分並建議下一步操作。
5. 準備就緒後，點擊 **Convert** 一步將線索轉換為 Account + Contact + Opportunity。

➜ 了解更多：[線索](/zh-Hant/docs/sales/leads)

## 4. 你的第一個商機

**商機**是你正在處理的真實交易。

1. 由線索轉換自動建立，或 **Sales → Opportunities → New**。
2. 設定 **Account**、**Amount**、**Close Date**、**Stage**。
3. 隨著交易推進，將其在各階段間移動：*Prospecting → Qualification → Proposal → Negotiation → Closed Won*。
4. 系統會強制執行[狀態機](/zh-Hant/docs/administration/state-machines) —— 你不能隨意跳過階段。
5. 點擊 **✍️ Draft Email** 讓 AI Copilot 起草一封符合上下文的跟進郵件。
6. 透過將階段設定為 *Closed Won* 來贏單 —— 系統會自動建立合約並通知團隊。

➜ 了解更多：[商機](/zh-Hant/docs/sales/opportunities)

## 5. 一個服務案例

**案例**是一個客戶問題。

1. 案例透過郵件、Web 表單、電話、聊天或入口網站到達。
2. 新案例進入佇列 —— 專員接手。
3. 在新工單上請助手 *「分流此工單」* —— [工單分流技能](/zh-Hant/docs/ai-copilot/service-copilot) 會建議優先順序、分類以及匹配的知識庫文章。
4. SLA 計時器開始 —— 在案例頁面查看回應時間 / 解決時間倒數計時。
5. 回覆客戶；解決後關閉案例。

➜ 了解更多：[案例](/zh-Hant/docs/service/cases)

## 6. AI Copilot

Copilot 位於每個頁面的**右側聊天面板**。問它：

- *「本週我的管道裡有什麼風險？」*
- *「給我 [客戶名稱] 的客戶 360。」*
- *「為這條線索起草一封發現跟進郵件。」*
- *「我本季度的預測是多少？」*

它從你的 CRM 資料中讀取並遵守你的共享 —— 你無法讓它洩露你本就看不到的記錄。

➜ 了解更多：[AI Copilot](/zh-Hant/docs/ai-copilot/index)
