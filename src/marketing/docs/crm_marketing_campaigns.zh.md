# 营销活动——成员、响应与投资回报

写给市场人员，也写给要了解市场部在做什么的销售团队。营销活动是一次市场推广（一封邮件、一场线上研讨会、一次展会），有预算、起止日期和它触达的人员名单。本页说明它的各个数字统计的是什么，让你知道什么时候可以相信它们，什么时候不能。

## 营销活动的状态

| 状态 | 含义 |
| --- | --- |
| **规划中** | 正在准备。已经可以加入成员。 |
| **进行中** | 正在开展。可以加入成员，成员的回应会被记录。 |
| **已完成** | 已结束。不再加入新成员，所以成员相关的数字停留在结束时的样子；之后赢单且关联了它的商机，仍会计入它的收入。 |
| **已中止** | 未完成就取消了。不再加入新成员。 |

**结束日期**已过的**进行中**活动会自动设为**已完成**：见[营销活动自动化](./crm_marketing_automation.md)。活动提前结束时，你也可以自己把它设为已完成。

每次保存都执行两条规则：**结束日期**必须晚于**开始日期**，两者都必填。**实际成本**超过**预算成本**不会阻止保存；它是留给你注意的。

## 成员及其状态

**营销活动成员**是某个人在某个营销活动中的一条记录：要么是线索，要么是联系人，不能两者都是，并且每个活动只能出现一次。一个人以线索身份加入一次、又以联系人身份加入一次，就是两条成员记录。人员如何加入活动，见[营销活动自动化](./crm_marketing_automation.md)。

| 成员状态 | 含义 | 由谁设定 |
| --- | --- | --- |
| **已发送** | 活动触达了他们。每个新成员都从这里开始。 | 加入活动时 |
| **已响应** | 他们有了回应：回复、报名、下载。 | 由可编辑成员的人在成员上点**标记为已响应** |
| **已转化** | 他们的线索成为了客户。 | 该线索转化时自动设定 |
| **已退订** | 他们要求不再接收你的消息。 | 由可编辑成员的人在成员上设定 |

大多数成员停留在**已发送**。处于**已发送**或**已响应**的成员，其线索转化后会自动变为**已转化**；**已退订**的成员永远不会。把成员设为**已退订**，还会在对应线索上勾选**拒收邮件**（联系人上为**拒绝邮件**），使这个人不再进入之后的任何活动。

HotCRM 不跟踪打开、点击或退信。它能观察到的是一个人作出回应、一条线索完成转化，它的成员状态也就只有这些。

## 各个数字统计的是什么

这些数字就在营销活动记录上，并且随时保持最新：成员加入、回应或移除，其线索转化，以及商机关联到该活动时都会重算。正在进行的活动显示的就是真实数字，不必等它结束。

- **发送数量**——活动的全部成员，不论状态。
- **响应数量**——处于**已响应**或**已转化**的成员：线索已转化的成员也算作回应过。
- **响应率（%）**——响应数量占发送数量的比例。
- **线索数量**——成员中不同线索的个数。
- **已转化线索数**——这些线索中已转化的个数。
- **已创建商机数**——**营销活动**字段为本活动的商机。
- **已赢得商机**——这些商机中处于**成交**的个数。
- **实际收入**——这些赢单商机的金额之和。

## 投资回报率统计什么

**投资回报率（%）**是（**实际收入** − **实际成本**）÷ **实际成本**，以百分比表示。由此可知三点：

- **只计赢单。** 未成交的商机不论多有希望，都不计入**实际收入**。
- **只计关联了本活动的商机。** 商机通过它的**营销活动**字段归属某个活动，每个商机只归属一个。请在商机上填写它：没有任何机制会替你填写，线索转化也不会；没有填写的商机不会给活动带来任何收入。
- **填写成本之前投资回报率为 0。** 没有**实际成本**，就没有衡量回报的基数，**投资回报率（%）**显示为 0。知道成本后请尽快填写。
