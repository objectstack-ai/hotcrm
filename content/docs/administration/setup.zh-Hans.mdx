# 设置清单

为新 HotCRM 管理员准备的实用的第一周清单。请按顺序逐项完成 —— 每个部分都建立在前一个之上。

## ✅ 第 1 天 —— 基础

### 1. 公司资料

导航至 **设置 → 公司信息**：

- [ ] 公司名称、地址、时区、默认货币
- [ ] 财年起始月份（所有预测报表都会用到）
- [ ] 默认语言

### 2. 工作时间

**设置 → 工作时间**：

- [ ] 工作日（例如周一至周五）
- [ ] 工作时段（例如上午 9 点 – 下午 6 点）
- [ ] 当年的假期

工作时间驱动 [SLA 计算](/zh-Hans/docs/service/sla-and-escalation) —— 例如“在 8 个工作小时内解决”就用到了这些。

### 3. 电子邮件设置

**设置 → 电子邮件**：

- [ ] 案例的入站邮件转发（例如 `support@yourdomain.com`）
- [ ] 出站邮件签名模板
- [ ] 用于发件人身份验证的 DKIM / SPF

## ✅ 第 2 天 —— 人员

### 4. 用户邀请

**设置 → 用户**：

- [ ] 导入或邀请所有用户
- [ ] 为每个用户分配一个 [权限档案](/zh-Hans/docs/administration/profiles)
- [ ] 在层级中为每个用户分配一个角色
- [ ] 为每个用户设置一名经理（驱动审批路由）

### 5. 角色层级

**设置 → 角色**：

- [ ] 确认默认层级（高管 → 总监 → 经理 → 代表）与你的组织相符
- [ ] 为区域或专门团队添加自定义角色

### 6. 权限档案与权限

**设置 → 权限档案**：

- [ ] 审查六种内置权限档案（参见 [权限档案](/zh-Hans/docs/administration/profiles)）
- [ ] 如有需要，克隆并自定义（例如一个删除权限有限的 *初级销售代表* 权限档案）

## ✅ 第 3 天 —— 数据基础

### 7. 客户与联系人所有权

- [ ] 为客户和联系人决定组织范围默认值（私有 vs 公开读取 vs 公开读/写）—— 参见 [共享与安全](/zh-Hans/docs/administration/sharing-and-security)
- [ ] 如果你以小组而非单个代表的方式销售，配置客户团队

### 8. 潜在客户路由

**设置 → 潜在客户设置**：

- [ ] 默认潜在客户所有者 / 队列（无规则匹配时）
- [ ] 路由规则（按区域、行业、来源）
- [ ] 对来自网页表单的新潜在客户的自动回复邮件

### 9. 产品目录

- [ ] 导入 [产品](/zh-Hans/docs/revenue/products) —— 至少：代码、名称、标价、计费类型
- [ ] 设置产品经理（每条产品线的联系人）
- [ ] 上传数据表（馈送 AI Copilot 的产品信息知识库）

## ✅ 第 4 天 —— 流程

### 10. 商机阶段

确认 7 阶段默认管道与你的销售流程相符。各阶段及其概率为：

| 阶段 | 概率 |
| --- | --- |
| Prospecting | 10% |
| Qualification | 25% |
| Proposal | 40% |
| Negotiation | 60% |
| Closed Won | 100% |
| Closed Lost | 0% |
| Closed Without Decision | 0% |

如果你的流程不同，请在 **设置 → 商机 → 阶段** 中调整。

### 11. 案例 SLA

确认默认的 [SLA 矩阵](/zh-Hans/docs/service/sla-and-escalation)：

| 优先级 | 首次响应 | 解决 |
| --- | --- | --- |
| Critical | 1 小时 | 4 小时 |
| High | 2 小时 | 8 小时 |
| Medium | 4 小时 | 2 个工作日 |
| Low | 1 个工作日 | 7 个工作日 |

如果你的支持承诺不同，请进行调整。

### 12. 审批流程

- [ ] 确认折扣审批阈值（默认 $500K）—— 参见 [审批](/zh-Hans/docs/revenue/approvals)
- [ ] 确认审批人（按角色：经理 + 总监）
- [ ] 通过提交一个示例商机进行测试

## ✅ 第 5 天 —— 知识与 AI

### 13. 知识库

- [ ] 用你最热门的 20 篇 FAQ 文章为 **支持知识** 填充种子内容
- [ ] 用你的销售指南为 **销售知识** 填充种子内容
- [ ] 用你最重要的 5 个竞争对手的对战卡为 **竞争情报** 填充种子内容
- [ ] 产品数据表 —— 已在产品记录中（自动同步）

参见 [知识库](/zh-Hans/docs/ai-copilot/knowledge-bases)。

### 14. AI Copilot

- [ ] 确认 AI Copilot 已启用（设置 → AI）
- [ ] 选择要启用哪些技能
- [ ] 运行一个示例查询（*“给我 [测试客户] 的 Customer 360”*）以验证
- [ ] 配置数据敏感性规则 —— Copilot 必须脱敏哪些字段

## ✅ 第 6 天 —— 仪表板与报表

- [ ] 将 **CRM 概览** 固定为所有人的主页仪表板
- [ ] 设置团队专属仪表板（销售 / 服务 / 高管）
- [ ] 为经理安排每周订阅邮件
- [ ] 审查 [标准报表](/zh-Hans/docs/analytics/reports) 并自定义筛选器

## ✅ 第 7 天 —— 上线

- [ ] 运行 **迁移检查**（所有导入的记录都有所有者和必填字段）
- [ ] 运行 **冒烟测试**：创建潜在客户 → 转换 → 商机 → 报价 → 赢单 → 合同
- [ ] 培训用户掌握他们的日常工作流（45 分钟的基于角色的会话）
- [ ] 设置一个内部 **#hotcrm-help** 频道用于答疑

## 上线后

- **第 2 周**：审查仪表板使用情况和采用指标。
- **第 1 个月**：首次回顾 —— 哪些有效，哪些无效。
- **每季度**：审查权限档案、共享规则、知识库是否有漂移。
