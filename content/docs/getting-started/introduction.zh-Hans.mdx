# 简介

**HotCRM 是一款 AI 原生的企业级 CRM。** 它通过内置于每个屏幕的 AI Copilot，帮助你的团队管理整个客户旅程 —— 从首次市场触达到成交以及之后。

## 包含哪些内容

该平台涵盖四大经典 CRM 支柱，外加一个了解你数据的 AI 层：

| 支柱 | 你可以做什么 |
| --- | --- |
| [**销售**](/zh-Hans/docs/sales/index) | 管理线索、客户、联系人、商机、报价单和管道 |
| [**服务**](/zh-Hans/docs/service/index) | 跟踪案例、执行 SLA、管理知识库 |
| [**市场营销**](/zh-Hans/docs/marketing/index) | 开展营销活动、为互动评分、衡量 ROI |
| [**收入**](/zh-Hans/docs/revenue/index) | 维护产品、治理合同、路由折扣审批 |
| [**AI Copilot**](/zh-Hans/docs/ai-copilot/index) | 一个起草邮件、分流案例、汇总客户的助手 |
| [**分析**](/zh-Hans/docs/analytics/index) | 仪表盘、报表和自助式数据 cube |

一切开箱即用地**串联在一起** —— 线索转化为商机，商机关联到报价单和合同，合同触发续约，支持案例能看到客户的完整历史。

## HotCRM 面向谁

- **销售代表和经理** —— 用于处理线索、交易和预测。
- **服务坐席和经理** —— 用于按时解决客户案例。
- **营销人员** —— 用于开展营销活动并证明 ROI。
- **销售运营和管理员** —— 用于配置系统以适配你的业务。
- **高管** —— 用于贯穿整个收入漏斗的汇总视图。

## 它有何不同

### 1. AI 原生，而非附加 AI

Copilot 内置于产品中，而非外挂。它遵守你的共享规则，借助你真实的 CRM 数据，并将答案接地于你掌控的知识库。

### 2. 开箱即具备流程感知

你无需从头构建审批流程、SLA 升级或营销活动自动化。它们出厂时已按行业最佳实践配置好 —— 调整即可，无需构建。

### 3. 构建于现代化、可扩展的平台之上

HotCRM 运行于 [**ObjectStack**](https://github.com/objectstack-ai/framework) —— 一个元数据优先的运行时。这意味着每个字段、规则、页面和工作流都在 Git 仓库中以代码形式定义。无需点击各种管理 UI 而忘记改了什么。

如果你是开发者，请参见[面向开发者](/zh-Hans/docs/getting-started/for-developers)了解这在实践中意味着什么。

## 开箱即包含什么

你第一天拿到的系统已经包含：

- **13 个业务对象**（客户、线索、联系人、商机、产品、报价单、合同、案例、营销活动等），具备行业标准字段、选择列表和验证。
- **10 级角色层级**，映射到典型的销售 / 服务 / 市场营销组织结构。
- **内置自动化**，用于线索路由、商机赢单、合同到期、报价单到期、营销活动自动注册和 SLA 升级。
- **审批流程**，用于高价值折扣。
- **标准列表视图、仪表盘和报表**，面向每个角色。
- **AI 技能**，用于线索资格审查、邮件起草、案例分流、收入预测和客户 360°。
- **知识库**，用于销售剧本、产品信息、支持文章和竞争情报。
