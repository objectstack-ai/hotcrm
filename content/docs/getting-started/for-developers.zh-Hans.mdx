# 面向开发者

本页面面向使用 HotCRM 源码仓库的工程师。

## 前置条件

- Node.js 20+
- pnpm 10+
- 已克隆 `objectstack-ai/hotcrm`

## 本地运行

```bash
git clone https://github.com/objectstack-ai/hotcrm.git
cd hotcrm
pnpm install
pnpm dev
```

打开 http://localhost:4001。应用会在首次启动时加载种子数据。

## 仓库结构

HotCRM 是一个单体 ObjectStack 应用。`objectstack.config.ts` 是注册 `src/` 中全部元数据的唯一事实来源。

```text
hotcrm/
├── objectstack.config.ts
├── src/
│   ├── objects/        # *.object.ts 模型和 *.hook.ts 生命周期逻辑
│   ├── hooks/          # 把对象 hooks 汇总交给 stack 的 barrel
│   ├── actions/        # UI 动作和可执行动作体
│   ├── flows/          # 自动化流程
│   ├── skills/         # AI skills
│   ├── apps/, views/, pages/
│   ├── dashboards/, reports/, datasets/
│   ├── mappings/       # 数据导入的列到字段映射
│   ├── profiles/, sharing/
│   ├── translations/
│   ├── data/           # 种子数据
│   ├── docs/           # 随构建产物一起分发的应用文档
│   └── interfaces/     # 共享类型（目前是空 barrel）
├── apps/docs/          # Fumadocs 应用
└── content/docs/       # 文档内容
```

HotCRM 只定义 skills，不定义 agent：应用自带的两个 copilot 及其所在目录已被移除，AI 能力来自每个 ObjectStack 环境都提供的平台助手。参见 [AI Skills](/zh-Hans/docs/customization/ai-skills)。

## 文件后缀协议

| 后缀 | 定义 |
| --- | --- |
| `*.object.ts` | 数据模型 |
| `*.hook.ts` | 服务端生命周期逻辑 |
| `*.actions.ts` | UI 动作和 AI 可调用动作体 |
| `*.flow.ts` | 自动化 |
| `*.skill.ts` | AI skill |
| `*.page.ts` | UI 页面 |
| `*.view.ts` | 列表或看板视图 |
| `*.dashboard.ts` | 仪表盘 |
| `*.report.ts` | 报表 |
| `*.sharing.ts` | 共享规则 |
| `*.profile.ts` | 权限档案 |

## 常见任务

### 新增或修改对象

在 `src/objects/` 下编辑或新增文件，然后从 `src/objects/index.ts` 导出。

```ts
import { ObjectSchema, Field } from '@objectstack/spec/data';

export const Warranty = ObjectSchema.create({
  name: 'crm_warranty',
  label: 'Warranty',
  fields: {
    name: Field.text({ label: 'Warranty Name', required: true }),
    crm_account: Field.lookup('crm_account', { label: 'Account' }),
  },
});
```

### 新增 AI skill

创建 `src/skills/<name>.skill.ts`，并从 `src/skills/index.ts` 导出。从这个 barrel 导出就是全部的接线工作——skill 会附着到平台助手（`ask`）上，本应用不定义任何自己的 agent。

### 新增 UI 元数据

使用 `src/views/` 定义列表和看板视图，使用 `src/pages/` 定义记录页面，使用 `src/actions/` 定义按钮和弹窗动作。

## 验证改动

```bash
pnpm validate
pnpm typecheck
pnpm build
pnpm test
```

```bash
pnpm verify
```
