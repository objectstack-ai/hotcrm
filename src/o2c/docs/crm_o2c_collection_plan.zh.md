# 回款计划——合同签订后销售看到什么

写给销售代表和销售经理。「订单与回款」在每张订单和每份合同上显示：开票了没有、回款了没有、哪些已经逾期。财务在别处记账，并把发票和回款记录到这里；销售维护的只有一样东西——**回款计划**：每条回款计划记录是计划中的一个节点。

回款计划属于一个**客户**，并写明它按哪张**订单**或哪份**合同**制定；两者都没有的节点会被拒绝。选择订单或合同会带出客户。

**一笔交易的回款计划只放在一个地方：有订单时放在订单上，没有订单时才放在合同上。** 系统不会拦着你在两处各做一份计划，但请不要这样做：客户上的数字不会重复统计，订单和合同的页面却会各显示一份计划。

订单归在某份合同（框架合同或订阅合同）下时，订单的回款计划也会带上这份合同。这样订单页面显示它自己的计划，合同页面汇总它所有订单的计划。填了订单、却填了另一份合同的节点会被拒绝；订单和合同属于不同客户的节点也会被拒绝。

订单在回款计划保存之后才有了合同（点了**起草合同**，或选了订单的**关联合同**），没填合同的回款计划、发票和回款会带上这份合同，合同页面随即把它们算进去。把订单改到另一份合同下时，原来跟着旧合同的节点一起改到新合同；清空订单的合同时，这些节点的合同也一起清空，订单下一次有了合同再把它们补上。填了其他合同的节点保持不变。每个节点的历史里都能看到这次修改。

## 订单确认时生成的回款计划

订单变为**已确认**、而且还没有回款计划时，HotCRM 会为它添加一条：金额是订单的**总金额**，计划日期是今天加上订单的**付款条款**（Net 15、30、60 或 90 天；Due on Receipt 或没填付款条款时为今天）。已经有回款计划的订单不会再生成，再次确认也不会再生成。分期由你自己安排：修改这条回款计划的金额，再添加其他节点。

订单的总金额之后有变化时，如果这条回款计划是订单唯一的一条，并且还没有收到任何回款，它会跟着改成新的总金额。否则回款计划保持不变；只要订单已有的回款计划合计不等于总金额，订单上就显示**回款计划与订单金额不符**：请修改、拆分或新增回款计划，直到合计相等。

## 谁可以修改回款计划

销售代表、销售经理和管理员，只要能查看这个客户，就能添加、修改和删除它的回款计划，不需要能编辑客户或合同。能查看客户及其合同的人都能查看它的回款计划。财务可以查看，但从不修改。

## 数字统计什么

| 数字 | 统计什么 |
| --- | --- |
| **已回款** | 填了该节点的回款。 |
| **未回款** | **计划金额**减去**已回款**。小于零表示收到的比计划多。 |

这两个数字都不用填写：财务保存回款时，它们随之变化。发票与回款计划并行，填的是订单或合同，不填节点。

**验收日期**是客户签字验收这个节点的日期。由人记录，系统不会代填。

## 本月计划回款与逾期回款计划

「订单与回款」应用的**跟进 → 本月计划回款**（也是**销售**应用**回款计划 → 回款计划**列表上的一个标签页）列出**计划日期**在当前自然月内的回款计划。每月 1 日起切换到新的月份。

**跟进 → 逾期回款计划**列出**计划日期**早于今天且仍有**未回款**金额的回款计划，最早的排在前面。任何回款计划列表都可以按**未回款**筛选。

## 订单上的汇总

订单的**价格**分区里有**计划回款**、**已开票**、**已回款**、**未回款**和**未开票**，统计填了这张订单的回款计划、发票和回款。**已开票**只统计已开具的发票。**未回款**是订单**总金额**减去**已回款**，**未开票**是总金额减去**已开票**，都不低于零。停用这个模块后，它们会从订单上消失。交易业绩只按订单自己的合计统计，从不统计这些数字。

## 合同和客户上的汇总

合同上有**计划回款**、**已开票**、**已回款**、**未回款**和**未开票**，统计填了这份合同的记录，未回款和未开票按**合同金额**计算。客户上的**已开票**和**已回款**统计它的所有发票和回款，包括没填订单或合同的。

客户上的**未回款**和**未开票**把客户已签下的交易各自的数加起来，每笔交易只算一次：

- 客户每张**已确认**或**已完成**的订单；
- 客户每份没有订单的**已激活**或**已过期**合同。

有订单的合同通过订单来统计，不按合同金额统计，所以框架合同的上限金额永远不会算成欠款。草稿和已取消的订单、尚未签订的合同都不计入。只填了客户的预收款计入**已回款**，但在财务填上它付的订单、合同或回款计划之前，不会减少任何一笔交易的未回款。

在合同上，这些汇总显示在**合同金额**分区；在客户上，显示在**财务信息**分区。保存回款计划、发票、回款、订单或合同时随之更新，没有人能编辑。能查看合同的人都能看到合同上的汇总；客户上的汇总要有和客户款项打交道的角色才能看到（销售、财务、市场、服务、项目经理、管理员）。只有每个成员都有的 CRM 用户权限集的人，或者顾问，能查看客户，但看不到这些汇总。
