# 價格表

本應用未隨附繁體中文語言包，因此本頁出現的介面名詞依固定順序取用：zh-CN 語言包已收錄者，採其用詞的繁體寫法；未收錄者，保留產品內的英文原名，不另造譯名。

**價格表**（**Price Book**）是一組命名的產品價格。產品目錄中每個產品只有一個 **List Price**；價格表讓同一產品面向不同對象有不同價格——夥伴等級、某個區域，或在兩個日期之間有效的促銷。

價格表中每個產品對應一條**價格表條目**（**Price Book Entry**）：產品、它在這本價格表中的 **List Price**，以及該條目是否 **Active**。

## 標準價格表 [#standard-book]

有且只有一本價格表是 **Standard** 價格表。它承載每個產品的公開價格，HotCRM 保證它唯一：

- 不能再把第二本價格表標記為 **Standard**。儲存會被拒絕，並指出目前的標準價格表是哪一本。
- 不能取消標準價格表的 **Standard** 標記，也不能刪除它。不想再使用時，請關閉 **Active**。

HotCRM 的範例資料包含一本名為 **Standard** 的價格表，範例目錄中的每個產品在其中都有一條條目，價格等於該產品的 **List Price**。已有資料的單一組織部署在升級後第一次啟動時會獲得這本價格表，且只產生一次；此後你在其中修改的價格會保留。

產品自身的 **List Price** 保持不變，「標價不得低於成本」的規則也仍在產品上。

## 每個產品一條條目 [#one-entry-per-product]

一本價格表中每個產品只有一個價格。為價格表中已有價格的產品再新增一條條目會被拒絕，提示中會寫明價格表和產品，方便你去編輯已有的那條。同一產品當然可以在每本價格表中各有一條條目。

## 有效期 [#validity]

**Valid From** 和 **Valid To** 記錄這本價格表適用的時間段，例如促銷的開始和結束。兩者都可以留空，表示不限期；**Valid To** 不能早於 **Valid From**。

## 誰可以修改價格表 [#who-can-change-price-books]

| 角色 | 價格表及其條目 |
| --- | --- |
| **System Administrator** | 建立、編輯、刪除任意價格表和條目。 |
| **Sales Manager** | 建立價格表，並編輯自己擁有的價格表：新增、改價、移除其中的條目。 |
| **Sales Rep** | 檢視所有價格表和條目。 |

價格表對所有有權檢視的人可見，與產品目錄的共享方式相同；能檢視、編輯某本價格表的人，也能檢視、編輯其中的條目。

## 幣別 [#currency]

價格表沒有自己的幣別。所有價格表中的價格都使用組織的預設幣別，與 HotCRM 中的所有金額一致。多幣別定價要等 ObjectStack 平台支援記錄級幣別和匯率後再做。

## 後續 [#what-comes-next]

報價目前還不讀取價格表：報價行的標價仍取自產品。在報價上選擇價格表、按價格表為報價行定價，是這項功能的下一步。
