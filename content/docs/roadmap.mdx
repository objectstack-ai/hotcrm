Our roadmap now focuses on **ecosystem growth**, **vertical solutions**, and **advanced AI** for 2026–2027+.


### 11A: Analytics Package (`@hotcrm/analytics`) — Q3 2026

Business Intelligence Cloud with reports, dashboards, KPIs, and AI-powered insights.

| Deliverable | Details |
|-------------|---------|
| **Objects** | `report`, `report_schedule`, `analytics_dashboard`, `kpi`, `metric`, `data_source`, `saved_filter` |
| **Hooks** | Report execution, KPI threshold alerts, metric formula validation, schedule management |
| **Actions** | Report AI (natural language reports), Dashboard AI (auto-layout), Insight AI (anomaly detection), Forecast Analytics (ML predictions) |
| **UI** | Report builder page, dashboard canvas, KPI scorecard view, analytics meta-dashboard |
| **Tests** | Spec compliance, hook tests, action tests, cross-cloud analytics integration tests |

### 11B: Integration Package (`@hotcrm/integration`) — Q3 2026

iPaaS Connectors with webhooks, data sync, and API middleware.

| Deliverable | Details |
|-------------|---------|
| **Objects** | `connector`, `connection`, `sync_config`, `sync_log`, `webhook_subscription`, `webhook_delivery`, `api_key`, `field_mapping` |
| **Hooks** | Connector lifecycle, token refresh, sync monitoring, webhook delivery tracking, API key management |
| **Connectors** | **High**: Stripe, DocuSign, Slack, Gmail, Microsoft Teams · **Medium**: PayPal, Adobe Sign, Outlook, QuickBooks, LinkedIn |
| **Actions** | Sync AI (field mapping suggestions), Connector AI (natural language setup) |
| **UI** | Connector marketplace, sync configuration editor, integration health dashboard |
| **Tests** | Spec compliance, connector tests (Stripe, DocuSign, Slack), sync flow integration tests |

### 11C: Community Package (`@hotcrm/community`) — Q4 2026

Customer Community Portal with forums, idea management, and gamification.

| Deliverable | Details |
|-------------|---------|
| **Objects** | `community`, `forum_category`, `topic`, `reply`, `idea`, `user_group`, `community_event`, `badge` |
| **Hooks** | Content moderation, answer acceptance, idea voting, RSVP management, badge auto-award, reputation tracking |
| **Actions** | Community AI (moderation, categorization, answer suggestion), Community Analytics (engagement, sentiment) |
| **UI** | Topic detail page, idea board, community health dashboard |
| **Tests** | Spec compliance, moderation tests, voting tests, community↔support integration tests |

### 11D: Cross-Ecosystem Hardening — Q4 2026

Security, performance, documentation, and end-to-end integration testing for all 3 new packages.

| Area | Details |
|------|---------|
| **Integration Tests** | Analytics↔CRM/Finance/Marketing, Integration↔Finance (Stripe→Invoice), Community↔Support (topic→case) |
| **Security** | Permission sets for analytics, integration, and community; credential encryption for connector tokens |
| **Performance** | Analytics query caching, bulk sync support (10K+ records), connector rate limiting |
| **Documentation** | Package guides (analytics, integration, community), connector setup tutorials, analytics query patterns |

## ✅ What's Been Delivered (Phases 1–10)

All 10 foundation phases are complete. See [What's New](/docs/whats-new) for detailed release notes.

### Phase 10: Salesforce Feature Parity ✅
- 25 new business objects: forecasting, territory, orders, subscriptions, journeys, A/B testing, and more
- Cross-cloud lifecycle automation (Opportunity→Order→Invoice, Campaign→Lead→Opportunity)
- Revenue recognition (ASC 606), billing schedules, payment methods
- Chatbot configuration, agent macros, benefits administration
- Salesforce parity increased from ~75% to ~92%

### Phase 9: Developer Experience & Documentation Governance ✅
- Fixed 20+ broken documentation links, updated statistics
- Created DEVELOPMENT_WORKFLOW.md, ARCHITECTURE.md
- Added `pnpm typecheck`, `pnpm test:changed`, `pnpm stats` scripts
- Link-checking CI to prevent future broken docs

### Phase 8: UI Completeness & Cross-Cloud Integration ✅
- 14 page layouts, 11 list views, 8 dashboards, 6 forms
- 71 hooks across 94 objects
- Cross-cloud data flow tests (Lead→Opportunity, Quote→Contract→Invoice, etc.)

### Phase 7: @objectstack/spec v3.0.0 Upgrade ✅
- All 10 packages upgraded to v3.0.0, zero breaking changes
- Studio plugin contributions, module cleanup

### Phase 6: Deep Schema Adoption ✅
- UI, Automation, Security, AI, Plugin schemas all validated via spec
- Advanced field types: masterDetail, summary, file, image, location, address

### Phase 5: Integration & Business Features ✅
- 47 hooks, full plugin registration, broker API migration, performance benchmarks

### Phase 4: Test Coverage & Documentation ✅
- 1,759 tests (118 files), full hook/action test coverage, deployment guides

### Phase 3: Quality & Protocol Compliance ✅
- 100% ObjectSchema compliance, zero type errors, all labels in English

### Phase 2: Deep Intelligence ✅
- 6 AI agent workflows, MCP integration, analytics dashboards

### Phase 1: Core Foundation ✅
- 6 business clouds, 94 objects, metadata engine, ObjectQL, plugin architecture
