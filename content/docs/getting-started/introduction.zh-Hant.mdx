# 簡介

**HotCRM 是一款 AI 原生的企業級 CRM。** 它透過內建於每個畫面的 AI Copilot，幫助你的團隊管理整個客戶旅程 —— 從首次市場觸達到成交以及之後。

## 包含哪些內容

該平台涵蓋四大經典 CRM 支柱，外加一個了解你資料的 AI 層：

| 支柱 | 你可以做什麼 |
| --- | --- |
| [**銷售**](/zh-Hant/docs/sales/index) | 管理線索、客戶、聯絡人、商機、報價單和管道 |
| [**服務**](/zh-Hant/docs/service/index) | 追蹤案例、執行 SLA、管理知識庫 |
| [**市場行銷**](/zh-Hant/docs/marketing/index) | 開展行銷活動、為互動評分、衡量 ROI |
| [**收入**](/zh-Hant/docs/revenue/index) | 維護產品、治理合約、路由折扣審批 |
| [**AI Copilot**](/zh-Hant/docs/ai-copilot/index) | 一個起草郵件、分流案例、彙總客戶的助手 |
| [**分析**](/zh-Hant/docs/analytics/index) | 儀表板、報表和自助式資料 cube |

一切開箱即用地**串聯在一起** —— 線索轉換為商機，商機關聯到報價單和合約，合約觸發續約，支援案例能看到客戶的完整歷史。

## HotCRM 面向誰

- **銷售代表和經理** —— 用於處理線索、交易和預測。
- **服務專員和經理** —— 用於按時解決客戶案例。
- **行銷人員** —— 用於開展行銷活動並證明 ROI。
- **銷售營運和管理員** —— 用於設定系統以適配你的業務。
- **高階主管** —— 用於貫穿整個收入漏斗的彙總檢視。

## 它有何不同

### 1. AI 原生，而非附加 AI

Copilot 內建於產品中，而非外掛。它遵守你的共享規則，借助你真實的 CRM 資料，並將答案接地於你掌控的知識庫。

### 2. 開箱即具備流程感知

你無需從頭建構審批流程、SLA 升級或行銷活動自動化。它們出廠時已按產業最佳實踐設定好 —— 調整即可，無需建構。

### 3. 建構於現代化、可擴展的平台之上

HotCRM 執行於 [**ObjectStack**](https://github.com/objectstack-ai/framework) —— 一個中繼資料優先的執行時。這意味著每個欄位、規則、頁面和工作流都在 Git 儲存庫中以程式碼形式定義。無需點擊各種管理 UI 而忘記改了什麼。

如果你是開發者，請參見[面向開發者](/zh-Hant/docs/getting-started/for-developers)了解這在實踐中意味著什麼。

## 開箱即包含什麼

你第一天拿到的系統已經包含：

- **13 個業務物件**（客戶、線索、聯絡人、商機、產品、報價單、合約、案例、行銷活動等），具備產業標準欄位、選擇清單和驗證。
- **10 級角色層級**，映射到典型的銷售 / 服務 / 市場行銷組織結構。
- **內建自動化**，用於線索路由、商機贏單、合約到期、報價單到期、行銷活動自動註冊和 SLA 升級。
- **審批流程**，用於高價值折扣。
- **標準清單檢視、儀表板和報表**，面向每個角色。
- **AI 技能**，用於線索資格審查、郵件起草、案例分流、收入預測和客戶 360°。
- **知識庫**，用於銷售劇本、產品資訊、支援文章和競爭情報。
