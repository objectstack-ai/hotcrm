# 项目交付

项目交付回答的是交付团队在赢单之后关心的问题：**谁在做这个项目，到目前为止花了多少钱，预算还剩多少，项目还赚不赚钱？**它是 HotCRM 的一个模块，有自己的应用**项目交付**，项目经理、顾问和财务在这里工作。

## 包含哪些记录

| 记录 | 是什么 | 谁来填写 |
| --- | --- | --- |
| **项目** | 为客户做的一次项目：售前、交付或内部工作 | 项目经理 |
| **项目成员** | 投入某个项目的一个人，以及他的职责和费率卡 | 该项目的项目经理 |
| **费率卡** | 一个工作职级，带有按小时或按天的成本单价和计费单价 | 财务、项目管理办公室 |
| **工时单** | 一个人在一个项目上某个期间（例如一周）的工时 | 工作的本人 |
| **工时明细** | 工时单上某一天的工时 | 工作的本人 |
| **费用** | 一个人为项目花的钱：差旅、住宿、餐饮。费用报销是独立的模块（[费用报销](/zh-Hans/docs/expenses)），项目交付为它加上项目 | 花钱的本人 |

项目挂在**客户**下面，还可以写明它来自哪个**商机**、交付哪份**合同**或哪张销售**订单**。打开客户、商机、合同或订单，**项目**标签页会列出相关项目。

| 页面 | 内容 |
| --- | --- |
| [项目与人员安排](./projects-and-staffing) | 新建项目、项目类型和状态、按费率卡安排人员、预算 |
| [项目预算](./budgets) | 按版本和明细编制预算、随项目一起审批、用追加预算调整 |
| [工时与费用](./time-and-expenses) | 填报工时和费用、提交与审批、成本怎么计算 |

## 在哪里找到

| 谁 | 在哪里 |
| --- | --- |
| 项目经理、项目成员、财务控制 | **项目交付**应用：**项目**分组下的**全部项目**、**我的项目**和**人员安排**；**工时与费用**分组下的**我的工时单**、**我的费用**、**待我审批的工时单**和**待我审批的报销单**；**费率**分组下的**费率卡**；项目所属的**客户**、**商机**和**合同**；以及**我的工作**分组下的**待我审批**，项目、工时单和费用都在这里审批。 |
| 销售经理 | 启动器上有项目交付应用，并且可以查看每个项目，从而了解团队赢下的单子交付得怎么样。 |
| 销售代表、服务、市场、应收会计 | 启动器上没有。 |
| 管理员 | 全部可见。 |

启动器决定的是提供哪些应用，而不是能打开哪些：启动器上没有的应用，用地址照样能打开；每条记录的访问权限仍由它的共享规则决定。

## 谁能做什么

项目是私有的。一个人能查看某个项目，是因为他是项目负责人、被安排在这个项目上，或者是它的项目经理；项目经理还可以编辑项目。财务和交付管理层可以查看每个项目。

| 人员 | 项目 | 人员安排 | 费率卡 | 工时与费用 |
| --- | --- | --- | --- | --- |
| 项目成员 | 查看自己参与的项目，**看不到成本和毛利** | 查看 | 查看，**看不到成本单价** | 填报自己的 |
| 项目经理 | 新建项目；编辑自己负责的项目 | 为自己负责的项目安排人员 | 查看 | 填报自己的；审批团队的 |
| 财务控制 | 查看每个项目和预算；审批 100,000 及以上的项目和增幅 10% 及以上的追加预算 | 查看 | 新建和编辑 | 查看全部；审批合计 2,000 及以上的报销单 |
| 项目总监、项目管理办公室 | 兼有以上两者；审批新项目 | 兼有 | 兼有 | 兼有 |
| 销售经理 | 查看每个项目 | 查看 | — | 查看全部 |
| 管理员 | 全部 | 全部 | 全部 | 全部 |

管理员在 **Setup → Position Holders** 中用**岗位**给人员授权：**项目成员**、**项目经理**、**财务控制**、**项目总监**或**项目管理办公室**。

> **项目成员永远看不到同事的成本。**成本单价、每条工时明细的成本、工时单的总成本，以及项目的成本和毛利，对「项目成员」岗位都是隐藏的。他们能看到工时、计费单价和可计费金额。

> **项目成员看得到客户，看不到商机。**「项目成员」岗位可以只读查看全部客户，所以项目上的**客户**会显示名称；客户的**已开票**、**已回款**、**未回款**和**未开票**对他们隐藏。商机仍对他们关闭：他们的项目页上不显示**商机**和**订单**字段，也打不开项目的商机，**项目交付**菜单里也没有**商机**入口。

## 项目上的金额 [#money]

项目上只有**计划收入**是手工填写的，其余数字都随工时、费用或预算版本的批准自动变化：

| 字段 | 统计什么 |
| --- | --- |
| **批准预算** | 项目基线[预算版本](./budgets)的合计 |
| **人工成本** | 项目上**已批准**工时单的工时成本 |
| **费用成本** | 项目上**已批准**的费用 |
| **实际成本** | 人工成本加费用成本 |
| **剩余预算** | 批准预算减实际成本 |
| **预算使用率** | 实际成本占批准预算的百分比 |
| **毛利** | 计划收入减实际成本 |
| **毛利率** | 毛利占计划收入的百分比 |
| **已批准待开票** | 已批准的可计费工时按计费单价计算的金额，加上已批准的可计费费用 |
| **预算状态** | 正常；达到批准预算的 80% 为预警，达到 100% 为超支。进入其中任一状态都会通知项目经理和财务 |

金额使用贵公司的本位币。项目只产出**已批准待开票**这个数字：给客户开票在[订单与回款](/zh-Hans/docs/order-to-cash)中完成。

## 不是每个客户都用

不做项目的公司，可以由管理员停用这个模块。它的应用、记录，以及客户、商机、合同和订单上的项目标签页都会随之消失；订单页面本身不受影响。
