# CRM 业务验收清单(persona × 旅程)

每条:**执行角色 → 操作 → 预期 → 验证方法**。走查报告按本单勾销:通过 / 失败(附证据)/ 跳过(附原因)。
"验证"栏的约定:UI=截图,API=以**执行角色身份**发的请求与状态码/返回体,LOG=服务端日志。

版本锚:初版基于 17.0.0-rc.4 走查(2026-08-07)。清单项后括号里的 issue 号是
该项历史上暴露过的缺陷,重点回归位。
