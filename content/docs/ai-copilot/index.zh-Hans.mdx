# AI 与智能体

**HotCRM 为智能体而建，但它不自带智能体。** 它提供智能体工作所需的三样东西：**对象**（每一个客户、商机、订单、合同、发票、项目、费用和工单），一个人从按钮上运行的**动作**，以及教智能体理解 CRM 的六项**技能**。智能体本身是你的：可以是你通过 MCP 接入的那个，也可以是平台提供的助手。

## 为什么这样设计

识别一张票据、按差旅制度核对一笔费用、起草一封回复、催收一张逾期发票：这些都是智能体每个月都做得更好的工作，没有一件需要内置进 CRM。HotCRM 保留智能体无法凭空造出的东西 —— 记录、守护这些记录的规则，以及谁可以做什么 —— 把推理留给智能体。

所以你在 HotCRM 里找不到内置的票据识别、制度引擎或聊天助手。你会找到：

| HotCRM 提供 | 在哪里阅读 |
| --- | --- |
| 每一个对象，通过 MCP，在调用者的权限之下 | [接入你的智能体](/zh-Hans/docs/ai-copilot/connect-your-agent) |
| 智能体可以运行的动作，以及它在不可撤销的动作前如何先确认 | [对智能体开放的动作](/zh-Hans/docs/ai-copilot/agent-actions) |
| 平台智能体携带的六项技能 | [技能](/zh-Hans/docs/ai-copilot/skills) |
| 智能体可以写入结论的字段，例如报销单或出差申请上的**检查提示** | [费用报销](/zh-Hans/docs/expenses) |

## 唯一的规则：智能体就是一个人

智能体**以某个人的身份**接入 —— 用登录会话或这个人的 API 密钥 —— 并以这个人的身份行事。它读这个人能读的，写这个人能写的，在这个人会被拒绝的地方被拒绝，提示也一样。它写下的记录带着这个人的名字。没有权限更宽的智能体账户，也没有能开出这种账户的开关。

所以"我的智能体能做什么？"和"这个人能做什么？"答案相同：看他的权限集、岗位和共享规则。参见[共享与安全](/zh-Hans/docs/administration/sharing-and-security)。

## 平台助手额外带来什么

ObjectStack 环境可以运行一个平台助手（`ask`）。HotCRM 不为它编写智能体；它的六项技能附着在这个助手上，教它判定线索资格、起草邮件、预测营收、生成客户 360° 和分流工单。本地社区版启动时不运行任何助手（`GET /api/v1/ai/agents` 返回空列表）：这时，智能体就是你接入的那个。

> **没有应用自有的智能体。** HotCRM 曾定义过两个自己的智能体——"销售 Copilot"和"服务 Copilot"。它们已被退役，其能力迁移到了附着于平台助手的技能中。
