# 自动化——每个门槛在哪里定义

面向管理员和实施人员。用户指南告诉大家系统会自己做什么；本篇告诉你**每一条规则定义在哪里**，以便调整。

## 自动化参数

业务规则定义在**流程**里，每个包把自己的流程放在各自的 `flows/` 目录下。要修改门槛，编辑流程并重新部署。以下是管理员最常调整的值：

| 行为 | 当前设置 | 定义位置 |
|---|---|---|
| 大额商机审批（经理） | 金额 **$100,000 或以上** | `opportunity-approval.flow.ts` |
| 大额商机审批（加总监） | 金额 **> $500,000** | `opportunity-approval.flow.ts` |
| 热线索跟进 SLA | **1 天**（线索评分 ≥ 4★） | `lead-assignment.flow.ts` |
| 普通线索跟进 SLA | **3 天** | `lead-assignment.flow.ts` |
| 停滞商机提醒 | 在同一阶段**超过 14 天**，每天 **07:30** 扫描（仅计划任务） | `opportunity-stagnation.flow.ts` |
| 大单成交提醒 | 金额 **$100,000** 或以上的商机**成交**时 | `opportunity-won-alert.flow.ts` |
| 报价单默认有效期 | **30 天** | `quote-generation.flow.ts` |
| 报价单自动过期扫描 | 每天 **01:00**（仅计划任务） | `quote-expiration.flow.ts` |
| 工单 SLA 违约扫描 | **每小时**（仅计划任务） | `case-sla-monitor.flow.ts` |
| 严重工单自动升级 | 优先级 = **严重** | `case-escalation.flow.ts` |
| 合同续约提醒 | 每份合同各自的**续约通知（天）**，每天 **08:00** 扫描（仅计划任务） | `contract-renewal.flow.ts` |
| 合同自动过期 | 超过**结束日期**，每天 **00:00** 扫描（仅计划任务） | `contract-expiration.flow.ts` |

## 计划任务默认关闭，需要你开启

标为*仅计划任务*的五行都是计划流程，部署只有在设置了 `OS_AUTOMATION_SCHEDULED_WORK_ENABLED=true` 之后才会运行计划流程（`1`、`on` 和 `yes` 也算；`os doctor` 会打印实际生效的值）。默认安装不设置它，启动时这些流程都未绑定：每个流程都会在日志里说明它声明了 `schedule` 触发器但没有绑定。所以那里什么都不会扫描：报价单和合同不会自己过期，SLA 违约不会被标记，停滞商机和续约提醒也不会发出。上表中的时间是开关打开之后的运行时间。

> 对象名、字段和关系可以直接在 **Studio** 和每条记录的详情页上看到——这里有意**不**重复列出。本指南只记录那些界面无法告诉你的东西。

## AI 技能

HotCRM 提供的是**技能**，而不是自己的助手。助手由平台提供（ObjectStack ADR-0063：运行时只拥有两个智能体，你所在的界面绑定其中一个）；应用通过编写按界面亲和性挂载的技能来扩展它。技能不需要逐个开启：有哪些技能由应用决定。每项技能做什么、可以按哪些按钮，见[使用助手](./crm_ai_skills.md)。
