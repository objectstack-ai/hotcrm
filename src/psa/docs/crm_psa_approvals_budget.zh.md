# 审批、预算状态与锁定——由谁决定

写给项目经理、财务、项目总监和项目管理办公室。这里的每一项审批都在**我的工作**下的**待我审批**中决定；没有人手工把状态改成**已批准**或**已驳回**。只有管理员可以这样做，用来修复审批无法运行的记录。

## 谁审批什么

- **项目**通过设为**审批中**来提交，而且必须先填写**批准预算**。任何一位**项目总监**或**项目管理办公室**岗位的人都可以决定，第一个做出决定的人代表所有人。预算达到 **100,000** 或以上时，随后还要交给**财务控制**。
- **工时单**提交后交给所属项目的项目经理。
- **费用**先交给项目经理，金额达到 **2,000** 或以上时再交给财务控制。
- **没有人审批自己的单据。** 项目经理自己的工时单或费用交给管理员。
- **已驳回**会把记录退回修改；在等待期间，提交人也可以在自己的待我审批中**撤回**，记录回到草稿。
- **等待期间记录被锁定**：在做出决定之前，没有人能编辑它。

## 批准预算归财务管

从**审批中**开始，批准预算就是项目获批所依据的数字。此后只有**财务控制**能修改；其他人修改会被拒绝，并提示去找财务。调高预算会立即改变**预算状态**，所以项目要回到**正常**，必须经过财务同意。

## 预算状态与通知

**预算状态**自动跟随已批准成本变化：低于批准预算的 80 % 为**正常**，达到 80 % 为**预警**，达到 100 % 为**超支**。没有预算的项目没有预算状态。

- **进入预警或超支的那一刻**，项目经理和每一位财务控制各收到一条站内通知和一封邮件。
- **每次越线只通知一次。** 项目停留在预警期间，即使又批准了更多工时，也不会再发送。回落之后（预算调高、费用被驳回）再次越线，会再次通知。
- **通知使用每个人自己的语言**，即其用户记录上的语言，而不是控制台菜单里切换的语言。

## 锁定

通知只是建议锁定；由人来决定，系统不会自动勾选。项目上勾选了**锁定工时与费用**时，这个项目上的任何工时单或费用都不能提交，**不论是谁提交**，管理员也一样。草稿仍然可以填写。取消勾选（例如财务设定了新预算之后），就又可以提交了。

**已关闭**或**已取消**的项目完全不接受新内容：不能在上面新建工时单或费用，也不能把已有的改挂上去；已有的草稿可以编辑但不能提交，管理员也一样。**已完成**的项目仍然接受补录；要停止补录，勾选锁定。
