# 报价

**报价**是发送给客户的正式定价提案。报价始终属于某个商机，并捕获其呈现时刻的定价。一旦报价被接受，它就成为合同的基础。

## 6 种报价状态

| 状态 | 含义 |
| --- | --- |
| ⚪ **草稿** | 正在内部准备 *(新建报价的默认值)* |
| 🟠 **审核中** | 等待内部审核（例如折扣审批） |
| 🔵 **已呈现** | 已发送给客户 |
| 🟢 **已接受** | 客户已同意——自动触发合同创建 |
| 🔴 **已拒绝** | 客户已拒绝 |
| ⚪ **已过期** | 有效期已过但未作出决定 |

一段典型的旅程：**草稿 → 已呈现 → 已接受 →（合同）**。

## 报价记录存储的内容

详情界面有 5 个区块：

| 区块 | 字段 |
| --- | --- |
| **报价信息** | 报价编号、名称、状态、客户、联系人、商机、负责人 |
| **定价** | 小计、折扣 %、折扣金额、税费、运费及手续费、总计 |
| **条款与有效期** | 报价日期、过期日期、付款条款、运输条款 |
| **地址** | 账单地址、收货地址 |
| **系统** | 描述（面向客户）、内部备注（仅供你查看） |

### 付款条款

Net 15 · Net 30 *(默认)* · Net 60 · Net 90 · Due on Receipt。

## 价格是如何计算的

系统会为你完成计算：

```
Subtotal       = sum of all line items
Discount       = Subtotal × Discount % ÷ 100
Total Price    = Subtotal − Discount + Tax + Shipping & Handling
```

你在行项目、折扣、税费或运费字段中更改的任何内容，合计都会自动更新。

## 行项目

一份报价可以有任意数量的行项目——每个所售产品一项。每一行存储：

- 产品（来自目录）
- 数量
- 单价（默认为产品的标价）
- 单行折扣 %
- 行合计

行项目之和汇总到报价小计中。

## 内置规则

- **过期日期必须晚于报价日期**——不能创建即过期的报价。
- **折扣不能超过 100%**——基本的合理性检查。

## 自动发生的事

- **每日过期扫描**——每晚凌晨 1 点，系统会将任何过期日期已过的报价标记为**已过期**（除非它已被接受或拒绝）。保持你的活跃列表干净整洁。
- **接受时**——当你将一份报价标记为*已接受*时，系统会用该报价的条款自动创建一份合同，将商机推进到*赢单*，将客户从潜在客户提升为客户（如适用），并安排一个在合同结束前 60 天的续约提醒任务。

## 生成报价

你不需手动创建报价——而是打开任意商机并点击**生成报价**。会弹出一个简短的表单：

- 报价名称
- 有效期（天）——默认 30
- 折扣 %

然后系统会一步完成：

1. 以**草稿**状态创建报价，并将商机的金额作为小计。
2. 应用折扣并重新计算总计。
3. 将商机推进到**提案**阶段。
4. 将商机的最近活动盖戳为今天。
5. 向你发送一封确认邮件。

随后销售代表审核该草稿，附上一份 PDF（或使用内置模板），并将状态更改为*已呈现*以将其发送给客户。

## 将报价发送给客户

在报价详情页，点击**发送给客户**。这会将状态设为*已呈现*，并使用报价封面邮件模板将 PDF 通过邮件发送。Sales Copilot 可以为你起草封面邮件——*"Draft a cover note for this quote"*。

## 标记为已接受 / 已拒绝

详情界面上的两个按钮可以闭合循环：

- **标记已接受** → 状态 = 已接受；触发上文所述的合同链。
- **标记已拒绝** → 状态 = 已拒绝；商机保持开放（你可以以更低的价格重新报价）。

## 高价值折扣审批

如果一份报价的总计超过折扣审批阈值（例如总计 > $500K 或折扣 > 30%），关联的商机会进入 [折扣审批](/zh-Hans/docs/revenue/approvals) 流程。报价顶部会显示一个横幅——在审批通过之前你无法将其标记为*已呈现*。

## 标准列表视图

- **我的报价**——你负责的报价。
- **活跃报价**——草稿、审核中或已呈现。
- **本周到期**——即将过期且仍开放。
- **赢单报价**——已接受。
- **按客户**——分组。

## 给销售代表的提示

- ✅ 如果你大幅折扣，请始终在*内部备注*中包含折扣原因。
- ✅ 从商机使用**生成报价**按钮，而不是从头创建报价——它会自动填充所有内容。
- ✅ 检查有效期（过期日期）是否与你的业务周期相匹配。按季采购的买家需要有效期到季末的报价。
- ❌ 不要更改已呈现报价上的定价——它会让客户困惑。改为创建一个新修订版。

## 给管理员的提示

- 每日过期扫描在凌晨 1 点运行。要更改时间，请调整报价对象工作流上的计划。
- 报价 PDF 模板（封面和行项目布局）存储在你的邮件模板设置中。
- 要在系统级 $500K 阈值之下要求经理审批（例如对每个折扣 >20% 的报价），请添加一个工作流，将报价翻转为*审核中*并通知经理。参见 [Administration › Automation](/zh-Hans/docs/administration/automation)。
