# For Developers

This page is for engineers working with the HotCRM source repo.

## Prerequisites

- Node.js 20+
- pnpm 10+
- A clone of `objectstack-ai/hotcrm`

## Run locally

```bash
git clone https://github.com/objectstack-ai/hotcrm.git
cd hotcrm
pnpm install
pnpm dev
```

Open http://localhost:4001. The app boots with seed data on first start.

## Repository shape

HotCRM is a single ObjectStack app. `objectstack.config.ts` is the source of truth that registers metadata from `src/`.

```text
hotcrm/
├── objectstack.config.ts
├── src/
│   ├── objects/        # *.object.ts and object lifecycle hooks
│   ├── actions/        # UI actions and executable action bodies
│   ├── flows/          # automation flows
│   ├── agents/         # AI agents
│   ├── skills/         # AI skills
│   ├── apps/, views/, pages/
│   ├── dashboards/, reports/, cubes/
│   ├── profiles/, sharing/
│   ├── translations/
│   └── data/
├── apps/docs/          # Fumadocs app
└── content/docs/       # documentation content
```

## File suffix protocol

| Suffix | Defines |
| --- | --- |
| `*.object.ts` | Data model |
| `*.hook.ts` | Server-side lifecycle logic |
| `*.actions.ts` | UI actions and AI-callable action bodies |
| `*.flow.ts` | Automation |
| `*.skill.ts` | AI skill |
| `*.agent.ts` | AI agent |
| `*.page.ts` | UI page |
| `*.view.ts` | List or kanban view |
| `*.dashboard.ts` | Dashboard |
| `*.report.ts` | Report |
| `*.sharing.ts` | Sharing rule |
| `*.profile.ts` | Permission profile |

## Common tasks

### Add or change an object

Edit or add a file under `src/objects/`, then export it from `src/objects/index.ts`.

```ts
import { ObjectSchema, Field } from '@objectstack/spec/data';

export const Warranty = ObjectSchema.create({
  name: 'crm_warranty',
  label: 'Warranty',
  fields: {
    name: Field.text({ label: 'Warranty Name', required: true }),
    crm_account: Field.lookup('crm_account', { label: 'Account' }),
  },
});
```

### Add an AI skill

Create `src/skills/<name>.skill.ts`, export it from `src/skills/index.ts`, and add the skill name to the relevant agent in `src/agents/`.

### Add UI metadata

Use `src/views/` for list and kanban views, `src/pages/` for record pages, and `src/actions/` for buttons and modal actions.

## Verify changes

```bash
pnpm validate
pnpm typecheck
pnpm build
pnpm test
```

The shortcut is:

```bash
pnpm verify
```
