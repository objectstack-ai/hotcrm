# 採購決策圈

本應用未隨附繁體中文語言包，因此本頁出現的介面名詞依固定順序取用：zh-CN 語言包已收錄者，採其用詞的繁體寫法；未收錄者，保留產品內的英文原名，不另造譯名。

凡是大到一個人簽不了字的採購，都是**若干人一起決定**的，而這些人各自想要的東西並不一樣。這群人就叫**採購決策圈**，它是 B2B 銷售裡最老的一個概念：你賣的從來不是「一家公司」，而是五六個具體的人，他們最後必須達成一致。

HotCRM 把這群人記錄在聯絡人上，用三個欄位回答三個不同的問題：

- **採購角色**——這個人在這次決策裡*做什麼*。
- **對我司態度**——他*站在哪一邊*。
- **與銷售關係強度**——我們*到底有多熟*。

三個都填上，一個客戶就不再是一張電話清單，而是一張開會之前就能讀的地圖。

## 為什麼只有職位不夠

聯絡人上本來就有**職位**和**部門**。那是關於這個人的僱主的事實，而且相當穩定：一位「區域 IT 經理」在你以後跟這家公司做的每一單裡都還是區域 IT 經理。

採購決策圈恰恰不穩定，這正是它的價值。同一位經理，可能在你的基礎設施單子裡是拍板的人，在你的分析單子裡卻在默默地擋著。你要記下來的是他在**這一次**採購裡的位置，而職位欄位承載不了這件事。

**主要聯絡人**標誌同樣承載不了。那個標誌只回答一個問題——預設聯絡誰——客戶處其餘的人一個都沒被描述。一個位元不是一張地圖。

## 每個人在決策裡做什麼

按你正在推進的這單採購，挑這個人扮演的那一個角色。選項是通用的，因為它們在任何行業裡都成立：

| 採購角色 | 實際指的是誰 |
| --- | --- |
| **決策者** | 他說「可以」，爭論就結束了。往往不是場上職級最高的那個名字。 |
| **預算決策人** | 錢從他的預算裡出。有時和上面是同一個人，更多時候不是——而且永遠不要預設是。 |
| **技術評估人** | 判斷東西到底能不能用：安全評審、整合、概念驗證。很少能拍板說行，卻很容易說不行。 |
| **使用者** | 買回去之後天天要用的人。他會告訴所有人這到底是不是個好主意。 |
| **影響者** | 在流程上沒有名分，實際分量卻很重——一位受信任的架構師、一位外部顧問、一位說話有人聽的同事。 |
| **守門人** | 控制的是「能不能接觸到」，不是「結果是什麼」：行政助理、採購專員、必須先被說服你才約得上會的安全負責人。 |

一個人確實可能同時是其中兩種。請記下**決定這一單成敗的那一種**，其餘的交給職位欄位去承載。

## 他站在哪一邊

**對我司態度**是一條五級階梯，從最好到最差：**擁護者** · **支持** · **中立** · **存疑** · **反對者**。

擁護者不等於「對你客氣的人」。擁護者是在你不在場的會議上會替你說話的人——這就是全部的判據，也是這一級比其他幾級都重要的原因。反對者是它的鏡像，早一點知道你的反對者是誰，比再做一次演示值錢得多。

真的還不知道的時候，就**留空**。留空和*中立*是兩件不同的事：前者說沒人形成過判斷，後者說你見過他，而他無動於衷。

## 我們到底有多熟

**與銷售關係強度**依次是**疏遠** · **一般認識** · **工作往來** · **關係緊密** · **可信顧問**。

這說的是關係，不是活動量。聯絡人上的**最近聯絡時間**是記錄通話或會議時自動寫上的，它量的是*近度*，完全是另一回事。每週都通話卻永遠不會站在你這邊的人，不算關係緊密；一個季度吃一次飯、但招標出去之前會先給你打個電話的人，才算。

## 把一個客戶讀成一張地圖

打開**聯絡人**。預設檢視**全部聯絡人**按所屬客戶分組、分組預設摺疊——展開你正在跟的那個客戶，這三欄就排在職位和部門旁邊，一屏之內回答：

- 這個客戶上到底有沒有**決策者**？還是我們只見過使用者？
- 誰是我們的**擁護者**——有沒有人是**反對者**？
- 我們關係最好的那幾個人，是真正拍板的人，還是只是最好說話的人？

缺口往往就是答案。一個客戶下面四個聯絡人，全是使用者、全是中立，無論活動記錄多熱鬧，都算不上一個被覆蓋住的客戶。

> **這裡沒有任何東西會攔住儲存。** 三個欄位都是普通的可選欄位——沒有規則校驗它們，沒有自動化替你填，三個全空的聯絡人和以前一樣能存下來。這是刻意的：採購決策圈是你的團隊寫下來的判斷，不是機器能算出來的狀態；一個會攔下儲存的產品，只會教會所有人往框裡隨便塞一個值。

## 給銷售的建議

- ✅ **開完會就填**，趁印象還新。每個欄位都只要幾秒。
- ✅ 盯著**缺的那個人**看，而不是已經填上的那些——一單裡沒有預算決策人，就是這一單還沒有人問過錢的事。
- ✅ 單子卡住的時候回頭看一眼態度那一欄。卡住通常是因為有個沒人寫下來的反對者。
- ⛔ 不要因為對方客氣就標成擁護者。要問的是：在你不在場的會上，他會不會替你說話。

## 給管理員的建議

- 三個欄位在聯絡人表單和詳情頁上自成一個**採購決策圈**分區。該分區由物件的欄位分組派生，不需要手工排版。
- 三個欄位在四種隨附語言裡都是普通選項列表。要改措辭或加值，參見 [Customization › Extending Objects](/zh-Hant/docs/customization/extending-objects)。
- 它們背後沒有自動化，也不打算有。如果你想要一個「未識別擁護者」的預警，那是一張讀這些值的報表或儀表板，而不是聯絡人上的一條規則。
