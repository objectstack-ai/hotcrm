# 客製化

本節面向用程式碼擴展 HotCRM 的開發者和技術實施人員。如果你是在應用裡配置使用者、權限、流程或共享規則，請從[管理](/zh-Hant/docs/administration/index)開始。

## 目前原始碼結構

HotCRM 是一個單體 ObjectStack 應用。請在 `src/` 下新增或修改中繼資料，然後從對應的 barrel 檔案匯出。

```text
src/
├── objects/        # 資料模型和物件 hooks
├── actions/        # UI 動作和可執行動作體
├── flows/          # 自動化
├── agents/         # AI agents
├── skills/         # AI skills
├── apps/
├── views/
├── pages/
├── dashboards/
├── reports/
├── profiles/
├── sharing/
├── translations/
└── data/
```

## 檔案後綴協議

| 後綴 | 定義 |
| --- | --- |
| `*.object.ts` | 資料模型 |
| `*.hook.ts` | 物件生命週期邏輯 |
| `*.actions.ts` | UI 動作和可執行動作 |
| `*.flow.ts` | 自動化 |
| `*.skill.ts` | AI Copilot skill |
| `*.agent.ts` | AI agent |
| `*.page.ts` | UI 頁面 |
| `*.view.ts` | 清單或看板視圖 |
| `*.dashboard.ts` | 儀表板 |
| `*.report.ts` | 報表 |
| `*.sharing.ts` | 共享規則 |
| `*.profile.ts` | 權限設定檔 |

## 黃金規則

- HotCRM 物件名使用 `crm_` 前綴。
- 使用 ObjectQL 和 ObjectStack API，不使用原始 SQL。
- 從對應的 `src/**/index.ts` 檔案匯出中繼資料。
- 新增使用者可見標籤時同步更新翻譯。
- 發布前執行 `pnpm verify`。
