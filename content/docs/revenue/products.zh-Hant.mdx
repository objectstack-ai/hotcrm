# 產品

**產品**是你銷售的任何東西——軟體、硬體、服務、訂閱、支援套餐。產品目錄會輸入到報價和商機中：當銷售構建報價時，他們從這個目錄中挑選產品，而不是手動輸入名稱。

## 產品記錄儲存的內容

詳情介面有 3 個區塊：

| 區塊 | 欄位 |
| --- | --- |
| **Product Information** | 產品編碼 *(自動)*、名稱、描述、類別、產品系列 |
| **Pricing & Billing** | 標價、成本、SKU、計費類型、計量單位、稅率、應稅標記 |
| **Resources** | 產品圖片、規格表、產品經理 |

## 類別和產品系列

用兩種方式對產品分類：

**類別（Category）**——產品如何交付：

- **Software** *(預設)*——已安裝或下載的軟體
- **Hardware**——物理設備
- **Service**——諮詢、培訓、專業服務
- **Subscription**——經常性存取
- **Support**——付費支援等級

**產品系列（Family）**——產品在你產品組合中的定位：

- **Enterprise Solutions**
- **SMB Solutions**
- **Professional Services**
- **Cloud Services**

類別和產品系列讓你能按產品組合切分報表——*"本季度我們記入了多少 SMB 等級的訂閱營收？"*

## 計費類型

| 計費類型 | 用於 |
| --- | --- |
| **One-Time** *(預設)* | 永久許可、一次性購買 |
| **Monthly** | 月度訂閱 |
| **Quarterly** | 季度訂閱 |
| **Annual** | 年度訂閱 |
| **Usage** | 基於用量（按 API 呼叫、按 GB 等） |

計費類型驅動報價如何計算總額（一次性費用 vs. 經常性），並輸入到營收確認報表中。

## 計量單位

指定產品如何銷售：

- **Each** *(預設)*——每數量一個單位
- **License**——按軟體許可
- **Seat**——按命名使用者
- **Hour**——用於服務
- **Day**——用於服務
- **Month**——用於有時限的訂閱

## 定價欄位

| 欄位 | 用途 |
| --- | --- |
| **List Price** | 標準公佈價——預設顯示在報價上的價格 |
| **Cost** | 你的成本——用於利潤計算 |
| **Default Tax Rate %** | 自動應用到報價明細行 |
| **Taxable** | 如果未勾選，則不新增稅（零稅率產品） |

如果成本大於標價（這會是一筆虧本的銷售），系統會警告你。

## 庫存追蹤

針對物理產品：

- **Quantity on Hand**——當前庫存。
- **Reorder Point**——何時補貨。

這些欄位是可選的——對於非庫存項（軟體、服務）保持為空。

## 產品圖片和規格表

兩個附件欄位讓你上傳：

- **Product Image**——顯示在報價明細行和產品列表檢視上。
- **Datasheet**——不超過 20 MB 的 PDF，供人從產品記錄上開啟檢視。

沒有任何東西會讀取這個檔案的內容。不存在*產品資訊*知識庫——HotCRM 不附帶任何獨立的知識庫——也沒有哪個技能會開啟附件，因此規格表永遠不會進入 AI 起草的郵件或提案。助手能引用的產品資訊，是敲進產品自身欄位裡的那些。參見 [知識庫](/zh-Hant/docs/ai-copilot/knowledge-bases)。

## 內建規則

- **標價必須大於零**——你不能銷售一個免費產品（如果你確實需要，可使用 $0.01 的標價配合 100% 折扣）。
- **成本不能超過標價**——僅警告，不阻止儲存。
- **商機 / 報價明細行上的單價必須為零或正數**——基本驗證。

## 共享——產品預設公開

產品目錄對整個組織是**公開唯讀**的。銷售代表可以查看和使用任何產品；只有市場/產品經理可以編輯。

## 標準列表檢視

- **Active Products**——`is_active = true`。
- **By Category**——分組。
- **By Family**——分組。
- **Subscriptions**——`category = subscription OR billing_type IN [monthly, quarterly, annual]`。
- **Low Stock**——`quantity_on_hand < reorder_point`（針對庫存產品）。

## 給產品經理的提示

- ✅ **保持規格表最新**——Sales Copilot 用它來起草面向客戶的內容。
- ✅ **使用產品圖片**——它能顯著改善面向客戶的報價的外觀。
- ✅ **將舊產品標記為非活躍**，不要刪除它們——過往的報價和合約仍引用它們。

## 給銷售代表的提示

- ✅ 使用目錄中的產品，而不是手動輸入明細行——定價和稅會被自動填充。
- ✅ 在提案前檢查規格表——它通常包含你提案所需的確切規格表。

## 給管理員的提示

- 類別、產品系列、計費類型和計量單位選項列表都可以擴展。參見 [定制 › 擴展物件](/zh-Hant/docs/customization/extending-objects)。
- 一個產品可以關聯到多個商機和報價——停用不會破壞歷史記錄。
