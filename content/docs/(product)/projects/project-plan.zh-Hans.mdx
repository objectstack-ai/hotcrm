# 项目计划

项目的计划就是它的**项目任务**。任务出现在项目的**相关**页签中，也出现在项目交付应用的**项目计划**（甘特图）和**任务树**中（包含所有项目）。项目自己的页面不画甘特图：要在甘特图上看一个项目的计划，打开**项目计划**，在**项目**筛选里选中这个项目。

## 谁来写计划

| 谁 | 能做什么 |
| --- | --- |
| 项目经理、项目负责人、管理员 | 新增、修改和删除任务。写任务需要有项目的编辑权限 |
| 被安排在项目上的人 | 查看所有任务，但不能修改，进度请告诉项目经理 |
| 财务总监、项目总监、项目管理办公室 | 查看所有项目的计划 |

## 一项任务

| 字段 | 含义 |
| --- | --- |
| **任务名称** | 这项工作是什么 |
| **上级任务** | 这项任务所属的任务。有子任务的任务是汇总任务 |
| **任务负责人** | 完成这项任务或对它负责的人 |
| **状态** | 未开始、进行中、暂停、已完成或已取消 |
| **里程碑** | 一个检查点而不是一项工作，画成菱形 |
| **计划开始**、**计划结束** | 任务计划在什么时候做 |
| **前置任务** | 这项任务开始前必须完成的任务 |
| **计划工时** | 这项任务计划投入的工时。项目的完成百分比按它给每项任务加权 |
| **完成百分比** | 这项任务完成了多少。标为已完成时设为 100 |
| **实际工时** | 记到这项任务上的工时 |

**上级任务**和每个**前置任务**都必须是同一项目的任务。如果选的上级任务是这项任务自己的子任务，会被拒绝，否则计划会绕成一个圈。

## 甘特图

甘特图画出任务，前置任务画成箭头，里程碑画成菱形。子任务和汇总任务并列显示，而不是缩进在它下面：应用中的**任务树**显示任务树。任务条的颜色跟随任务状态，填充部分跟随完成百分比。

- **拖动任务条**修改任务的计划日期，**拖动进度手柄**修改完成百分比，都会立即保存。
- 甘特图工具栏上的**自动排期**会移动等待被移动任务的后续任务，并保存。

> **只有甘特图会重新排期。** 服务器不会连带调整：在任务表单里、通过导入或 API 修改日期，只移动这一项任务，后续任务的日期保持不变，直到有人去移动它们。

## 记到任务上的工时

工时明细有一个可选的**任务**，从工时单所属项目的任务中选择；选别的项目的任务会被拒绝。任务的**实际工时**汇总所有选了它的工时明细，不管工时单处于什么状态。成本仍然只在工时单批准后才计入（见[工时与费用](/zh-Hans/docs/projects/time-and-expenses)）。

## 完成百分比

项目的**完成百分比**由任务计算，不能手工填写。每次任务变化时：

1. 取没有子任务的任务，去掉已取消的任务。汇总任务通过它的子任务计入，所以同一工时不会算两次。
2. 用每项任务的计划工时给它的完成百分比加权，已完成的任务按 100 计。
3. 除以计划工时总数。

| 任务 | 完成百分比 |
| --- | --- |
| 设计，40 小时，50%；启动，10 小时，已完成 | (40 × 50 + 10 × 100) ÷ 50 = **60%** |
| 同上，设计也已完成 | **100%** |

如果计入的任务都没有计划工时，每项任务权重相同。没有可计入任务的项目不显示百分比。
