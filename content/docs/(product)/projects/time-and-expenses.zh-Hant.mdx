# 工時與費用

## 填寫本週工時

打開 **Time and Expenses** 下的 **My Week**。這裡列出你本週（週一到週日）的工時明細，按項目分組，可以直接在列表裡修改。要加一天的工作，點 **New**，填寫 **Project**、**Date**、**Hours**，需要的話再選 **Task**。**Timesheet** 留空即可：

- 會用你在這個項目上、期間包含這一天的那張工時單。
- 如果還沒有，就自動為你建一張這一週（週一到週日）的草稿工時單，把這筆明細放進去。

所以跨三個項目的一週可以逐行錄入，自動形成三張工時單，每個項目一張，各由自己的項目經理審批。修改一筆明細的 **Project** 或 **Date**，它會移到對應的工時單。已提交的工時單既不能移出明細，也不能移入明細。

**My Time** 列出你所有的明細，按工時單分組，最新的在前，可以用來補上週的工時。

一週填完後，打開 **Submit This Week**。這裡列出你本週涉及的工時單，每個項目一張。全選後點 **Submit**：每張單獨提交，交給它所屬項目的項目經理。如果某個項目已鎖定或已關閉，只有那張會被拒絕，其他的照常提交。單張工時單上也有 **Submit** 按鈕。

## 工時單

**Timesheet**（工時單）記錄一個人在一個項目上某個期間（通常是一週）的工時。打開 **My Timesheets**，點 **New**：

- 選擇 **Project**，以及 **Period Start** 和 **Period End**。一個期間最長 31 天。
- **Timesheet** 名稱留空時，會根據項目和期間自動填寫，之後改了項目或期間也會跟著更新。你自己輸入的名稱會原樣保留。
- **Approver**（審批人）是當時項目的項目經理，不能修改。

每個項目每個期間只保留一張工時單：同一項目、同一期間開始日期的第二張會被拒絕，提示訊息會指出第一張，請把工時加到那張上。

### 工時明細

每天的工作是工時單 **Time Entries** 分頁中的一筆 **Time Entry**（工時明細）：**Date**、**Hours**（從一刻鐘到 24 小時）、是否 **Billable**，以及備註。

- 日期必須在工時單的期間之內。
- 只能在自己被安排的項目上填報工時。否則會被拒絕，提示訊息會指出項目：請聯繫項目經理把你加進去。
- 工時明細在儲存時會從你的人員安排所用的費率卡複製 **Cost Rate** 和 **Bill Rate**，換算成每小時單價（一天按 8 小時計），並算出 **Cost** 和 **Amount to Bill**。不可計費的明細，或者以不可計費身分被安排的成員，計費金額為零。

工時單的 **Totals** 匯總它的明細：**Total Hours**、**Total Cost** 和 **Amount to Bill**。

### 提交與審批

| 狀態 | 含義 |
| --- | --- |
| **Draft** | 還在填寫 |
| **Submitted** | 已發給審批人。工時被凍結 |
| **Approved** | 工時計入項目成本。終態 |
| **Rejected** | 被退回。改回 Draft、修正後再提交 |

一週結束後，點 **Submit**（或在 **Submit This Week** 裡一次提交整週）。已提交的工時單不能再新增、修改或刪除明細，工時單本身在等待審批期間也被鎖定。

審批人在自己的 **Inbox**（**My Work** 群組下）裡點 **Approve** 或 **Reject**。**Timesheets to Approve** 列出同樣的工時單，方便決定前打開查看。

- **Approved**：工時計入項目成本。
- **Rejected**：退回 **Draft**，修正後再次提交，會重新交給審批人。
- **想改主意？**在等待審批時從自己的 Inbox 裡撤回，工時單會回到 **Draft**。

沒有人能手動設定 **Approved** 或 **Rejected**：這兩個狀態只由審批寫入。只有管理員可以手動設定，用來修復審批無法執行的工時單。

**審批依賴部署中的審批功能。** 向審批人發起審批、以及審批人做決定的 **Inbox**，都來自部署中的審批功能。如果部署不包含審批功能，就沒有人會被詢問：你提交的工時單照常儲存，顯示為 **Submitted** 並一直停在那裡，它的成本也不會自己計入項目。審批人也無法決定它：手動設定 **Approved** 或 **Rejected** 會被拒絕，提示訊息讓他去一個這個部署並不存在的 Inbox。此時由管理員決定每一張已提交的工時單，把它的 **Status** 設為 **Approved** 或 **Rejected**；批准後的工時單照常計入項目成本。

> **任何人都不能審批自己的工時。**審批人提交自己的工時單時，不會讓他自己審批，而是交給管理員。

**只有一個人的組織。** 沒有人能審批自己提交的申請，管理員也一樣，所以工時單需要另一位能審批它的使用者：項目的項目經理，或者一位管理員。工時單保留建立時的審批人：你擔任項目經理期間建立的工時單，會交給你以外的管理員。在這個人加入之前，提交的工時單停在 **Submitted**，沒有人能決定它：請在 **Inbox** 裡撤回，等這個人加入後再次提交。

## 費用

費用報銷是一個獨立的模組，面向所有員工：如何記錄費用、有哪些欄位、由誰審批，見[費用報銷](/zh-Hant/docs/expenses)。這裡只說項目帶來的部分。

費用可以選擇一個 **Project**，項目人員在這裡的 **Time and Expenses** 下也能找到 **My Expenses** 和 **Reports to Approve**。**Submit for Reimbursement** 會把每個項目的費用各自放進一張寫明該項目的報銷單。這張報銷單由項目經理審批，而不是報銷人自己的上級，提交時項目經理被記為它的 **Approver**；Total 從 2,000 起的財務審批和任何報銷單一樣（見[由誰審批](/zh-Hant/docs/expenses#由誰審批)）。報銷單批准時，單上的每筆費用隨之批准。

如果部署不包含審批功能，已提交的報銷單同樣停在 **Submitted**，沒有人會被詢問。由管理員把報銷單的 **Status** 設為 **Approved** 或 **Rejected** 來決定它；單上的費用隨報銷單變化，批准的費用計入項目成本。

[出差申請](/zh-Hant/docs/expenses/travel-requests)也可以選擇 **Project**，項目人員在這裡的 **My Expenses** 旁邊也能找到 **My Travel Requests**。項目上的出差申請由項目經理審批，只有一級，不論金額多少，所以出差和它的費用交給同一個人；沒有項目的出差申請交給出差人自己的上級。項目頁面的 **Related** 分頁列出這個項目的出差申請。出差申請是計劃，不是成本：它不計入項目成本，下面的鎖定也不阻止它。

## 如何成為項目的成本

只有 **Approved** 的工時單和費用才計入：

- 工時單的 **Total Cost** 計入項目的 **Labor Cost**，它的 **Amount to Bill** 計入 **Approved to Bill**。
- 費用的 **Amount** 計入項目的 **Expense Cost**；可計費的費用還計入 **Approved to Bill**。

Draft、Submitted 和 Rejected 的都不計入。一旦批准，項目的[成本和毛利](/zh-Hant/docs/projects#money)立即變化。

## 項目被鎖定時

項目經理或財務可以在項目上勾選 **Lock Time and Expenses**，通常是在收到[預算通知](/zh-Hant/docs/projects/projects-and-staffing#budget-lock)之後。勾選期間，提交這個項目上的工時單會被拒絕，提示訊息會寫明項目名稱。提交這個項目的報銷單同樣會被拒絕並說明原因，報銷單仍是 **Draft**。**Submit for Reimbursement** 和 **Submit for a Trip** 仍會產生這個項目的報銷單，但把它留作 Draft、費用仍在單上，照常提交其他項目的報銷單，並以一條寫明未提交報銷單的錯誤提示結束。先儲存為草稿：解除鎖定後照常提交。

## 項目已結束時

**Closed** 或 **Cancelled** 的項目不再接受工時和費用。在這樣的項目上新建工時單會被拒絕，把已有的工時單改掛到這樣的項目上也會被拒絕，提示訊息會寫明項目名稱和狀態。項目上已有的草稿工時單保持原樣，仍可編輯，但提交會被拒絕：把它改掛到 Active 的項目上再提交。

費用的 **Project** 選擇框不提供 Closed 或 Cancelled 的項目。已經掛在這樣項目上的報銷單（例如單上是項目關閉前寫好的費用）不能提交：提交會當場被拒絕並說明原因，報銷單仍是 **Draft**。刪除這張報銷單，把費用改掛到 Active 的項目上再重新提交。

**Completed** 的項目仍然接受補錄的工時單和費用。要停止補錄，勾選 **Lock Time and Expenses**，或關閉項目。
