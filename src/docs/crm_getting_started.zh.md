# 快速上手——第一天

写给第一次打开 HotCRM 的每个人。[概览](./crm_overview.md)讲的是四个业务领域各自做什么；这一页讲界面：应用打开在哪里、你自己的工作在哪里等着你，以及卡住时去哪里找答案。

## HotCRM 打开在哪里

应用会打开在你侧边栏显示的第一个入口上，而这个入口取决于你的岗位：

| 你是 | HotCRM 打开在 |
|---|---|
| 销售代表 | **销售主页**——你自己的数字、你的线索、进行中的商机和待办任务，以及即将到来的活动 |
| 客服专员或服务经理 | **服务概览**——工单仪表盘，位于**服务**分组顶部 |
| 销售经理、市场人员或管理员 | **首页**——**Executive Overview** 仪表盘 |

侧边栏只显示你有权查看、并且你的工作用得到的内容：销售代表看不到工单，**知识库**在**销售**分组的最后，而不在**服务**下；客服专员看不到管道类仪表盘，也看不到商机列表。如果你以为会有的入口不在，原因是你的权限，而不是故障——请联系你的管理员。

## 你自己的工作：我的工作

**我的工作**汇集了属于你的记录，你很少需要再去搜索：

- **我的任务**——你的待办任务，最先要做的排在前面。系统为你创建的任务（停滞商机的跟进、工单升级）也会出现在这里；见[活动](./crm_sales_activities.md)。
- **我的商机**和**我的线索**——你负责的商机和线索。服务人员名下没有商机，只看到**我的线索**。
- **我的日历**——你的会议和电话。
- **待我审批**——等你处理的审批请求（见下文）。
- **我的工单**——你负责的工单，供服务人员使用。

这些入口各自打开一个列表页，页面顶部的标签页提供同一批记录的其他视图，比如全部任务或管道看板。换一种视图就是那里的一个标签页，而不是侧边栏里再多一个入口。

## 审批：待我审批

有些记录会停下来等一个人处理：一笔大额商机、一个新客户、一次需要签批的线索转化。轮到**你**处理时，它会出现在**我的工作 › 待我审批**里；在那里打开它，批准或驳回。记录的负责人会收到结果通知。请求待审期间，相关记录会被锁定，不能编辑。每种审批由什么触发，写在该记录对应的页面里，例如[商机](./crm_sales_opportunities.md)。

## 通知

右上角的铃铛里是 HotCRM 发给你的提醒：分给你的新线索、紧急任务、大单成交、到期的提醒。很多提醒同时也会发邮件。每条提醒都链接到相关的记录。

## 查找记录

顶部的搜索框（**Ctrl+K**，Mac 上为 **⌘K**）可以按名称查找记录、列表、仪表盘和报表，也会列出你最近打开过的记录。

## 向助手提问

如果你的部署运行了平台助手（ObjectOS Cloud 和 Enterprise），你可以用平常的话问它关于 CRM 的问题："我哪些商机有风险？""给我 Acme 的全貌""给这条线索打分"。它只读取你能读取的内容，它能做的少数修改也都通过你自己会按的那些按钮完成。它在这里能做什么、能按哪些按钮，见[使用助手](./crm_ai_skills.md)。自行部署的开源版本不带助手，所以没有这个面板。

## 帮助

**帮助**是侧边栏最后一个分组，里面是各本手册，包括你正在读的这本；按岗位该读哪一篇，见[概览](./crm_overview.md)。这个分组默认是收起的：点击**帮助**展开它。
