# 定制化

本节面向用代码扩展 HotCRM 的开发者和技术实施人员。如果你是在应用里配置用户、权限、流程或共享规则，请从[管理](/zh-Hans/docs/administration/index)开始。

## 你可以构建什么

| 领域 | 内容 |
| --- | --- |
| [扩展对象](/zh-Hans/docs/customization/extending-objects) | 字段、对象、hooks、流程、校验、共享 |
| [AI skills](/zh-Hans/docs/customization/ai-skills) | Copilot skills 和 agent 接线 |
| [UI 扩展](/zh-Hans/docs/customization/ui-extensions) | 页面、视图、仪表盘、动作 |
| [测试与 CI](/zh-Hans/docs/customization/testing-and-ci) | 元数据校验和自动化检查 |

## 当前源码结构

HotCRM 是一个单体 ObjectStack 应用。请在 `src/` 下新增或修改元数据，然后从对应的 barrel 文件导出。

```text
src/
├── objects/        # 数据模型和对象 hooks
├── actions/        # UI 动作和可执行动作体
├── flows/          # 自动化
├── agents/         # AI agents
├── skills/         # AI skills
├── apps/
├── views/
├── pages/
├── dashboards/
├── reports/
├── profiles/
├── sharing/
├── translations/
└── data/
```

## 文件后缀协议

| 后缀 | 定义 |
| --- | --- |
| `*.object.ts` | 数据模型 |
| `*.hook.ts` | 对象生命周期逻辑 |
| `*.actions.ts` | UI 动作和可执行动作 |
| `*.flow.ts` | 自动化 |
| `*.skill.ts` | AI Copilot skill |
| `*.agent.ts` | AI agent |
| `*.page.ts` | UI 页面 |
| `*.view.ts` | 列表或看板视图 |
| `*.dashboard.ts` | 仪表盘 |
| `*.report.ts` | 报表 |
| `*.sharing.ts` | 共享规则 |
| `*.profile.ts` | 权限档案 |

## 黄金规则

- HotCRM 对象名使用 `crm_` 前缀。
- 使用 ObjectQL 和 ObjectStack API，不使用原始 SQL。
- 从对应的 `src/**/index.ts` 文件导出元数据。
- 新增用户可见标签时同步更新翻译。
- 发布前运行 `pnpm verify`。
