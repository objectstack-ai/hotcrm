# 合約

**合約**是你公司與客戶之間的法律協議——他們購買什麼、為期多久、價格如何、付款條款是什麼。在 HotCRM 中，合約是**活躍客戶關係的記錄系統**：一旦啟用，它就會解鎖帳戶上的 *Customer* 狀態。

## 5 種狀態

| 狀態 | 顏色 | 含義 |
| --- | --- | --- |
| ⚪ **Draft** | 灰色 | 正在談判，尚未簽署 |
| 🔵 **In Approval** | 藍色 | 已發送進行內部簽批 |
| 🟢 **Activated** | 綠色 | 已簽署並生效 |
| 🟠 **Expired** | 橙色 | 結束日期已過 |
| 🔴 **Terminated** | 紅色 | 提前取消 |

啟用是關鍵轉換——它會觸發帳戶被提升為 *Customer*。

## 6 種合約類型

| 類型 | 用於 |
| --- | --- |
| **Subscription** | 經常性存取——SaaS、軟體訂閱 |
| **Service** | 有時限的服務——諮詢、培訓 |
| **License** | 永久軟體許可 |
| **Partnership** | 經銷商、推薦、渠道合作夥伴協議 |
| **NDA** | 保密協議（零價值） |
| **MSA** | 主服務協議——多個 SOW 的總框架 |

## 合約記錄儲存的內容

| 區塊 | 欄位 |
| --- | --- |
| **Parties & Type** | 合約編號 *(自動)*、帳戶、類型、商機 *(如果源自某筆交易)* |
| **Status & Dates** | 狀態、開始日期、結束日期、簽署日期、啟用日期 |
| **Financials** | 合約價值、計費頻率、付款條款 |
| **Renewal** | 自動續約標記、續約通知（天數）、續約條款 |
| **Ownership** | 合約所有者、客戶經理 |
| **Documents** | 已簽署合約（檔案）、訂單表（檔案） |

## 計費頻率

客戶被開票的頻率：

- **One-Time**
- **Monthly**
- **Quarterly**
- **Annual**
- **Custom**

## 付款條款

客戶何時付款：

- **Net 15**——開票後 15 天內
- **Net 30** *(預設)*——30 天內
- **Net 45 / Net 60 / Net 90**
- **Due on Receipt**——立即
- **Prepaid**——預先付款

## 續約

三個欄位驅動續約：

- **Auto-Renew**——合約是否自動滾動續約？
- **Renewal Notice Days**——在結束日期前多少天提醒團隊（例如 60 天）
- **Renewal Terms**——自由文字說明（"續約時上調 5%，除非客戶選擇退出"）

當合約進入其續約視窗時，系統會建立一個跟進任務並向合約所有者發送郵件。

## 系統自動做的事

### 合約啟用時
所有者將合約提升為 *Activated*：

1. 如果帳戶曾是潛在客戶，則 **帳戶狀態 → Customer**。
2. 如果帳戶的 **Customer Since 日期**為空，則標記它。
3. 向主要聯絡人發送**歡迎郵件**（可配置）。
4. 向帳戶所有者發送**通知**。

### 每日——到期掃描
每晚午夜，系統會查找結束日期已過的 *Activated* 合約：

1. **狀態 → Expired**。
2. 向合約所有者發送**通知**。
3. 向帳戶所有者發送**通知**。

### 每日——續約提醒
每天上午 8 點，系統會查找進入其續約視窗的合約（在結束日期的 `renewal_notice_days` 範圍內），並向合約所有者發送一條提醒，帶一個一鍵操作"建立續約商機"。

### 手動終止
所有者可以將狀態更改為 *Terminated*。這是一個單向操作——已終止的合約無法重新啟用。審計日誌記錄誰在何時操作。

## 內建規則

- **結束日期必須晚於開始日期**——基本的合理性檢查。
- **合約價值必須為零或正數**——NDA 可以是 $0。
- **已啟用的合約不能被刪除**——改為將狀態更改為 Terminated。

## 共享

合約是 **私有** 的，也沒有任何共用規則放開它。合約的可見性 **不** 跟隨帳戶：

- **合約所有者** 讀取並編輯自己的合約。
- **Sales Manager** 與 **System Administrator** 能讀取全部合約（對該物件持有 *檢視所有*）；除管理員外，編輯權仍留在所有者手裡。
- **其他所有人** —— 包括透過區域或團隊共用規則拿到該帳戶的銷售代表 —— 只能看到自己擁有的合約。因此即使帳戶本身完全可讀，帳戶上的 *Contracts* 相關清單也可能是空的。

如果你的組織希望合約跟隨帳戶，需要管理員明確設定：在 Contract 上新增共用規則，或把它的 OWD 改成「由父層控制」—— 參見[共用與安全](/zh-Hant/docs/administration/sharing-and-security)。兩種做法都會對該物件的所有使用者放開合約可見性。

## 標準列表檢視

- **My Active Contracts**——`owner_id = me AND status = Activated`。
- **Expiring in 60 Days**——`end_date <= TODAY + 60 AND status = Activated`。
- **Up for Renewal**——在續約通知視窗內。
- **Expired This Month**——`status = Expired AND last_modified IN this month`。
- **Pending Activation**——`status IN [Draft, In Approval]`。

## 給合約所有者的提示

- ✅ **啟用時附上已簽署的 PDF**——審計人員會感謝你。
- ✅ **為企業級交易設定 Renewal Notice Days = 90**——給你整整一個季度去談判。
- ✅ **使用 Renewal Terms 欄位**來記錄交易——"價格鎖定 3 年；續約時上調 5%"。

## 給銷售代表的提示

- ✅ 當報價被接受、你建立合約時，**商機連結**會被預填——保留它；它驅動售後報表。
- ✅ 不要偷偷修改已啟用的合約——改為建立一份修訂（一份關聯到同一帳戶的新合約）。

## 給管理員的提示

- 合約啟用流程和到期掃描可以定制。參見 [管理 › 自動化](/zh-Hant/docs/administration/automation)。
- 合約類型和計費頻率選項列表是可擴展的。
