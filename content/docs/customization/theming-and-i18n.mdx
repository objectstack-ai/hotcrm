# Theming and i18n

HotCRM's current repository focuses on metadata labels and locale bundles. Runtime theming is handled by the ObjectStack shell; app-specific text lives in translations.

## App translations

Locale bundles live in `src/translations/`.

```text
src/translations/
├── en.ts
├── zh-CN.ts
├── es-ES.ts
├── ja-JP.ts
└── crm.translation.ts
```

When you add an object, action, page, view, dashboard, or report with user-visible labels, update the relevant translation files.

## Documentation translations

Product docs live in `content/docs/`.

| Locale | File pattern |
| --- | --- |
| English | `*.mdx` |
| Simplified Chinese | `*.zh-Hans.mdx` |
| Traditional Chinese | `*.zh-Hant.mdx` |

Navigation metadata follows the same pattern:

```text
meta.json
meta.zh-Hans.json
meta.zh-Hant.json
```

## Workflow

1. Update the English source page first.
2. Mirror the structural changes in localized pages.
3. Keep links locale-aware, for example `/zh-Hans/docs/...`.
4. Run the docs type check or build.

```bash
pnpm --filter @hotcrm/docs types:check
pnpm --filter @hotcrm/docs build
```

## Verification

For app metadata:

```bash
pnpm validate
pnpm typecheck
```

For docs:

```bash
pnpm --filter @hotcrm/docs types:check
```
