# 订单

**订单**记录客户这一次买了什么：哪些产品或服务、多少、什么价格。它是一笔交易最终落地的记录。**合同**记录双方约定了什么，是可选的：订单可以挂在一份框架合同下，但大多数订单没有合同。

| | 订单 | 合同 |
| --- | --- | --- |
| 记录 | 这一次买了什么 | 双方约定了什么 |
| 明细 | 有；小计是各订单行之和 | 没有明细 |
| 日期 | 下单日期、发货日期 | 开始、结束、期限、续约 |
| 适用 | 一次销售 | 订阅、项目服务、框架协议、保密协议 |

一张订单最多属于一份合同；一份合同可以有多张订单，也可以没有。

## 在哪里找到订单

- 销售应用 **销售** 分组中的 **订单**。
- 客户页面上的 **订单** 列表，以及订单所挂合同的页面上的 **订单** 列表。
- 订单与回款应用中的 **订单、合同与客户**，财务在这里查看订单。

订单只展示给使用报价单的人：销售代表、销售经理、销售管理层和管理员，以及只读查看的财务（应收会计和财务总监）。服务和市场人员看不到订单。

## 订单状态

| 状态 | 含义 |
| --- | --- |
| ⚪ **草稿** | 正在整理 *（新订单的默认状态）* |
| 🔵 **已确认** | 已与客户确认；订单行被锁定 |
| 🟢 **已完成** | 已交付完毕 |
| ⚫ **已取消** | 不再执行 |

订单按 **草稿 → 已确认 → 已完成** 推进。**已确认** 可以退回 **草稿**，**草稿** 或 **已确认** 可以改为 **已取消**。**已完成** 和 **已取消** 是最终状态；其他任何状态变更在保存时都会被拒绝。

## 订单记录保存的内容

| 分组 | 字段 |
| --- | --- |
| **订单信息** | 订单编号、订单名称、订单负责人、所属客户、联系人、关联商机、状态、下单日期、关联合同、客户采购单号、描述 |
| **价格** | 小计、折扣 (%)、折扣金额、税额、运费及手续费、总金额、付款条款 |
| **发货** | 发货状态、发货日期 |
| **地址** | 账单地址、收货地址 |
| **系统** | 外部编号 |

**客户采购单号** 是客户自己采购单上的编号。**外部编号** 是这张订单在其他系统（例如它来自的订单系统）中的编号；两张订单不能使用同一个外部编号。

## 订单行

每一行包括产品、产品标题、描述、数量、标价、销售单价、行折扣，以及这一行的小计和总计，与报价单明细相同。

- **选择产品**：这一行以产品名称作为标题、带出产品的标价，销售单价默认等于标价，可以改成别的价格。
- **没有产品？** 填写这一行的 **产品标题** 和 **销售单价**。目录里没有的东西就这样录入；报价与产品模块关闭时（其产品选择器为空），订单行也这样录入。
- 订单行的标价取自产品本身，而不是价格表。

## 合计如何计算

```
小计       = Σ 订单行（数量 × 销售单价 × (1 − 行折扣 %)）
折扣金额   = 小计 × 订单折扣 %
总金额     = 小计 − 折扣金额 + 税额 + 运费及手续费
```

每次添加、修改或删除订单行，小计都会重新计算；小计、折扣、税额或运费任一变化时，折扣金额和总金额随之更新。没有订单行的订单保留你填写的小计。

## 已确认订单的订单行被锁定

订单离开 **草稿** 后，订单行不能再添加、修改或删除，**订单行** 列表上也不再显示 **新建**。要修改已确认订单的订单行，请先把它退回 **草稿**，改完后再确认。已完成或已取消订单的订单行保持不变。订单的其他字段（例如发货字段）仍可编辑。

## 发货

**发货状态**（*未发货*、*部分发货*、*已发货*）和 **发货日期** 表示订单发货到了哪一步。它们由人手动填写或由导入填写；HotCRM 中没有别的功能会改动它们，背后也没有库存或发货单。

## 标准列表视图

| 视图 | 显示内容 |
| --- | --- |
| **全部订单** *（落地标签）* | 你有权看到的每一张订单：订单编号、订单名称、所属客户、状态、下单日期、发货状态、总金额（带列合计）、订单负责人。按下单日期从新到旧排序。 |
