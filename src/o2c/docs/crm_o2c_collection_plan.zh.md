# 回款计划——合同签订后销售看到什么

写给销售代表和销售经理。「订单与回款」在每份合同上显示：开票了没有、回款了没有、哪些已经逾期。财务在别处记账，并把发票和回款记录到这里；销售维护的只有一样东西——合同的**回款计划**，即一组**回款节点**。

回款节点属于合同所在的**客户**，并写明它按哪份合同制定；没有合同的节点会被拒绝。选择合同会带出客户。

## 谁可以修改回款计划

销售代表、销售经理和管理员，只要能查看这个客户，就能添加、修改和删除它的回款节点，不需要能编辑客户或合同。能查看客户及其合同的人都能查看它的回款节点。财务可以查看，但从不修改。

## 数字统计什么

| 数字 | 统计什么 |
| --- | --- |
| **已开票** | 关联到该节点、状态为**已开具**的发票。已作废的发票不计入。 |
| **已回款** | 关联到该节点的回款：财务直接关联的，以及针对该节点发票的每一笔回款。 |
| **未回款** | **计划金额**减去**已回款**。小于零表示收到的比计划多。 |

这些数字都不用填写：财务保存发票或回款时，它们随之变化。针对发票的回款会自动带上发票的回款节点。如果财务之后把发票改到另一个节点，已记录的回款保留原来的节点，直到在这些回款上重新选择一次发票。

**验收日期**是客户签字验收这个节点的日期。由人记录，系统不会代填。

## 本月计划回款

「订单与回款」应用的**跟进 → 本月计划回款**（也是**销售**应用**回款计划 → 回款节点**列表上的一个标签页）列出**计划日期**在当前自然月内的回款节点。每月 1 日起切换到新的月份。

## 合同和客户上的汇总

合同上有**计划回款**、**已开票**、**已回款**和**应收余额**，统计填了这份合同的记录；客户上有**已开票**、**已回款**和**应收余额**，统计它的所有发票和回款，包括没填合同的。**已开票**只统计已开具的发票。**应收余额**是客户在未结清发票上仍欠的金额，即已开具发票的**未付**金额之和；尚未对应到发票的回款（例如预收款）只计入**已回款**。在合同上，它们显示在**合同金额**分区；在客户上，显示在**财务信息**分区。保存回款节点、发票或回款时随之更新，没有人能编辑。能查看合同的人都能看到合同上的汇总；客户上的汇总要有和客户款项打交道的角色才能看到（销售、财务、市场、服务、项目经理、管理员）。只有每个成员都有的 CRM 用户权限集的人，或者顾问，能查看客户，但看不到这些汇总。
