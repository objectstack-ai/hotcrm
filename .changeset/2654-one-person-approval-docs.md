**The docs say how a one-person organization gets its timesheets, expense reports and travel requests approved (#2654).**

Nobody approves a request they submitted, an administrator included, so in an organization with one user a submitted timesheet, expense report or travel request waited in Submitted with nobody able to decide it, and no page said why. The Project Delivery and Expenses manuals (English and Chinese) and the Time and Expenses, Expenses and Travel Requests pages (English, Simplified and Traditional Chinese) now state the rule and the way on:

- Approval needs a second user who can approve it. A timesheet, or an expense report or travel request on a project: the project's Project Manager or an administrator. One with no project: your manager, a Finance Controller or an administrator. An expense report of 2,000 or more also needs a Finance Controller or an administrator.
- A timesheet keeps the approver it was created with, so one created while you were its project's Project Manager goes to an administrator other than you.
- A request already waiting stays in Submitted: recall it from the Inbox and submit it again once that person has been added.

No approval rule, flow or permission changes.
