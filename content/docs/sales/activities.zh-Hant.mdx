# 活動

**活動**是你相對於另一筆記錄去做、或者欠下的任何事項。HotCRM 把活動放在**兩個**物件裡，本頁講的是第一個：

- **任務**（`crm_task`）——你仍然**欠**某人的事：要打的電話、要發的郵件、要安排的跟進。它錨在**截止日期**上。
- **活動（Event）記錄**（`crm_event`）——佔用某個人日曆上一個時段的會議或電話，無論它已經發生，還是預約在之後。它錨在**開始時間與結束時間**上，在場的每個人都是一筆真實記錄。見[會議與電話](/zh-Hant/docs/sales/meetings-and-calls)，那一頁有完整的任務 / 活動記錄對照表。

兩者都幾乎可以附加到任何東西上：客戶、聯絡人、商機、潛在客戶或案例。

## 活動有什麼用

- 🗓 **追蹤你對客戶的承諾**——*"週二跟進 Jane"*。
- 🔁 **標準化打法**——*"演示後 24 小時發送提案回顧郵件"*。
- 📈 **衡量活動量**——一個本週沒有記錄任何通話的銷售代表是一個輔導機會。
- 🤝 **交接**——當你休假時，你的經理可以看到你的開放任務。

## 5 種活動狀態

| 狀態 | 含義 |
| --- | --- |
| ⚪ **未開始** | 已建立但尚未開始 *(預設)* |
| 🟠 **進行中** | 你正在處理它 |
| 🟡 **等待中** | 被他人阻塞 |
| 🟢 **已完成** | 完成 |
| ⚪ **已推遲** | 無限期推遲 |

## 4 個優先級別

| 優先級 | 何時使用 |
| --- | --- |
| 🔵 **低** *(預設)* | 錦上添花 |
| 🟢 **普通** | 例行工作 |
| 🟠 **高** | 重要，今天就做 |
| 🔴 **緊急** | 放下一切 |

當你建立一個緊急任務時，負責人會收到一封郵件提醒。

## 6 種活動類型

- **電話**——你還要打的一通電話
- **郵件**——外發或入站郵件
- **會議**——你還要張羅的一次對話
- **跟進**——一次通用的回訪
- **演示**——一次產品演示
- **其他**——其他任何事項

這裡的*電話*和*會議*標注的是一件**待辦**——*"週二給 Jane 回個電話"*。任務帶的是截止日期，而不是開始與結束時間，也沒有參與者名單。真正打完的那通電話、你正要預約到下週的那場會議，是一筆活動（Event）記錄——由記錄上的 **Log a Call**、**Log a Meeting**、**Schedule a Meeting** 三個按鈕寫入。見[會議與電話](/zh-Hant/docs/sales/meetings-and-calls)。

## 活動記錄儲存的內容

| 區塊 | 欄位 |
| --- | --- |
| **基本** | 主題、描述、類型、狀態、優先級 |
| **日程** | 截止日期、提醒日期/時間、完成日期 |
| **指派** | 負責人 |
| **關聯到** | 客戶、聯絡人、商機、潛在客戶或案例 |
| **重複** | 它是重複性的嗎？每日 / 每週 / 每月 / 每年，帶間隔和結束日期 |
| **追蹤** | 預計工時、實際工時、進度 % |

## 重複任務

將一個任務標記為重複，並選擇節奏（每日 / 每週 / 每月 / 每年）和間隔（每 1 週、每 2 個月等）。當你完成當前實例時，系統會生成新實例，一直持續到重複結束日期。

用例：

- *與關鍵客戶的季度回訪*——每月重複 × 3。
- *每日站會記錄*——每日重複。
- *合約結束前 60 天的續約提醒*——由合約流程自動設定。

## 自動發生的事

- **標記已完成** → `is_completed` 被設為 true，`completed_date` 被蓋戳為現在，`progress_percent` 變為 100。這些你都不必手動設定。
- **已逾期** → 如果一個任務超過其截止日期且未完成，系統會將其標記為**逾期**（列表視圖中的紅色徽章）。
- **緊急提醒** → 建立或儲存一個*緊急*任務會向負責人發送郵件。

## 內建規則

- 一個標記為**已完成**的任務必須有完成日期（系統會為你填上）。
- 一個**重複**任務必須設定重複類型，否則系統會要求你提供。
- 一個警告提示會建議將任務關聯到至少一筆相關記錄（客戶、商機等），以免它遺失。

## 活動出現在哪裡

活動會出現在**三個**地方：

1. **任務列表**——全局的「我的任務」標籤頁。
2. **相關記錄上的活動標籤頁**——打開一個客戶，可以看到所有相關任務。
3. **首頁活動小工具**——*今日任務*和*逾期任務*。

## 標準列表視圖

- **我的開放任務**——你未完成的任務。
- **逾期**——已過截止日期，未完成。
- **今天**——今天到期。
- **本週**——未來 7 天內到期。
- **本週已完成**——用於活動報告。
- **按優先級**——按優先級降序排序。

## 系統如何使用活動

- **客戶最近活動日期**——沉默客戶報表所依據的客戶接觸時點時鐘。任務完成只是刷新它的**四個**動作之一：一筆活動（Event）記錄變為**已舉行**、一個任務被完成、在聯絡人上 **Send Email**、一個案例被設為*已解決*。這個時點戳還會**沿關係鏈向上走**——你在商機、聯絡人或案例上完成任務，系統會順著關聯為背後的客戶蓋戳，這正是一個往來頻繁的客戶不會在整個銷售週期裡顯得沉默的原因。完整表格（含唯一一個非互動來源：修改客戶的負責人或類型同樣會蓋戳）見[會議與電話](/zh-Hant/docs/sales/meetings-and-calls)的「什麼會刷新最後互動」一節。
- **停滯的交易**——商機上**沒有**屬於自己的最近活動欄位；你記錄在交易上的活動，刷新的是它背後的**客戶**。讓一筆安靜下來的交易浮出水面的是**當前階段停留天數**（由進入當前階段日期推算），以及每日的[停滯商機提醒](/zh-Hant/docs/administration/automation)——它會提醒負責人並建立一個跟進任務。
- **Sales Activity（銷售活動）儀表板**——活動量指標在這張儀表板上，不在 Sales Performance（銷售業績）上，後者只承載管道指標。**Activity by Rep** 依負責人拆分已記錄的互動量——統計的是狀態為 **Held（已舉行）** 的活動（Event）記錄，也就是真正發生過的電話與會議，**不含任務**；已完成的任務由同一張儀表板上的 **Tasks Completed** 磁貼單獨統計。兩者都沒有按週的時間窗：這張儀表板刻意不帶日期範圍選擇器，按週的讀數由相鄰的 **Activity Volume by Week** 圖表給出。參見[儀表板](/zh-Hant/docs/analytics/dashboards)。

## 給銷售代表的提示

- ✅ 已經打完的電話用 **Log a Call** 記錄，而不是建一個*電話*任務——它寫入的是一筆帶參與者和時長的[活動（Event）記錄](/zh-Hant/docs/sales/meetings-and-calls)，也正是它會進入客戶的互動歷史。*電話*任務留給你還沒打的電話。
- ✅ 如果你會在截止日期前忘記，請設定*提醒日期/時間*。
- ✅ 將任務關聯到**商機**，而不僅僅是客戶——這才能讓它出現在商機時間線上。

## 給服務坐席的提示

- ✅ 對正在等待客戶的案例使用*跟進*任務；將截止日期設為今天 + 3 以記得去催。

## 給管理員的提示

- 緊急任務郵件提醒範本可以自訂。
- 重複任務每個週期生成一個新實例。沒有日曆式的重複編輯器——請逐個調整間隔。
- 活動類型（電話 / 郵件 / 會議 / 等）可以透過選擇列表擴展。參見 [Customization › Extending Objects](/zh-Hant/docs/customization/extending-objects)。
