# 發票與回款

本應用未隨附繁體中文語言包，因此本頁出現的介面名詞依固定順序取用：zh-CN 語言包已收錄者，採其用詞的繁體寫法；未收錄者，保留產品內的英文原名，不另造譯名。

這裡的**發票**（**Invoice**），是財務在自己系統中開立的一張發票的紀錄；**回款**（**Payment**），是收到款項的紀錄。兩者都由財務輸入或匯入。業務在合約、客戶和 **Order to Cash** 下的清單中查看它們。

## 發票 [#invoices]

| 欄位 | 內容 |
| --- | --- |
| **Invoice Number** | 財務開立的發票上的號碼 |
| **Contract** | 這張發票針對的合約 |
| **Billing Milestone** | 這張發票對應的回款節點（如有）。只提供這張發票所屬合約的節點 |
| **Issue Date** | 開立的日期 |
| **Due Date** | 應付款的日期（見下文） |
| **Amount** | 開票金額，含稅 |
| **Status** | **Issued** 或 **Cancelled** |
| **Paid** | 針對這張發票收到的回款合計 |
| **Open** | **Amount** 減去 **Paid**；已作廢的發票為零 |
| **Invoice File** | 發票檔案（如已附上） |

**到期日。** **Due Date** 留空時，儲存時會自動填寫：**Issue Date** 加上合約的 **Payment Terms**（Net 15、30、60 或 90 天；Due on Receipt 即開票當天）。填寫了日期則按填寫的儲存。

**已作廢的發票。** 在源頭作廢或全額折讓的發票，在這裡設為 **Cancelled**。它隨即退出所有統計：所屬節點不再把它計為已開票，未付金額為零。

## 逾期發票 [#overdue-invoices]

**Order to Cash → Invoices** 下的**逾期發票**清單，按到期日從早到晚列出你能看到的、狀態為 **Issued**、**Due Date** 早於今天且仍有 **Open** 金額的發票。回款付清當天，或財務將其作廢後，發票就會離開這個清單。

## 回款 [#payments]

| 欄位 | 內容 |
| --- | --- |
| **Payment Number** | 自動編號：PAY-00001、PAY-00002…… |
| **Contract** | 這筆款項針對的合約 |
| **Invoice** | 這筆款項支付的發票（如有）。只提供這筆回款所屬合約的發票 |
| **Billing Milestone** | 這筆款項計入的節點。有發票時從發票帶入；開票前收到的預付款，請自行選擇 |
| **Payment Date** | 收到款項的日期 |
| **Amount** | 收到多少 |
| **Method** | **Bank Transfer** 或 **Other** |

**每張發票一行。** 一筆收款支付了多張發票時，按財務已有的拆分，每張發票記錄一筆回款。HotCRM 中沒有分攤這一步。

**開票前的預付款。** 把回款記錄到回款節點上。發票開立後，在同一筆回款上填寫 **Invoice**。

**針對其他合約發票的回款會被拒絕**，提示會寫明是哪張發票。這只可能發生在匯入中，因為表單只提供本合約的發票。

## 匯入 [#importing]

財務可以用 **Invoice Import (CSV)** 和 **Payment Import (CSV)** 兩個匯入對應，從試算表、會計軟體或 ERP 的匯出檔案批次匯入發票和回款。帶有正確欄位標題的範本是 `assets/import-templates/` 下的 `invoices.csv` 和 `payments.csv`。

| 欄 | 發票 | 回款 |
| --- | --- | --- |
| ERP Reference | ✓ 唯一編號 | ✓ 唯一編號 |
| Contract | ✓ 合約編號，例如 CTR-0001 | ✓ |
| Invoice Number | ✓ | — |
| Invoice | — | ✓ 發票號碼 |
| Billing Milestone | ✓ 節點名稱 | ✓ |
| Issue Date、Due Date、Amount、Status | ✓ | — |
| Payment Date、Amount、Method | — | ✓ |

- **ERP Reference 是唯一鍵。** 匯入一行時，如果它的 **ERP Reference** 已在某張發票上，就更新這張發票，而不會再新增一張。因此財務修改檔案後可以再次匯入。ERP 透過介面寫入時使用同一個編號。
- **每一筆匯入的紀錄都有標記。** 它的 **Source** 為 **Import**，**Synced At** 為匯入的時刻，讀者可以看出數字從哪裡來、有多新。手動輸入的紀錄，**Source** 為 **Manual entry**。
- **參照按名稱比對。** 合約編號、發票號碼或節點名稱比對不到任何紀錄時，該行匯入失敗，匯入報告會寫明原因。

金額使用公司的幣別，與 HotCRM 中所有金額一樣。請在匯入前完成換算。
