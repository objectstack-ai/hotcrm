# 主題與 i18n

目前倉庫主要維護中繼資料標籤和 locale bundles。執行時主題由 ObjectStack shell 處理；應用內文案放在翻譯檔案中。

## 應用翻譯

Locale bundles 位於 `src/translations/`。

```text
src/translations/
├── en.ts
├── zh-CN.ts
├── es-ES.ts
├── ja-JP.ts
└── crm.translation.ts
```

新增帶使用者可見標籤的物件、動作、頁面、視圖、儀表板或報表時，請同步更新相關翻譯檔案。

## 文件翻譯

產品文件位於 `content/docs/`。

| 語言 | 檔案模式 |
| --- | --- |
| 英文 | `*.mdx` |
| 簡體中文 | `*.zh-Hans.mdx` |
| 繁體中文 | `*.zh-Hant.mdx` |

導覽中繼資料遵循同樣模式：

```text
meta.json
meta.zh-Hans.json
meta.zh-Hant.json
```

## 工作流

1. 先更新英文源頁面。
2. 在本地化頁面中同步結構變化。
3. 連結保持 locale-aware，例如 `/zh-Hant/docs/...`。
4. 執行文件類型檢查或構建。

```bash
pnpm --filter @hotcrm/docs types:check
pnpm --filter @hotcrm/docs build
```

## 驗證

應用中繼資料：

```bash
pnpm validate
pnpm typecheck
```

文件：

```bash
pnpm --filter @hotcrm/docs types:check
```
