# Installation

## Prerequisites

- **Node.js ≥ 20**
- **pnpm ≥ 10**
- A C/C++ toolchain (for the `better-sqlite3` native build): Xcode CLT on macOS, `build-essential` on Linux, or Visual Studio Build Tools on Windows.

You do not need a database server — the dev runtime uses `better-sqlite3` and creates a file at `.objectstack/data/standalone.db`.

## Clone & Install

```bash
git clone https://github.com/objectstack-ai/hotcrm.git
cd hotcrm
pnpm install
npm rebuild better-sqlite3    # ensures the native binding is built
```

> **Why `npm rebuild`?** pnpm's lifecycle-script approval prompt blocks the native build on first install. Running `npm rebuild` once produces `node_modules/better-sqlite3/build/Release/better_sqlite3.node`. Alternatively, run `pnpm approve-builds` and follow the prompts.

## Link the UI Apps (dev only)

The `@objectstack/console` and `@objectstack/account` admin UIs aren't published to npm yet; they live in the `framework` monorepo next door. Symlink them:

```bash
git clone https://github.com/objectstack-ai/framework.git ../framework
ln -sf $(pwd)/../framework/apps/console node_modules/@objectstack/console
ln -sf $(pwd)/../framework/apps/account node_modules/@objectstack/account
```

`@objectstack/studio` is on npm and installs automatically.

## Build & Run

```bash
pnpm build      # compiles src/ → dist/objectstack.json
pnpm dev        # starts the dev server on http://localhost:3000
```

Expected dev-server banner:

```
✓ Server is ready

  ➜  API:       http://localhost:3000/
  ➜  Studio:    http://localhost:3000/_studio/
  ➜  Account:   http://localhost:3000/_account/
  ➜  Console:   http://localhost:3000/_console/

Plugins: 29 loaded
```

## Create Your First User

```bash
curl -X POST http://localhost:3000/api/v1/auth/sign-up/email \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com","password":"admin123","name":"You"}'
```

The first sign-up triggers seed loading — about 90 records across 9 tables. Verify:

```bash
sqlite3 .objectstack/data/standalone.db \
  "SELECT 'account',COUNT(*) FROM account UNION ALL
   SELECT 'lead',COUNT(*) FROM lead UNION ALL
   SELECT 'opportunity',COUNT(*) FROM opportunity"
```

Open [http://localhost:3000/_console/](http://localhost:3000/_console/) and log in.

## Production

For production, swap the SQLite driver for Postgres or MongoDB by adding the driver package and setting `OS_DATABASE_URL`. See [Architecture → Data Protocol](/docs/architecture/data-protocol) for driver options.

## Troubleshooting

| Symptom | Fix |
|---|---|
| `Cannot find package '@objectstack/metadata'` | Run `pnpm install` again — explicit deps are declared in `package.json`. |
| `Could not locate the bindings file` (better-sqlite3) | `npm rebuild better-sqlite3` |
| `@objectstack/console not found — skipping UI` | Re-create the symlinks above. |
| Empty `_console` page | Sign up first — the UI requires an authenticated session. |
| `pnpm dev` fails on port 3000 | Another process is using the port; `kill` it or set `PORT=3001`. |
