# 回款計劃

本應用未隨附繁體中文語言包，因此本頁出現的介面名詞依固定順序取用：zh-CN 語言包已收錄者，採其用詞的繁體寫法；未收錄者，保留產品內的英文原名，不另造譯名。

合約的**回款計劃**由一組**回款節點**（**Billing Milestone**）組成：每個節點寫明業務預計在哪一天收多少錢。一筆軟體交易可能是預付款 30%、上線 40%、驗收 25%，一年後再收 5% 保留款；訂閱則每個計費週期一個節點。

回款計劃屬於業務。財務的發票和回款會對照它統計，但從不修改它。

## 制定回款計劃 [#building-the-plan]

在合約上打開 **Billing Milestones** 分頁，為付款安排的每一部分新增一個節點：

| 欄位 | 填寫什麼 |
| --- | --- |
| **Milestone** | 合約裡這一步的說法：「預付款 30%」「上線」「第二年」 |
| **Planned Amount** | 這一步應收多少 |
| **Planned Date** | 預計哪天收到 |
| **Accepted Date** | 按驗收付款的節點：客戶簽字驗收的日期。由你記錄，系統不會代填 |
| **Notes** | 團隊需要知道的其他資訊 |

儲存時，節點的 **Account** 會從合約帶入。

只要你能編輯合約所屬的客戶，就能在該合約上新增、修改或刪除回款節點。合約變更後，請相應修訂回款計劃：回款計劃是預測，從來不是帳本。

## 數字統計什麼 [#figures]

每個節點顯示三個數字。它們不需要你填寫，而是跟隨財務的紀錄變化。

| 數字 | 統計什麼 |
| --- | --- |
| **Invoiced** | 財務關聯到這個節點、狀態為 **Issued** 的發票金額。已作廢的發票不計入。 |
| **Received** | 計入這個節點的回款：財務直接關聯到它的回款（開票前收到的預付款），以及針對這個節點的發票收到的回款。 |
| **Open** | **Planned Amount** 減去 **Received**。收到的比計劃多時會小於零。 |

針對發票收到的回款會自動計入這張發票所屬的節點，財務只需關聯發票。如果財務之後把發票改到另一個節點，已記錄的回款保留原來的節點；在這樣的回款上重新選擇一次發票，它也會隨之改過去。

## 本月計劃回款 [#planned-this-month]

**Order to Cash → Billing Milestones** 下的**本月計劃回款**清單，按日期先後列出你能看到的、**Planned Date** 在目前自然月內的所有節點，以及目前已開票和已回款的金額。它隨日曆變化：每月 1 日起顯示新的月份。
