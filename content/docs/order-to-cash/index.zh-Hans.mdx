# 订单与回款

合同签订后，销售最关心三个问题：**开票了吗？回款了吗？有没有逾期？**「订单与回款」回答的就是这三个问题。它是 HotCRM 的一个模块，位于侧边栏的**订单与回款**下。

## 是窗口，不是账本 [#a-window-not-a-book]

每张发票、每笔回款都保存在财务记账的地方：ERP、财务软件，或财务自己的记录。「订单与回款」是销售**查看**它们的窗口。财务在记录页面上录入，或批量导入；ERP 也可以通过同一个导入编号写入。数字从不在 HotCRM 里更正：在源头更正后，再按同样的方式进来。

因此这个模块不做任何记账。它不开具、不审批发票，不分摊收款，不与银行对账，不催收，也不确认收入。赢单和合同生效时通知计费系统的，仍然是[计费交接](/docs/revenue/billing-handoff)。

销售在这里维护的只有一样东西：自己的**回款计划**。

## 包含什么 [#whats-included]

| 记录 | 是什么 | 由谁录入 |
| --- | --- | --- |
| **回款节点** | 合同回款计划中的一步：预付款、上线、验收、质保金，或一个订阅周期 | 合同的销售团队 |
| **发票** | 财务针对合同开具的一张发票 | 财务 |
| **回款** | 针对合同、发票或回款节点收到的款项 | 财务 |

三者都挂在**合同**下。打开合同，**回款节点**、**发票**和**回款**三个标签页分别列出它们；客户页面列出该客户所有合同的同类记录。

| 页面 | 内容 |
| --- | --- |
| [回款计划](./collection-plan) | 规划合同的回款节点，以及「已开票」「已回款」「未回款」各统计什么 |
| [发票与回款](./invoices-and-payments) | 录入和导入发票与回款、到期日、逾期发票、票据 |

## 谁能做什么 [#who-can-do-what]

| 人员 | 回款计划 | 发票与回款 |
| --- | --- | --- |
| 销售代表、销售经理 | 在自己可编辑其客户的合同上新建、编辑、删除回款节点 | 只读 |
| 应收会计（财务） | 只读 | 在所有合同上录入、导入、编辑、删除 |
| 管理员 | 全部 | 全部 |

其他能查看合同的人，也能随合同一起查看它的回款计划、发票和回款：这三类记录跟随合同的共享设置。财务的权限来自**应收会计**岗位，由管理员在 **Setup → Position Holders** 中指派。

销售从不录入回款。销售看到的数字永远是财务录入的，所以按回款计算的提成方案不会读到销售自己填写的数字。

## 不是每个客户都要用 [#not-every-customer-uses-it]

不需要「订单与回款」的公司，由管理员停用这个模块。它的菜单项、记录，以及合同和客户页面上的相关标签页都会随之消失。

## 后续 [#coming-next]

合同和客户记录本身的汇总数字（计划、已开票、已回款和未收应收款）将在后续更新中提供（hotcrm#2416）。在此之前，合同页面上的每个标签页各自列出金额。
