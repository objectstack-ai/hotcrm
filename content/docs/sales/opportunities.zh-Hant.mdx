# 商機

**商機**是一筆活躍的交易——一個有已知客戶、金額、成交日期和階段的潛在營收事件。這是銷售代表每天都要處理的記錄。

## 7 個銷售階段

每個商機都會經歷這些階段。系統會追蹤你所處的位置並自動更新贏單機率。

| 階段 | 預設贏單機率 | 處於此階段時 |
| --- | --- | --- |
| ⚪ **開發期** | 10% | 首次接觸，審核預算和需求 |
| 🟠 **資格審核** | 25% | 你已識別出決策者 |
| 🟡 **需求分析** | 40% | 需求已被記錄 |
| 🔵 **提案** | 60% | 報價已發送 |
| 🟣 **談判** | 80% | 正在協商定價和條款 |
| 🟢 **贏單** | 100% | **交易贏得** *(最終階段)* |
| 🔴 **輸單** | 0% | **交易失去** *(最終階段)* |

你可以從任何開放階段直接移動到**輸單**（交易隨時可能失去），但你不能向前跳過——你必須一次一個階段地走過漏斗。系統會攔截無效跳轉，以保持你的預測真實可靠。

## 商機記錄儲存的內容

詳情介面有 7 個區塊：

| 區塊 | 欄位 |
| --- | --- |
| **基本資訊** | 名稱、客戶、主要聯絡人、負責人 |
| **財務** | 金額、預期營收 *(自動)*、機率 *(從階段自動得出)* |
| **銷售流程** | 階段、成交日期、建立日期、當前階段停留天數 |
| **分類** | 類型（新業務 / 升級 / 續約 / 擴展）、潛在客戶來源 |
| **競爭與行銷活動** | 競爭對手、來源行銷活動 |
| **備註與後續步驟** | 描述、後續步驟 |
| **預測與指標** | 行項目合計、審批狀態 |

## 商機類型

| 類型 | 含義 |
| --- | --- |
| **新業務** | 全新的品牌 / 客戶 |
| **現有 - 升級** | 現有客戶升級到更高層級 |
| **現有 - 續約** | 現有合約續約 |
| **現有 - 擴展** | 現有客戶增加新產品線 |

按類型拆分交易對於準確的營收預測至關重要——新業務和續約的贏單率差異很大。

## 自動發生的事

你無需記住其中任何一項——系統會為你完成：

- 每當你推進交易時，**機率**會從階段中設定（如果你有特殊情況，*可以*手動覆蓋，但下次階段變化時它會重置）。
- **預期營收** = 金額 × 機率 ÷ 100，每當金額或機率變化時重新計算。
- **當前階段停留天數**每天重新計算——它能暴露停滯的交易。
- 當你將一筆交易標記為**贏單且金額超過 $100K** 時，銷售管理層會收到郵件。
- 當金額超過 **$500K** 時，交易會自動進入 [折扣審批](/zh-Hant/docs/revenue/approvals) 流程。

## 行項目——實際在銷售什麼

每個商機可以有行項目——每個所售產品一項。每一行儲存：

- 產品（來自目錄）
- 數量
- 單價（預設為產品的標價，可以被覆蓋）
- 折扣 %
- 行合計

所有行項目之和彙總到商機**金額**中。如果你更願意直接手動鍵入金額而不設定行項目，也可以——兩種方式都行。

## 高價值交易的折扣審批

如果一筆交易的**金額超過 $500,000**，商機會被自動路由進行審批：

1. 商機被**鎖定**——無人可以編輯它。
2. **銷售經理**首先審核。
3. 如果批准，**銷售總監**簽字確認。
4. 最終批准後，階段會被自動設為**贏單**。
5. 如果在任何步驟被拒絕，交易會被退回給銷售代表重新論證。

審批狀態會顯示為商機詳情介面頂部的橫幅。完整流程參見 [Revenue › Approvals](/zh-Hant/docs/revenue/approvals)。

## 共享——誰能看到哪筆交易

預設情況下商機是**私有**的——只有負責人以及角色層級中位於其之上的人才能看到。

在此之上：

- **$100K 或以上的開放商機**會以*唯讀*方式與銷售總監及層級中位於其之下的所有人共享。這樣領導層無需跟進就能看到大單。
- **審批中的高價值交易**無論歸屬如何，審批人都可見。

## 標準列表視圖

- **我的商機**——你負責的商機。
- **本季度銷售管道**——本季度成交的開放交易。
- **本月成交**——本月成交的開放交易。
- **有風險**——已過成交日期但仍開放。
- **按金額排名的頂級交易**——最大的在前。
- **銷售管道看板**——按階段分組的看板（也可透過側邊欄快捷方式「銷售管道」存取）。

## 商機詳情版面

當你打開一個商機時，會看到：

- **頭部**——名稱、帶 7 階段路徑的階段徽章、金額、成交日期、負責人。點擊路徑上的任意階段可直接跳轉到它。
- **銷售路徑**——一鍵階段推進。
- **報價**相關列表——帶有一個**生成報價**按鈕，可執行 [報價生成流程](/zh-Hant/docs/sales/quotes#generating-a-quote)。
- **行項目**——帶有一個**新增產品**按鈕。
- **活動時間線**——統一彙集評論、已記錄通話（`sys_activity`）、外發郵件（`sys_email`）、任務完成以及欄位歷史稽核條目。商機上每個被追蹤的更改（階段、金額、成交日期、負責人）都會自動出現在這裡；沒有單獨的「歷史」標籤頁。
- **競爭對手與備註**——帶有談話要點的側邊面板。
- **AI 參考欄**——Sales Copilot 建議（Customer 360、營收預測、相關訊號）。

## AI Copilot 如何提供協助

當你打開一個商機時，可以提問：

- *"What's at risk here?"*——營收預測技能會檢查階段停留時長、競爭對手訊號和成交日期滑移。
- *"Draft a follow-up email"*——郵件起草技能會撰寫下一條外發訊息。
- *"Summarise this account"*——Customer 360 技能給你一屏的客戶歷史簡報。

## 給銷售代表的提示

- ✅ **及時推進階段**——如果你的階段錯了，機率就是錯的。
- ✅ **新增行項目**以進行恰當的營收預測；彙總後的金額更準確。
- ✅ **填寫後續步驟**——這是交接和站會中最有用的單個欄位。
- ✅ **選擇競爭對手**——AI 會用它來呈現制勝策略。
- ❌ 不要僅僅因為交易在滑移就更改成交日期。**有風險**視圖的存在就是為了暴露真實的滑移。

## 給管理員的提示

- 階段列表和預設機率位於商機物件的自動化中。參見 [Customization › Extending Objects](/zh-Hant/docs/customization/extending-objects) 來更改它們——你需要同步更新工作流規則和狀態機。
- $500K 折扣審批閾值可以在 [審批流程設定](/zh-Hant/docs/revenue/approvals) 中更改。
- $100K 大單通知閾值位於商機工作流規則中。
