# 系統管理

系統管理部分面向 **CRM 管理員** —— 即為團隊設定權限設定檔、共用規則、自動化和流程治理的人員。無需撰寫程式碼。

## 你將在這裡找到什麼

| 頁面 | 涵蓋內容 |
| --- | --- |
| [**設定清單**](/zh-Hant/docs/administration/setup) | 讓 HotCRM 為你的團隊做好準備的第一週任務 |
| [**權限設定檔**](/zh-Hant/docs/administration/profiles) | 六種內建權限設定檔以及如何指派使用者 |
| [**共用與安全**](/zh-Hant/docs/administration/sharing-and-security) | 組織範圍預設值、角色階層、共用規則、FLS |
| [**自動化**](/zh-Hant/docs/administration/automation) | 流程、物件鉤子、排程作業 |
| [**狀態機**](/zh-Hant/docs/administration/state-machines) | 狀態轉換與強制執行 |

## 本部分面向誰

- **CRM 管理員** —— 你的日常手冊。
- **銷售 / 服務營運** —— 用於理解為什麼事情會以特定方式運作。
- **實施顧問** —— 在初始上線期間。

如果你是用程式碼 **擴充 HotCRM 的開發者**，請改前往 [自訂](/zh-Hant/docs/customization/extending-objects)。

## 管理員的心智模型

HotCRM 建立在三個核心抽象之上：

1. **物件** —— 資料實體（客戶、聯絡人、商機、案例）。
2. **自動化** —— 物件變更時發生的事情（工作流、流程、狀態機）。
3. **安全** —— 誰能檢視和編輯什麼（權限設定檔、共用規則、欄位級安全）。

大多數管理任務都屬於這其中之一。本部分的頁面會向你展示每一類的控制項。

## 你擁有的工具

- **設定 UI** —— 在齒輪圖示下（右上角）找到它。所有管理任務的主中樞。
- **稽核日誌** —— 每一次設定變更都會記錄誰/何時/做了什麼。
- **沙箱** —— 在生產上線之前安全地測試設定變更。

## 從這裡開始

1. 全新安裝？遵循 [設定清單](/zh-Hant/docs/administration/setup)。
2. 需要給某個使用者不同的存取權限？參見 [權限設定檔](/zh-Hant/docs/administration/profiles)。
3. 在梳理誰能看到什麼？參見 [共用與安全](/zh-Hant/docs/administration/sharing-and-security)。
4. 新增自動化？參見 [自動化](/zh-Hant/docs/administration/automation)。
