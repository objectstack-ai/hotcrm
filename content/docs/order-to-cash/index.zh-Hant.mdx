# 訂單與回款

本應用未隨附繁體中文語言包，因此本頁出現的介面名詞依固定順序取用：zh-CN 語言包已收錄者，採其用詞的繁體寫法；未收錄者，保留產品內的英文原名，不另造譯名。

合約簽訂後，業務最關心三個問題：**開票了嗎？回款了嗎？有沒有逾期？**「訂單與回款」回答的就是這三個問題。它是 HotCRM 的一個模組，位於側邊欄的 **Order to Cash** 下。

## 是窗口，不是帳本 [#a-window-not-a-book]

每張發票、每筆回款都保存在財務記帳的地方：ERP、會計軟體，或財務自己的紀錄。「訂單與回款」是業務**查看**它們的窗口。財務在紀錄頁面上輸入，或批次匯入；ERP 也可以透過同一個匯入編號寫入。數字從不在 HotCRM 裡更正：在源頭更正後，再以同樣的方式進來。

因此這個模組不做任何記帳。它不開立、不審核發票，不分攤收款，不與銀行對帳，不催收，也不認列收入。贏單和合約生效時通知計費系統的，仍然是[計費交接](/docs/revenue/billing-handoff)。

業務在這裡維護的只有一樣東西：自己的**回款計劃**。

## 包含什麼 [#whats-included]

| 紀錄 | 是什麼 | 由誰輸入 |
| --- | --- | --- |
| **Billing Milestone** | 合約回款計劃中的一步：預付款、上線、驗收、保留款，或一個訂閱週期 | 合約的業務團隊 |
| **Invoice** | 財務針對合約開立的一張發票 | 財務 |
| **Payment** | 針對合約、發票或回款節點收到的款項 | 財務 |

三者都掛在**合約**下。打開合約，**Billing Milestones**、**Invoices** 和 **Payments** 三個分頁分別列出它們；客戶頁面列出該客戶所有合約的同類紀錄。

| 頁面 | 內容 |
| --- | --- |
| [回款計劃](./collection-plan) | 規劃合約的回款節點，以及 **Invoiced**、**Received**、**Open** 各統計什麼 |
| [發票與回款](./invoices-and-payments) | 輸入和匯入發票與回款、到期日、逾期發票 |

## 在哪裡找到它 [#where-to-find-it]

| 誰 | 在哪裡 |
| --- | --- |
| 財務（應收會計） | **Order to Cash** 應用：**Receivables** 下的 **Invoices**、**Payments** 和 **Billing Milestones**，**Follow-up** 下的 **Overdue Invoices** 和 **Planned This Month**，以及這些紀錄所屬的 **Contracts** 和 **Accounts**。這是財務啟動器上唯一的應用。 |
| 銷售代表和銷售經理 | **Sales** 應用 **Collection Plan** 群組下的 **Billing Milestones**，以及每份合約上的 **Billing Milestones**、**Invoices**、**Payments** 分頁。銷售代表的啟動器上沒有 Order to Cash 應用。 |
| 銷售經理和管理員 | 兩處都有：他們的啟動器提供全部四個應用。 |

啟動器決定的是提供哪些應用，而不是能打開哪些：啟動器上沒有的應用，用位址照樣能打開；每筆紀錄的存取權限仍由它的共用規則決定。

## 誰能做什麼 [#who-can-do-what]

| 人員 | 回款計劃 | 發票與回款 |
| --- | --- | --- |
| 業務代表 | 在自己能查看的合約上新增、編輯、刪除回款節點 | 唯讀 |
| 業務經理 | 在自己能查看的合約上新增、編輯、刪除回款節點 | 唯讀 |
| Accounts Receivable（財務） | 唯讀 | 在所有合約上輸入、編輯、刪除和匯入 |
| 管理員 | 全部 | 全部 |

能查看合約，就足以按上表寫入它的回款計劃、發票和回款：業務代表不用編輯合約就能維護回款計劃，財務在只能查看的合約上輸入發票和回款。不能查看合約的人，這三類紀錄都寫不了。

其他能查看合約的人，也能隨合約一起查看它的回款計劃、發票和回款：這三類紀錄跟隨合約的共用設定。財務的權限來自 **Accounts Receivable** 職位，由管理員在 **Setup → Position Holders** 中指派。

業務從不輸入回款。業務看到的數字永遠是財務輸入的，所以按回款計算的獎金方案不會讀到業務自己填寫的數字。

## 不是每個客戶都要用 [#not-every-customer-uses-it]

不需要「訂單與回款」的公司，由管理員停用這個模組。它的應用、Sales 應用裡的選單項目、紀錄，以及合約和客戶頁面上的相關分頁和彙總數字都會隨之消失。

## 合約和客戶上的彙總 [#totals]

合約和客戶上各有本模組的彙總數字，業務不用打開分頁就能看到（介面名稱依 zh-CN 語言包的繁體寫法）：

| 欄位 | 所在紀錄 | 統計什麼 |
| --- | --- | --- |
| **計劃回款** | 合約 | 回款計劃各節點的計劃金額合計 |
| **已開票** | 合約、客戶 | 狀態為**已開具**的發票金額合計；已作廢的發票不計入 |
| **已回款** | 合約、客戶 | 回款金額合計 |
| **應收餘額** | 合約、客戶 | 客戶在未結清發票上仍欠的金額：**已開立**發票的**未付**金額之和。尚未對應到發票的回款（例如預收款）只計入**已回款**，所以預收款不會讓餘額變成負數。溢付的發票未付為零，所以溢付也不會讓餘額變成負數 |

客戶的彙總涵蓋該客戶的所有合約。這些數字都不是手動填寫的：儲存回款節點、發票或回款時隨之更新。在合約上，它們顯示在「合約金額」區段；在客戶上，顯示在「財務資訊」區段。能查看合約或客戶的人都能看到，沒有人能編輯。客戶上的彙總不會讓看不到合約的人因此看到其發票。
