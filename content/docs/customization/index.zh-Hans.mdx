# 定制化

本节面向用代码扩展 HotCRM 的开发者和技术实施人员。如果你是在应用里配置用户、权限、流程或共享规则，请从[管理](/zh-Hans/docs/administration/index)开始。

## 当前源码结构

HotCRM 由四个包构建出一个 ObjectStack 制品（ADR-0130）：`src/` 下的一个目录**就是**一个包。请在拥有该对象的包里新增或修改元数据，然后从那个包对应的 barrel 文件导出。一个文件只能从自己的目录或 `src/sales/` 导入，模块之间不得横向导入。

```text
src/
├── sales/          # `type: app` 包 —— 客户、销售管道、活动记录，以及所有应用级条目
├── service/        # 模块 —— 工单与知识库
├── revenue/        # 模块 —— 产品、报价、行项目、合同
├── marketing/      # 模块 —— 市场活动与活动成员
└── docs/           # 陈述流程所实现业务规则的应用文档
```

包内是它用到的元数据类型子目录：

```text
src/sales/
├── objects/        # *.object.ts 模型，以及紧挨着各自模型的 *.hook.ts
├── actions/        # UI 动作和可执行动作体
├── flows/          # 自动化
├── skills/         # AI skills
├── apps/
├── views/
├── pages/
├── dashboards/
├── reports/
├── datasets/       # 仪表盘和报表查询的维度与度量
├── mappings/       # 数据导入的列到字段映射
├── profiles/
├── sharing/
├── translations/
├── data/           # 种子数据
└── interfaces/     # 共享类型（目前是空 barrel）
```

HotCRM 只定义 skills，不定义 agent：应用自带的两个 copilot 及其所在目录已被移除，AI 能力来自每个 ObjectStack 环境都提供的平台助手。把 skill 从 `src/*/skills/index.ts` 导出就是全部的接线工作。参见 [AI Skills](/zh-Hans/docs/customization/ai-skills)。

## 文件后缀协议

| 后缀 | 定义 |
| --- | --- |
| `*.object.ts` | 数据模型 |
| `*.hook.ts` | 对象生命周期逻辑 |
| `*.actions.ts` | UI 动作和可执行动作 |
| `*.flow.ts` | 自动化 |
| `*.skill.ts` | AI Copilot skill |
| `*.page.ts` | UI 页面 |
| `*.view.ts` | 列表或看板视图 |
| `*.dashboard.ts` | 仪表盘 |
| `*.report.ts` | 报表 |
| `*.sharing.ts` | 共享规则 |
| `*.profile.ts` | 权限档案 |

## 黄金规则

- HotCRM 对象名使用 `crm_` 前缀。
- 使用 ObjectQL 和 ObjectStack API，不使用原始 SQL。
- 从对应的 `src/**/index.ts` 文件导出元数据。
- 新增用户可见标签时同步更新翻译。
- 发布前运行 `pnpm verify`。
