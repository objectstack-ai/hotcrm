Widen the source hygiene gate's control-byte scan to `docs/`, `.github/`,
`.claude/` and a whitelist of root-level first-class files — including
`objectstack.config.ts`, `vitest.config.ts` and `playwright.config.ts`, which no
check had ever read (#838).

One raw control byte makes grep and ripgrep classify the **entire file** as
binary: the `-l` / `-c` forms most sweeps use then report nothing, so the file
drops out of every text search and the defect hides itself — what fails first is
the ability to investigate. #818 widened this scan to `content/` and
`.changeset/`; the surfaces left outside it were the ones agents read most.
`docs/` and `AGENTS.md` are grepped daily, and `.claude/` is where skill and
hook files land — upstream objectstack#4890 put a bare NUL inside a `.claude/`
`SKILL.md` *while writing the rule that forbids bare NULs*, outside every gate's
scan surface, which is why it survived.

The byte-scan surface grows by 75 files — 59 under the three new trees, 16 at
the root — from the 837 it read before. (The gate prints 913 on this branch; the
extra file is this changeset, which the old surface already covered.) The gate is
green on all of it today, so this is coverage, not a repair. Only the control-byte check moves: its rationale is the bytes on disk,
which is true of any text file, while `console.log`, `TODO`/`FIXME`, the 100KB
cap and the copyright-header position keep exactly the surface they had.

Two exclusions are deliberate and are pinned by tests rather than left to
inference. `assets/` stays out: 22 of its 34 files are images, and admitting it
would force an extension predicate onto a check whose whole stance is that the
surfaces it reads hold text only. `pnpm-lock.yaml` and `package-lock.json` stay
out: they are generated by pnpm and npm, so the remedy this check prints ("write
the character as an escape sequence") has no author to reach.
