# 指标——仪表盘上的数字怎么算

写给看仪表盘、想在行动之前弄清一个数字含义的每个人。磁贴上只有名称和数字；这一页说明每个数字统计的是什么，让两个人看同一块磁贴时读出同样的意思。

每个数字只统计**你**有权查看的记录。能看到全部商机的经理看到的是全公司的合计；销售代表看到的是自己的。

## 商机与收入

这些数字统计的是商机。"未结"始终指还没有到**成交**或**失败**的商机。

| 数字 | 统计内容 |
|---|---|
| **Total Amount** | 当前范围内商机的**金额**之和。管道磁贴和成交收入磁贴用的都是这个数字，区别只在保留哪些商机。 |
| **Avg Deal Size** | 当前范围内商机**金额**的平均值。 |
| **Avg Probability** | **成交概率 (%)** 的平均值。成交概率随阶段变化，所以它反映的是这些商机推进到了哪一步。 |
| **Won Deals** | 处于**成交**的商机。 |
| **Lost Deals** | 处于**失败**的商机。 |
| **Settled Deals** | 处于**成交**或**失败**的商机：所有已有结果的商机。 |
| **Won Revenue** | 处于**成交**的商机的**金额**。 |
| **Lost Revenue** | 处于**失败**的商机的**金额**。 |
| **Win Rate** | **Won Deals** ÷ **Settled Deals**。未结商机不计入，所以管道再满也不会拉低赢率。 |

凡是显示 **Win Rate** 的表格，旁边都同时显示 **Won Deals** 和 **Lost Deals**，方便你核对算式。如果赢率是空的、旁边却有失败的商机，意思是还没有赢单，即 0%，而不是缺数据。

磁贴把这些数字套在一组商机和一个时间窗口上：

| 磁贴 | 统计内容 |
|---|---|
| **Open Pipeline (Selected Period)** | 不处于**成交**或**失败**的商机的 **Total Amount**，时间段由日期选择器决定。 |
| **Closed Won (QTD)** | **预计成交日期**落在本季度至今、处于**成交**的商机的 **Total Amount**。 |
| **Total Revenue (YTD)** | **预计成交日期**落在本年至今、处于**成交**的商机的 **Total Amount**。 |
| **Win Rate (12M)** | **预计成交日期**落在最近 12 个月内的商机的 **Win Rate**。 |
| **Deals Won (12M)** | **预计成交日期**落在最近 12 个月内的 **Won Deals**。 |
| **Deals Lost (12M)** | **预计成交日期**落在最近 12 个月内的 **Lost Deals**。 |

## 配额与达成

配额类数字来自**销售预测**记录：每位负责人每个周期一条，记着这位负责人的配额，以及已成交、已承诺和仍在管道中的金额。

| 数字 | 统计内容 |
|---|---|
| **Quota** | 当前范围内销售预测的**配额**之和。 |
| **Closed** | **已成交金额**之和：负责人们已经赢下的金额。 |
| **Pipeline** | **管道金额**之和：负责人们的未结商机。 |
| **Commit** | **承诺金额**之和：负责人们承诺能落地的金额。 |
| **Attainment** | **Closed** ÷ **Quota**。先把金额加总再相除，所以配额大的人权重更大。 |
| **达成率（%）** | 单条销售预测上的 **已成交金额** ÷ **配额**。设置配额之前显示 0%。 |
| **覆盖倍数** | 单条销售预测上的 **管道金额** ÷（**配额** − **已成交金额**），即剩下的管道够不够填补还差的部分。配额已完成后显示 0。 |
| **Quota Attainment by Rep** | 每位负责人的 **Quota**、**Closed** 和 **Attainment**，只取本季度的**季度**预测。要等夜间预测快照开出本季度、并由经理设好每个配额之后才有数据。 |

周期始终是固定的。把一个季度的配额和一个月的配额加在一起，得到的数字没有意义，所以每个配额数字要么只显示一个周期，要么把各个周期并排列出。

在**报表**下，**季度管道覆盖率**用整个团队回答同一个问题：

| 报表 | 统计内容 |
|---|---|
| **Pipeline Coverage by Quarter** | 不处于**成交**或**失败**的商机的 **Total Amount** 和 **Opportunities**，按 **Forecast Category** 和 **Close Quarter** 分列。 |

## 互动

| 数字 | 统计内容 |
|---|---|
| **Activities** | 电话和会议，每个活动算一次。 |
| **Minutes** | **时长（分钟）**之和。 |
| **Interactions Logged** | 状态为**已举行**的 **Activities**：真正发生过的接触。 |
| **Meetings Booked** | 类型为**会议**、状态为**已计划**的 **Activities**：还没到来的会议。 |
| **Customer Minutes** | 状态为**已举行**的活动的 **Minutes**。 |
| **Tasks Completed** | 勾选了**是否完成**的 **Tasks**。 |

为什么只有已举行的活动才算接触，见[活动](./crm_sales_activities.md)。

## 客户、线索与流失信号

| 数字 | 统计内容 |
|---|---|
| **Active Accounts** | 标记为**是否活跃**的 **Accounts**。 |
| **Open Leads** | 未勾选**已转化**的 **Leads**。 |
| **Quiet 30+ Days** | 标记为**是否活跃**、**最近活动日期**在 30 天以前的 **Accounts**。 |
| **Quiet 60+ Days** | 标记为**是否活跃**、**最近活动日期**在 60 天以前的 **Accounts**。 |
| **Quiet 90+ Days** | 标记为**是否活跃**、**最近活动日期**在 90 天以前的 **Accounts**。 |

**报表**下的**客户流失信号**把四个早期预警叠在一起：

| 区块 | 统计内容 |
|---|---|
| **CSM-Flagged Accounts** | 标记为**是否活跃**、且**健康度**被人设为**风险**或**流失中**的 **Accounts**。它没有时间窗口：这是唯一一个由人判断、而不是由日期推出的信号。 |
| **At-Risk Accounts** | 标记为**是否活跃**、**最近活动日期**在 60 天以前的 **Accounts**。 |
| **Silent High-Value Accounts** | 标记为**是否活跃**、**客户分层**为**战略客户**或**企业客户**、**最近活动日期**在 90 天以前的 **Accounts**。 |
| **Recently Lost Opportunities** | **预计成交日期**落在最近 30 天内、处于**失败**的商机的 **Total Amount** 和 **Opportunities**。 |

沉默客户和风险客户的数字读的是**最近活动日期**，而只有已举行的电话或会议才会推动它。每天都在沟通的客户永远不会显示为沉默；只约了下个季度会议的客户，仍然算沉默。

工单类数字（SLA 达成率、解决时长、知识库自助解决率）和工单本身放在一起讲，见[工单与 SLA](./crm_service_cases.md) 和[知识库](./crm_service_knowledge.md)。
