# 客戶

**客戶**是你與之開展業務的公司（或任何組織）。它是其他一切所依附的中心樞紐：

- 聯絡人*為*某個客戶工作。
- 商機是*與*某個客戶的。
- 案例是*由*某個客戶*提出*的。
- 報價和合約是*由*某個客戶*簽署*的。

## 4 種客戶類型

每個客戶都有一個**類型**，它決定了系統其餘部分如何處理它：

| 類型 | 何時使用 |
| --- | --- |
| 🟠 **潛在客戶** | 售前——尚無合約。*（新建客戶的預設值。）* |
| 🟢 **客戶** | 正在付費的活躍客戶。 |
| 🔵 **合作夥伴** | 經銷商、整合商或通路合作夥伴。 |
| ⚪ **流失客戶** | 已流失——保留以用於贏回行銷活動。 |

當為某個潛在客戶啟用一份合約時，系統會自動將該客戶提升為**客戶**。你無需記著去更新它。

## 每筆客戶記錄儲存的內容

客戶詳情介面分為 6 個區塊：

| 區塊 | 欄位 |
| --- | --- |
| **基本資訊** | 客戶編號、名稱、類型、產業、描述 |
| **財務** | 年營收、員工人數 |
| **聯絡資訊** | 電話、網站、帳單地址、辦公地點（含地圖） |
| **歸屬與狀態** | 負責人、父級客戶、活躍標誌 |
| **品牌** | 品牌顏色（用作頭像強調色） |
| **系統** | 時間戳、稽核追蹤 |

## 客戶層級

使用**父級客戶**來建模帶有子公司的全球性企業：

```
Acme Corp Global
├── Acme Corp US
├── Acme Corp EMEA
│   ├── Acme Corp UK
│   └── Acme Corp Germany
└── Acme Corp APAC
```

該層級給你帶來：

- **彙總報告**——全球父級的年營收會彙總所有子級。
- **級聯共享**——當管理員授予對父級的存取權限時，所有子級都會繼承它。
- **更便捷的導覽**——從子級你可以跳轉到全球父級。

## 內建規則

- 客戶**名稱在你所屬的組織內必須唯一**。如果你嘗試用一個已存在的名稱再建一個客戶，會收到錯誤。同一平台上的其他組織可以有自己的 "Acme Corp" —— 這條規則只作用於你自己的資料，而不是整個平台。名稱按原樣精確比較，因此 `Acme Corp` 與 `ACME  Corp` 目前算作兩個不同的客戶。
- **年營收必須為零或正數**——不允許負數。
- 你**無法刪除**一個有開放商機或活躍合約的客戶。改為將其設為*非活躍*（`is_active = false`）。

## 自動更新

- 每當客戶更換負責人或類型時，**最近活動日期**會被自動蓋戳，因此你總能知道上次發生有意義的進展是什麼時候。
- **成為客戶日期**在首次合約啟用時被記錄。
- **商機總金額**和**贏單商機金額**會自動從相關商機彙總。
- **開放案例數**始終是即時的，因此你能一眼看出某個客戶是否正經歷困難時期。

## 客戶詳情版面

當你打開一個客戶時，會看到以下標籤頁：

- **概覽**——描述、關鍵聯絡人、負責人、主地址及一張小地圖。
- **商機**——所有相關交易，按階段分組，頂部顯示銷售管道總額。
- **聯絡人**——該客戶處的所有人，主要聯絡人被高亮顯示。
- **案例**——開放及近期關閉的支援案例。
- **活動**——電話、郵件、會議，最新的在前。
- **合約**——活躍及歷史合約。
- **檔案**——附加的文件（標誌、已簽署 PDF、資料表）。

## 共享——誰能看到哪個客戶

預設情況下客戶是**私有**的——只有負責人以及角色層級中位於其之上的人才能看到。

在此之上：

- **活躍客戶帳戶**會自動與所有銷售經理共享（讀/編輯）。
- **轄區規則**按帳單國家/地區共享客戶：
  - 北美（US、CA、MX）→ 北美銷售團隊
  - 歐洲（UK、DE、FR、IT、ES）→ 歐洲銷售團隊

管理員可以更改這些規則——參見 [Administration › Sharing](/zh-Hant/docs/administration/sharing-and-security)。

## 誰能編輯什麼

- **年營收**對**銷售代表是唯讀的**。只有銷售經理及以上才能更改它（保護財務估算）。
- **描述**可由任何有該客戶存取權限的人編輯。

## 標準列表視圖

- **我的客戶**——你負責的客戶。
- **所有客戶**——活躍的客戶。
- **按營收排名的頂級客戶**——最大的在前。
- **非活躍客戶**——`is_active = false`，用於清理。
- **按產業**——分組。
- **最近更新**——上次更改的內容。

## 給銷售代表的提示

- ✅ 始終設定一個**主要聯絡人**——許多流程預設使用它（報價、合約）。
- ✅ 使用**父級客戶**，而不是為每個區域建立重複的客戶。
- ✅ 一簽署合約就立即將潛在客戶提升為客戶（這會自動發生，但請核實）。

## 給管理員的提示

- 要新增的產業或國家轄區？參見 [Administration › Sharing](/zh-Hant/docs/administration/sharing-and-security) 和 [Customization › Extending Objects](/zh-Hant/docs/customization/extending-objects)。
- 詳情介面上的 6 個預設區塊可以按設定檔重新排序或隱藏。
