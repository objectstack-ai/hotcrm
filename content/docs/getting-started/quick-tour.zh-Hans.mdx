# 快速导览

带你导览你每天都会用到的屏幕。

## 1. 主页仪表盘

你看到的第一个东西是 **CRM Overview** 仪表盘。它告诉你：

- 你有多少**打开的线索**。
- 你的管道中有多少**商机**。
- 任何**等待你响应**的案例。
- 按管道价值排名的顶级客户。
- 近期活动（最近的通话、会议、邮件）。

把它当作你每日开始工作的着陆页。如果你是经理，你还会看到团队级汇总。

➜ 了解更多：[仪表盘](/zh-Hans/docs/analytics/dashboards)

![销售业绩仪表盘](/screenshots/hotcrm/sales-dashboard/zh-Hans.jpg)

## 2. 应用启动器

点击**应用启动器**（左上角网格图标）以在应用之间切换：

- **Enterprise CRM** —— 包含所有 CRM 功能的主应用。
- **Admin** —— 面向系统管理员。

在 Enterprise CRM 内，左侧导航按以下方式分组：

| 分组 | 内容 |
| --- | --- |
| **Sales** | Leads、Accounts、Contacts、Opportunities、Quotes、Contracts |
| **Service** | Cases、Knowledge Base |
| **Marketing** | Campaigns、Campaign Members |
| **Products** | Products |
| **Activities** | Tasks、Events |
| **Analytics** | Dashboards、Reports |
| **AI** | Copilot、Knowledge Bases |
| **Approvals** | Approval Requests、Action History |

## 3. 你的第一条线索

**线索**是已表达兴趣但尚未通过资格审查的人。

1. 点击 **Sales → Leads → New**。
2. 填写 **Name**、**Company**、**Email**。
3. 保存。线索会自动分配给你。
4. 在线索详情页上请助手 *"判定此线索资格"* —— [线索资格判定技能](/zh-Hans/docs/ai-copilot/sales-copilot) 会按 BANT 给出 0–100 的评分并建议下一步操作。
5. 准备就绪后，点击 **Convert** 一步将线索转化为 Account + Contact + Opportunity。

➜ 了解更多：[线索](/zh-Hans/docs/sales/leads)

![已确认线索工作区](/screenshots/hotcrm/lead-detail/zh-Hans.png)

## 4. 你的第一个商机

**商机**是你正在处理的真实交易。

1. 由线索转化自动创建，或 **Sales → Opportunities → New**。
2. 设置 **Account**、**Amount**、**Close Date**、**Stage**。
3. 随着交易推进，将其在各阶段间移动：*Prospecting → Qualification → Proposal → Negotiation → Closed Won*。
4. 系统会强制执行[状态机](/zh-Hans/docs/administration/state-machines) —— 你不能随意跳过阶段。
5. 点击 **✍️ Draft Email** 让 AI Copilot 起草一封符合上下文的跟进邮件。
6. 通过将阶段设置为 *Closed Won* 来赢单 —— 系统会自动创建合同并通知团队。

➜ 了解更多：[商机](/zh-Hans/docs/sales/opportunities)

![销售管道看板](/screenshots/hotcrm/sales-pipeline/zh-Hans.png)

## 5. 一个服务案例

**案例**是一个客户问题。

1. 案例通过邮件、Web 表单、电话、聊天或门户到达。
2. 新案例进入队列 —— 坐席接手。
3. 在新工单上请助手 *"分流此工单"* —— [工单分流技能](/zh-Hans/docs/ai-copilot/service-copilot) 会建议优先级、分类以及匹配的知识库文章。
4. SLA 计时器开始 —— 在案例页面查看响应时间 / 解决时间倒计时。
5. 回复客户；解决后关闭案例。

➜ 了解更多：[案例](/zh-Hans/docs/service/cases)

## 6. AI Copilot

Copilot 位于每个页面的**右侧聊天面板**。问它：

- *"本周我的管道里有什么风险？"*
- *"给我 [客户名称] 的客户 360。"*
- *"为这条线索起草一封发现跟进邮件。"*
- *"我本季度的预测是多少？"*

它从你的 CRM 数据中读取并遵守你的共享 —— 你无法让它泄露你本就看不到的记录。

➜ 了解更多：[AI Copilot](/zh-Hans/docs/ai-copilot/index)
