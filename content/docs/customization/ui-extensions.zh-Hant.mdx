# UI 擴展

本應用未隨附繁體中文語言包，因此本頁出現的介面名詞依固定順序取用：zh-CN 語言包已收錄者，採其用詞的繁體寫法；未收錄者，保留產品內的英文原名，不另造譯名。

HotCRM UI 中繼資料位於擁有它的那個套件自己的目錄下——`src/*/views/`、`src/*/pages/`、`src/*/dashboards/`、`src/*/reports/` 和 `src/*/actions/`，其中 `*` 是四個套件之一（`sales`、`service`、`revenue`、`marketing`）。一個項目與它所針對的那個物件放在一起。

## 新增動作

```ts
// src/sales/actions/opportunity.actions.ts
import type { Action } from '@objectstack/spec/ui';

export const MarkOpportunityReviewedAction: Action = {
  name: 'mark_opportunity_reviewed',
  label: 'Mark Reviewed',
  objectName: 'crm_opportunity',
  icon: 'check-circle',
  type: 'modal',
  target: 'mark_opportunity_reviewed',
  locations: ['record_header'],
  body: {
    language: 'js',
    capabilities: ['api.write'],
    source: `
      await ctx.api.object('crm_opportunity').update(input.id, {
        next_step: 'Reviewed by manager'
      });
      return { id: input.id };
    `,
  },
  refreshAfter: true,
};
```

## 新增視圖和頁面

- 清單和看板定義放在擁有它的那個套件的 `views/`——`src/sales/views/`、`src/service/views/`、`src/revenue/views/` 或 `src/marketing/views/`。
- 記錄頁面和工具頁面放在那個套件的 `pages/`——今天是 `src/sales/pages/` 或 `src/service/pages/`。
- 從對應的 `index.ts` 匯出新中繼資料。
- 將使用者可見標籤加入 `src/sales/translations/{locale}.ts`。
