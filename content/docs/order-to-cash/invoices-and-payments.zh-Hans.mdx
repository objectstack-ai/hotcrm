# 发票与回款

这里的**发票**，是财务在自己系统中开具的一张发票的记录；**回款**，是收到款项的记录。两者都由财务录入或导入。销售在合同、客户和**订单与回款**下的列表中查看它们。

## 发票 [#invoices]

| 字段 | 内容 |
| --- | --- |
| **发票号码** | 财务开具的发票上的号码 |
| **合同** | 这张发票针对的合同 |
| **回款节点** | 这张发票对应的回款节点（如有）。只提供这张发票所属合同的节点 |
| **开票日期** | 开具的日期 |
| **到期日** | 应付款的日期（见下文） |
| **金额** | 开票金额，含税 |
| **状态** | **已开具**或**已作废** |
| **已付** | 针对这张发票收到的回款合计 |
| **未付** | **金额**减去**已付**；已作废的发票为零 |
| **发票文件** | 发票文件（如已附上） |

**到期日。** **到期日**留空时，保存时会自动填写：**开票日期**加上合同的**付款条件**（Net 15、30、60 或 90 天；Due on Receipt 即开票当天）。填写了日期则按填写的保存。

**已作废的发票。** 在源头作废或全额红冲的发票，在这里设为**已作废**。它随即退出所有统计：所属节点不再把它计为已开票，未付金额为零。

## 逾期发票 [#overdue-invoices]

**订单与回款 → 发票**下的**逾期发票**列表，按到期日从早到晚列出你能看到的、状态为**已开具**、**到期日**早于今天且仍有**未付**金额的发票。回款付清当天，或财务将其作废后，发票就会离开这个列表。

## 回款 [#payments]

| 字段 | 内容 |
| --- | --- |
| **回款编号** | 自动编号：PAY-00001、PAY-00002…… |
| **合同** | 这笔款项针对的合同 |
| **发票** | 这笔款项支付的发票（如有）。只提供这笔回款所属合同的发票 |
| **回款节点** | 这笔款项计入的节点。有发票时从发票带入；开票前收到的预付款，请自行选择 |
| **回款日期** | 收到款项的日期 |
| **金额** | 收到多少 |
| **方式** | **银行转账**或**其他** |

**每张发票一行。** 一笔收款支付了多张发票时，按财务已有的拆分，每张发票记录一笔回款。HotCRM 中没有分摊这一步。

**开票前的预付款。** 把回款记录到回款节点上。发票开具后，在同一笔回款上填写**发票**。

**针对其他合同发票的回款会被拒绝**，提示会写明是哪张发票。这只可能发生在导入中，因为表单只提供本合同的发票。

## 导入 [#importing]

财务可以用**Invoice Import (CSV)** 和 **Payment Import (CSV)** 两个导入映射，从电子表格、财务软件或 ERP 的导出文件批量导入发票和回款。带有正确列标题的模板是 `assets/import-templates/` 下的 `invoices.csv` 和 `payments.csv`。

| 列 | 发票 | 回款 |
| --- | --- | --- |
| ERP Reference | ✓ 唯一编号 | ✓ 唯一编号 |
| Contract | ✓ 合同编号，例如 CTR-0001 | ✓ |
| Invoice Number | ✓ | — |
| Invoice | — | ✓ 发票号码 |
| Billing Milestone | ✓ 节点名称 | ✓ |
| Issue Date、Due Date、Amount、Status | ✓ | — |
| Payment Date、Amount、Method | — | ✓ |

- **ERP 编号是唯一键。** 导入一行时，如果它的 **ERP 编号**已在某张发票上，就更新这张发票，而不会再添加一张。因此财务修改文件后可以再次导入。ERP 通过接口写入时使用同一个编号。
- **每一条导入的记录都有标记。** 它的**来源**为**导入**，**同步时间**为导入的时刻，读者可以看出数字从哪里来、有多新。手工录入的记录，来源为**手工录入**。
- **引用按名称匹配。** 合同编号、发票号码或节点名称匹配不到任何记录时，该行导入失败，导入报告会写明原因。

金额使用公司的币种，与 HotCRM 中所有金额一样。请在导入前完成换算。
