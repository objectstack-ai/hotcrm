# 项目与成本——谁在项目上，每个数字算什么

写给项目经理、被安排在项目上的人员，以及财务。项目是为某个客户做的售前、交付或内部工作；三种项目的人员安排、工时填报和成本核算方式完全相同，所以售前和内部投入同样计入成本。项目可以在**订单**中写明它交付的销售订单（与合同并列），订单页面的**项目**列表随即列出它。

## 人员安排决定谁能查看和管理项目

- **项目经理来自人员安排。** 在人员安排中职责为*项目经理*的人，就是项目的**项目经理**：他们编辑项目、为项目安排人员，并审批项目的工时单和费用。这个字段不能在项目上直接填写，要修改人员安排行。
- **安排的所有人都是项目团队**，项目经理也在其中，可以查看项目。删除一行人员安排，也就收回了这个人的访问权限。
- **项目团队看得到客户，看不到商机。** 团队成员可以只读查看全部客户，所以项目上的客户会显示名称，但看不到客户的已开票、已回款、未回款和未开票。他们的项目页上不显示商机和订单，也打不开项目的商机，「项目交付」菜单里也没有「商机」入口。
- **每人在每个项目上只有一行。** 重复安排同一个人会被拒绝。
- **先安排项目经理。** 在有人被安排为项目经理之前，在这个项目上填写的工时单没有审批人，在这个项目上提交的报销单交给管理员审批。
- **只有被安排在项目上的人才能为它填报工时。** 其他人的工时会被拒绝，并写明是哪个项目。

## 一小时如何计成本

- **单价在填写工时时复制。** 工时条目从这个人人员安排行上的费率卡取**成本单价**和**计费单价**并保留下来。之后修改费率卡，不会改变过去的成本；只有修改后填写的工时才使用新单价。
- **按天计价的费率卡按 8 小时折算。** 按天定价的费率卡，每小时成本为日单价除以 8。
- **不计费的人员安排不产生计费金额。** 他们的工时照样计成本。
- **工时只能落在所属工时单的周期内。** 日期超出工时单周期的条目会被拒绝；工时单一经提交，其中的条目就不能再修改。
- **一周的工时逐行录入。** 在**我的本周**里，一条填了项目和日期、没选工时单的明细，会记到你在这个项目上、期间包含这一天的工时单；没有的话就新建这一周（周一到周日）的草稿工时单。每个项目各有自己的工时单和审批人；**提交本周**一次把它们逐张提交。
- **项目团队成员看不到成本。** 成本单价、条目成本和项目的成本数字对被安排为团队成员的人隐藏；计费一侧照常显示。

## 自动变化的数字

只有**计划收入**是手工填写的。**批准预算**是项目基线预算版本的合计，只在某个版本获批时变化。项目上的其他金额只统计**已批准**的工时和费用：草稿，或正在等审批人的工时单，都还不算成本。

- **人工成本**和**费用成本**分别汇总已批准的工时和费用。**实际成本**是两者之和。
- **剩余预算**是批准预算减去实际成本；**预算使用率**是实际成本占批准预算的比例，项目花费超出预算时会超过 100。
- **毛利**是计划收入减去实际成本。
- **已批准待开票**是同一批已批准工时和费用的计费一侧，按计费单价计算；由「订单与回款」开票。
