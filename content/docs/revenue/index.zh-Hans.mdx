# 营收云

营收模块涵盖**销售说"我们赢了"之后**发生的一切：管理产品目录和价格、治理合同和续约，以及审批高价值折扣。

## 包含内容

| 领域 | 作用 |
| --- | --- |
| [**产品**](/zh-Hans/docs/revenue/products) | 你所销售内容的目录——名称、编码、标价、计费类型。 |
| [**合同**](/zh-Hans/docs/revenue/contracts) | 与客户签署的协议——条款、价值、续约。 |
| [**审批**](/zh-Hans/docs/revenue/approvals) | 针对高价值折扣的多步骤审批。 |

## 营收生命周期

```
Product (catalog)
   │
   ▼
Quote with line items
   │ (accepted)
   ▼
Contract (Activated)
   │
   ▼ (renewal_notice_days before end_date)
Renewal task ──► Renewal opportunity
```

1. **建立目录**——带编码、标价、计费类型的产品。
2. **构建报价**——使用目录中的明细行（参见 [报价](/zh-Hans/docs/sales/quotes)）。
3. **接受时**系统会以报价的条款创建一份合同。
4. **合同被激活**——账户被提升为 *Customer*。
5. **合同结束前**，系统会安排一个续约任务和一个续约提醒。
6. **续约商机**可在客户希望延期时创建。

## 系统为你做的事

- **自动提升账户**——合同被激活的那一刻将账户提升为 *Customer*。
- **自动盖签署日期**——同一次激活会在**合同**上写入当天日期，且仅当合同上还没有签署日期时才盖。**账户**上不会盖任何日期：没有 *Customer Since* 字段，也没有任何其它名字的字段记录账户何时成为客户，所以做同期群分析只能读合同的**签署日期**或**开始日期**。
- **每日到期扫描**——午夜时分，超过结束日期的合同被标记为 *Expired* 并通知所有者。
- **每日续约提醒**——当合同进入它自己的通知窗口（**续约通知（天）**，不改就是 30 天）时，**合同负责人**会收到一个续约任务和一条提醒（站内收件箱 + 邮件）。除他之外无人被通知——账户所有者不会，账户上的续约负责人也不会。
- **折扣审批**——超过 $500K 的商机自动路由给经理 + 总监签批。

## 在哪里找到这些内容

在 Enterprise CRM 应用中，**产品**分组包含：

- **产品**——目录

而**销售**分组包含**合同**（因为它们属于销售流程）。

审批位于**审批**分组中：

- **审批请求**——待处理的内容
- **操作历史**——谁在何时审批了什么
- **流程**——审批规则的管理员视图
