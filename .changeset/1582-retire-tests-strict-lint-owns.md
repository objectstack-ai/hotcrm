Tests and tooling only, releases nothing. For maintainers: `pnpm verify` no longer runs `lint:i18n-gate`, and CI no longer runs the i18n lint gate step. `pnpm lint` is `objectstack lint --strict`, which already fails on every `i18n/missing-*` finding the gate counted, so the gate script (`scripts/check-lint-i18n-gate.mjs`), its test and its `package.json` script are gone. In the same change, the local test assertions whose every case `objectstack lint --strict` now reports are retired, row by row: the inert decision `config.condition`, `list.tabs`, page and form field references, field-group integrity, skill tool names, report dataset/dimension/measure bindings, preset filter comparands, the option-key, navigation-orphan and section-name translation checks, FLS key qualification and field names, and RLS predicates (#1582, #1583, #1584, #1585, #1586, #1805).
